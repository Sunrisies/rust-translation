# Influences

Rust 并非一种特别原创的语言，其设计元素来自多种来源。以下列出了其中一些元素（包括后来被移除的元素）：

* SML、OCaml：代数数据类型、模式匹配、类型推导、分号语句分隔 * C++：引用、RAII、智能指针、移动语义、单态化、内存模型 * ML Kit、Cyclone：基于区域的内存管理 * Haskell (GHC)：类型类、类型族 * Newsqueak、Alef、Limbo：通道、并发 * Erlang：消息传递、线程失败、~~轻量级并发~~ * Swift：可选绑定 * Scheme：卫生宏 * C#：属性 * Ruby：闭包语法、~~块语法~~ * NIL、Hermes：~~类型状态~~ * [Unicode Annex #31](http://www.unicode.org/reports/tr31/)：标识符和模式语法
