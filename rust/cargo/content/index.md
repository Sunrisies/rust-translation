# Cargo 手册

![Cargo Logo](images/Cargo-Logo-Small.png)

Cargo 是 [Rust] [*包管理器*][def-包-manager]。Cargo 会下载你的 Rust [包][def-包]的依赖项，编译这些包，生成可分发包，并将它们上传到 [crates.io]，这是 Rust 社区的 [*包注册表*][def-包-registry]。你可以在 [GitHub] 上为这份手册做出贡献。
