# cargo-clippy(1)

## 名称

cargo-clippy —— 对软件包进行检查，以发现常见错误并优化你的 Rust 代码

## 描述

这是一个随 Rust 工具链一起提供的外部命令，作为可选组件存在。它未内置于 Cargo 中，可能需要额外安装。

关于使用方法和安装的详细信息，请参阅 [Clippy 文档](../../clippy/index.html)。
