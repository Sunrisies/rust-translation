# cargo-fmt(1)

## 名称

cargo-fmt —— 使用 rustfmt 格式化当前 crate 中的所有 bin 和 lib 文件

## 描述

这是一个随 Rust 工具链一起提供的外部命令，作为可选组件存在。它未内置于 Cargo 中，可能需要额外安装。

关于使用和安装的详细信息，请参见 <https://github.com/rust-lang/rustfmt>。
