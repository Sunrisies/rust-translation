# cargo-miri(1)

## 名称

cargo-miri —— 在 Miri 环境中运行二进制 crate 和测试

## 描述

这是一个随 Rust 工具链一起提供的外部命令，作为可选组件存在。它未内置于 Cargo 中，可能需要额外安装。

此命令仅可在 [nightly](https://doc.rust-lang.org/book/appendix-07-nightly-rust.html) 频道上使用。

关于用法和安装的详细信息，请参见 <https://github.com/rust-lang/miri>。
