# 常见集合

Rust 标准库包含许多非常有用的数据结构，称为_集合_。大多数其他数据类型表示单一值，而集合可以包含多个值。与内置数组和元组类型不同，这些集合所指向的数据存储在堆上，这意味着数据量无需在编译时确定，并且可以在程序运行过程中增长或缩小。每种集合都有不同的功能和成本，选择适合当前情况的集合是一个需要随着时间培养的技能。在本章中，我们将讨论 Rust 程序中经常使用的三种集合：

- _向量_允许你同时存储任意数量的值。
- _字符串_是字符的集合。我们之前提到过`String`类型，但在本章中将深入讨论它。
- _哈希映射_允许你将值与特定键关联起来。它是更一般的数据结构_映射_的一种具体实现。

要了解标准库提供的其他类型的集合，请查看[文档][collections]。

我们将讨论如何创建和更新向量、字符串和哈希映射，以及每种集合的独特特性。
