# 前言

在短短几年内，Rust 编程语言已经取得了显著的进步。从由一群新兴爱好者社区创建和培育开始，它如今已成为世界上最受喜爱且需求旺盛的编程语言之一。回顾过去，Rust 的强大功能和巨大潜力必然会在系统编程领域获得认可并占据一席之地。然而，全球范围内对它的兴趣与创新的迅速增长却并非必然，这种增长通过开源社区传播，促使各个行业广泛采用该语言。

此时此刻，可以很容易地指出 Rust 提供的诸多优秀特性来解释其如此迅速的受欢迎程度。谁不希望拥有内存安全、快速性能、友好的编译器以及出色的工具集等特性呢？如今我们所看到的 Rust 语言结合了多年系统编程研究成果和充满热情的社区实践智慧。这种语言经过精心设计，为开发者提供了一种能够编写安全、高效且可靠的代码的工具。

但真正使 Rust 与众不同的在于其旨在赋能用户实现目标的核心理念。这是一种希望用户取得成功的语言，而这种赋能原则贯穿了构建、维护和支持该语言的社区核心。自上一版权威文本以来，Rust 已经发展成为一个真正的全球性且值得信赖的语言。Rust 项目现在得到了 Rust Foundation 的强大支持，该基金会还投资于关键计划，确保 Rust 的安全、稳定与可持续性。

本版《Rust 编程语言》是对该语言多年发展情况的全面更新，并提供了宝贵的新信息。但这不仅仅是一本语法和库指南——它邀请你加入一个重视质量、性能与深思熟虑设计的社区。无论你是首次探索 Rust 的资深开发者，还是希望提升技能的经验丰富的 Rustacean，本版都适合所有人。

Rust 的发展历程是合作、学习与迭代的结果。该语言及其生态系统的成长直接反映了其充满活力的多元化社区。从核心语言设计者到普通贡献者，数千名开发者的贡献使得 Rust 成为如此独特且强大的工具。通过阅读这本书，你不仅仅是在学习一种新的编程语言——你正在加入一个致力于让软件更加优秀、安全且更易于使用的运动。

欢迎加入 Rust 社区！

- Bec Rumbul，Rust 基金会执行主任
