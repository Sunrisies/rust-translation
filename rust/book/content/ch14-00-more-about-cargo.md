# 更多关于 Cargo 和 Crates.io 的信息

到目前为止，我们仅使用了 Cargo 最基本的功能来构建、运行和测试代码，但它还能做很多事情。在本章中，我们将讨论一些更高级的功能，以展示如何执行以下操作：

- 通过发布配置文件自定义构建过程。
- 在 [crates.io](https://crates.io/) 上发布库。
- 使用工作区组织大型项目。
- 从 [crates.io](https://crates.io/) 安装二进制文件。
- 使用自定义命令扩展 Cargo 功能。

Cargo 的功能远不止本章所涵盖的，如需了解其所有功能的详细说明，请查看 [官方文档](https://doc.rust-lang.org/cargo/)。
