# 智能指针

指针是表示内存地址的变量的一般概念。这个地址指向或“指向”其他数据。Rust中最常见的指针类型就是引用，你在第4章中已经了解过。引用由`&`符号表示，用于借用其指向的值。它们除了能够引用数据之外没有特殊功能，也没有额外的开销。

另一方面，_智能指针_是一种既像指针又具有额外元数据和功能的数据结构。智能指针的概念并非Rust所独有：智能指针起源于C++，也存在于其他语言中。Rust的标准库中定义了多种智能指针，它们提供了比引用更多的功能。为了了解这一概念，我们将通过几个不同的智能指针示例来展示，包括一种_引用计数_智能指针类型。这种指针允许数据拥有多个所有者，通过跟踪所有者的数量来实现，当没有所有者时则清理数据。

在Rust中，由于所有权和借用机制的存在，引用与智能指针之间存在另一个区别：虽然引用仅借用数据，但在许多情况下智能指针_拥有_其指向的数据。

智能指针通常使用结构体实现。与普通结构体不同，智能指针实现了`Deref`和`Drop`特质。`Deref`特质使智能指针结构体的实例能够像引用一样行为，这样你就可以编写代码来同时使用引用和智能指针。`Drop`特质则允许你自定义当智能指针实例超出作用域时运行的代码。在本章中，我们将讨论这两个特质，并说明它们对智能指针的重要性。

鉴于智能指针模式是 Rust 中常用的一种通用设计模式，本章不会涵盖所有现有的智能指针。许多库都有自己独特的智能指针，甚至你可以编写自己的智能指针实现。我们将介绍标准库中最常见的几种智能指针：

- `Box<T>`，用于在堆上分配值 - `Rc<T>`，一种引用计数类型，支持多所有者关系 - `Ref<T>` 和 `RefMut<T>`，通过 `RefCell<T>` 访问，这是一种在运行时而非编译时强制执行借用规则的类型

此外，我们还将介绍 _内部可变性_ 模式，即不可变类型提供用于修改内部值的 API。我们还会讨论引用循环：它们如何导致内存泄漏以及如何防止这种情况。
