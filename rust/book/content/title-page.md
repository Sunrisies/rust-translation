# Rust 编程语言

由 Steve Klabnik、Carol Nichols 和 Chris Krycho 编写，Rust 社区也做出了贡献_

本版本文本假设您正在使用 Rust 1.99.1（发布于 2026-10-15）或更高版本，并且所有项目的 *Cargo.toml* 文件中设置了 `edition = "2024"`，以采用 Rust 2024 版惯用法。关于安装或更新 Rust 的说明，请参见第 1 章的[“安装”部分][install]<!-- ignore -->，关于版本的更多信息则请参阅[附录 E][appendix-e]<!-- ignore -->。

HTML 格式可在 [https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/) 在线查看，也可以通过使用 `rustup` 安装的 Rust 离线获取；运行 `rustup doc --book` 即可打开。

还有多种社区[翻译版本]可供选择。

本文本有[纸质版和电子书版本由 No Starch Press 出版][nsprust]。


> **🚨 想要更互动的学习体验？尝试使用不同版本的 Rust 书籍，包含：测验、高亮显示、可视化效果等**：<https://rust-book.cs.brown.edu>
