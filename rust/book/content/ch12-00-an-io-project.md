# 一个 I/O 项目：构建命令行程序

本章将回顾你迄今为止学到的许多技能，并探索一些标准库功能。我们将构建一个与文件和命令行输入输出交互的命令行工具，以实践你已掌握的 Rust 概念。

Rust 的速度、安全性、单一二进制输出以及跨平台支持使其成为创建命令行工具的理想语言。因此，在我们的项目中，我们将实现经典命令行搜索工具 `grep` 的自定义版本（**全局搜索**正则表达式并**打印**结果）。在最简单的使用场景中，`grep` 会在指定文件中查找指定的字符串。为此，`grep` 需要传入文件路径和字符串作为参数。然后，它读取文件，找到包含该字符串的行，并输出这些行。

在此过程中，我们将展示如何使我们的命令行工具利用许多其他命令行工具使用的终端功能。我们将读取环境变量的值，以便用户能够配置工具的行为。我们还将错误消息输出到标准错误流（`stderr`），而不是标准输出（`stdout`），这样用户就可以将成功输出重定向到文件，同时仍能在屏幕上看到错误信息。

Rust 社区成员 Andrew Gallant 已经创建了一个功能齐全且速度极快的 `grep` 版本，名为 `ripgrep`。相比之下，我们的版本会相对简单，但本章将为你提供理解像 `ripgrep` 这样的实际项目所需的一些背景知识。
