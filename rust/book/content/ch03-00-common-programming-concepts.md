# 常见的编程概念

本章介绍了几乎每种编程语言都存在的概念，以及它们在 Rust 中的运作方式。许多编程语言在核心上有很多共同之处。本章所介绍的概念并非 Rust 独有，但我们将在 Rust 的语境下讨论它们，并解释使用这些概念的规范。

具体来说，你将学习变量、基本类型、函数、注释和控制流。这些基础是所有 Rust 程序都需要的，尽早掌握它们可以让你有一个扎实的基础。

> #### 关键词
>
> Rust 语言有一组_关键词_，这些词仅由该语言保留使用，与其他语言类似。请注意，你不能将这些词用作变量或函数的名称。大多数关键词具有特殊含义，你将在 Rust 程序中利用它们执行各种任务；少数关键词目前没有特定功能，但被保留用于未来可能添加到 Rust 中的功能。你可以从[附录 A][appendix_a]中找到关键词列表。
