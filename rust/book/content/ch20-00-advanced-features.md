# 高级特性

到现在为止，你已经学习了 Rust 编程语言中最常用的部分。在我们在第21章开展另一个项目之前，我们将探讨一些你在日常使用中可能不会经常遇到但偶尔会遇到的语言特性。你可以将这一章作为遇到任何未知问题的参考手册。这里介绍的这些特性在非常特定的情况下非常有用。虽然你可能不会经常使用它们，但我们希望确保你能够掌握 Rust 所提供的所有特性。

在本章中，我们将涵盖：

- 不安全 Rust：如何放弃 Rust 的一些保证，并自行负责维护这些保证 - 高级特质：相关类型、默认类型参数、完全限定语法、超特质以及与特质相关的新类型模式 - 高级类型：关于新类型模式、类型别名、never 类型和动态大小类型的更多内容 - 高级函数和闭包：函数指针和返回闭包 - 宏：在编译时定义更多代码的代码定义方式

这是一系列丰富的 Rust 特性，适合各种需求！让我们开始探索吧！
