# 简介

> 注意：本版书籍与[Rust 编程语言][nsprust]相同，该版本以纸质版和电子书形式由[No Starch Press][nsp]提供。


欢迎阅读《Rust 编程语言》，这是一本关于 Rust 的入门书籍。Rust 编程语言帮助你编写更快、更可靠的软件。在编程语言设计中，高级易用性与低级控制往往存在矛盾；Rust 挑战了这种矛盾。通过平衡强大的技术能力与优秀的开发者体验，Rust 让你能够在不经历传统控制所带来的诸多麻烦的情况下，控制底层细节（如内存使用）。

## Rust 适合谁

由于多种原因，Rust 非常适合许多人。让我们来看看几个最重要的群体。

### 开发团队

Rust 被证明是大型开发团队之间协作的有效工具，这些团队拥有不同水平的系统编程知识。低级代码容易出现各种细微错误，在大多数其他语言中只能通过广泛的测试和经验丰富的开发者仔细的代码审查来发现。在 Rust 中，编译器扮演了守门人的角色，拒绝编译包含这些难以发现的错误的代码，包括并发错误。通过与编译器合作，团队可以专注于程序逻辑，而不是追逐错误。

Rust 还将现代开发工具引入系统编程领域：

- Cargo 作为内置的依赖管理器和构建工具，使添加、编译和管理依赖变得轻松且在整个 Rust 生态系统中保持一致。
- `rustfmt` 格式化工具确保开发者使用统一的编码风格。
- Rust 语言服务器支持集成开发环境（IDE）的代码补全和内联错误提示功能。

通过使用这些以及 Rust 生态系统中的其他工具，开发者可以在编写系统级代码时保持高效。

### 学生

Rust 适合学生以及对系统概念感兴趣的人。通过学习 Rust，许多人掌握了操作系统开发等主题。社区非常友好，乐于解答学生的疑问。通过如本书这样的努力，Rust 团队希望让更多人能够理解系统概念，尤其是那些编程新手。

### 企业

数百家大小公司将 Rust 用于生产环境中的多种任务，包括命令行工具、网络服务、DevOps 工具、嵌入式设备、音频和视频分析与转码、加密货币、生物信息学、搜索引擎、物联网应用、机器学习，甚至 Firefox 浏览器的重要部分。

### 开源开发者

Rust 适合那些希望构建 Rust 编程语言、社区、开发工具和库的人。我们非常欢迎您的贡献。

### 重视速度与稳定性的人

Rust 适合那些渴望语言具有速度和稳定性的人。这里的“速度”既指 Rust 代码运行的速度，也指您编写程序的能力。Rust 编译器的检查机制通过功能添加和重构来确保稳定性。这与没有这些检查机制的旧语言中的脆弱遗留代码形成对比，后者往往让开发者不敢修改。通过追求零成本抽象——即高级特性能够以与手动编写的代码一样快的方式编译成低级代码——Rust 致力于使安全代码也能具有高性能。

Rust 编程语言也希望支持更多用户；这里提到的只是一些最大的利益相关者。总体而言，Rust 的最大目标是通过提供安全性与生产力、速度与易用性，消除程序员几十年来必须接受的权衡。尝试使用 Rust，看看它的选择是否适合您。

## 本书适用于谁

这本书假设您已经使用其他编程语言编写过代码，但并未对具体语言做出任何假设。我们努力使内容能够广泛适用于不同编程背景的读者。我们没有花太多时间讨论编程是什么或如何思考编程问题。如果您完全是编程新手，那么阅读专门介绍编程入门的书会更为合适。

## 如何使用本书

通常来说，这本书要求您按顺序从前往后阅读。后面的章节会在前面章节的概念基础上进行扩展，而前面的章节可能不会深入讨论某个特定主题的细节，但在后续章节中会再次涉及该主题。

本书包含两种类型的章节：概念章节和项目章节。在概念章节中，您将学习Rust的某些特性。在项目章节中，我们将一起构建小型程序，应用您迄今为止学到的知识。第2章、第12章和第21章属于项目章节；其余的是概念章节。

**第1章**介绍了如何安装Rust、如何编写“Hello, world!”程序以及如何使用Cargo（Rust的包管理器和构建工具）。**第2章**是一个实践性的入门课程，让您构建一个数字猜谜游戏。在这里，我们以宏观层面介绍概念，后续章节将提供更多细节。如果您想立即动手实践，第2章是合适的选择。如果您是一位非常细致的学习者，喜欢在进入下一章节之前了解所有细节，那么可以跳过第2章，直接阅读**第3章**，该章介绍了与其他编程语言类似的Rust特性；之后，当您希望应用所学知识进行项目开发时，再返回第2章。

在**第4章**中，您将学习Rust的所有权系统。**第5章**讨论结构体和方法。**第6章**涵盖枚举、`match`表达式以及`if let`和`let...else`控制流结构。您将使用结构体和枚举来创建自定义类型。

在**第7章**中，你将了解Rust的模块系统以及用于组织代码及其公共应用程序编程接口（API）的隐私规则。**第8章**讨论了标准库提供的一些常见集合数据结构：向量、字符串和哈希映射。**第9章**探讨了Rust的错误处理理念与技巧。

**第10章**深入介绍了泛型、特征及生命周期，这些概念使你能够定义适用于多种类型的代码。**第11章**则全面讨论测试，即使有Rust的安全保证，确保程序逻辑正确也是必要的。**第12章**中，我们将从`grep`命令行工具实现一部分功能，该工具用于在文件中搜索文本。为此，我们将运用前几章中讨论的许多概念。

**第13章**探讨了闭包和迭代器：这些是源自函数式编程语言的Rust特性。**第14章**将更深入地介绍Cargo，并讨论与他人共享库的最佳实践。**第15章**讨论了标准库提供的智能指针及其实现功能的特征。

在**第16章**中，我们将探讨不同的并发编程模型，并讨论Rust如何帮助你无畏地使用多个线程进行编程。**第17章**在此基础上进一步探索Rust的异步和等待语法，以及任务、未来值和流，以及它们所支持的轻量级并发模型。

**第18章**将比较Rust的惯用法与你可能熟悉的面向对象编程原则。**第19章**是一篇关于模式和模式匹配的参考文章，它们是表达Rust程序中概念的强大方式。**第20章**包含一系列高级主题，包括不安全的Rust、宏以及关于生命周期、特征、类型、函数和闭包的更多内容。

在**第21章**中，我们将完成一个项目，其中会实现一个低级多线程Web服务器！

最后，一些附录以参考形式提供了关于语言的有用信息。**附录 A**介绍了 Rust 的关键字，**附录 B**介绍了 Rust 的运算符和符号，**附录 C**介绍了标准库提供的可派生特征，**附录 D**介绍了一些有用的开发工具，而 **附录 E**则解释了 Rust 的不同版本。在 **附录 F**中你可以找到书籍的翻译内容，在 **附录 G**中我们将介绍 Rust 的构建过程以及当前版本的特性。

阅读这本书没有错误的方式：如果你想跳过某些内容，那就去吧！如果你感到困惑，可能需要回到之前的章节。但请选择最适合你的方式。
