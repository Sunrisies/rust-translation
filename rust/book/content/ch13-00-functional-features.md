# 函数式语言特性：迭代器与闭包

Rust的设计汲取了多种现有语言和技术的灵感，其中重要的影响之一就是_函数式编程_。以函数式风格进行编程通常包括将函数作为值使用，通过传递参数来调用它们，从其他函数中返回这些函数，将它们赋给变量以便后续执行等。

在本章中，我们不会讨论什么是函数式编程以及什么不是函数式编程，而是会探讨Rust中的一些特性，这些特性与许多被称为函数式的语言中的特性类似。

更具体地说，我们将涵盖：

- _闭包_，一种可以存储在变量中的函数式构造 - _迭代器_，处理一系列元素的方法 - 如何在第12章中使用闭包和迭代器来改进I/O项目 - 闭包和迭代器的性能（剧透警告：它们比你想象的要快！）

我们已经介绍了其他一些Rust特性，如模式匹配和枚举，这些特性也受到函数式风格的影响。因为掌握闭包和迭代器是编写高效、符合语言习惯的Rust代码的重要部分，我们将整章内容都用于介绍这些主题。
