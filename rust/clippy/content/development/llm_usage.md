# LLM 使用指南

Clippy 遵循与 `rust-lang/rust` 相同的 [LLM 使用政策]。在参与 `rust-lang/rust-clippy` 时使用 LLM 辅助服务前，请阅读该政策。

为便于理解，此政策包含 Clippy 采纳后所做的任何更新；我们的意图是在持续的基础上与当前政策保持一致。

在结合 Clippy 背景阅读政策时：

* 将 `rust-lang/rust` 读作 `rust-lang/rust-clippy`。 * 将批准团队视为 Clippy 团队。 * 将“诊断信息”理解为涵盖 Clippy 用户输出的整体概念。 * 忽略不适用于 Clippy 的部分，例如与编译器或语言相关的特定内容。 * 随着时间推移，Clippy 团队将更精确地定义“关键”领域的含义。我们期望采用 `rust-lang/rust` 所采用的任何工具来更精确地说明这一点。 * 如有疑问，Clippy 团队将提供所有与 Clippy 相关的政策解释，直到政策本身更新以包含 Clippy。

关于如何有效使用 LLM 以及如何审查 LLM 生成的 PR 的建议，请参阅 [rustc-dev-guide][llm-guidance]。

[LLM usage policy]: https://forge.rust-lang.org/policies/llm-usage.html
[llm-guidance]: https://rustc-dev-guide.rust-lang.org/llm-guidance.html
