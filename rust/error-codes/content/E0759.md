#### 注意：此错误代码不再由编译器生成。

涉及 trait 的返回类型不需要 `'static` 生命周期。

错误的代码示例：

```compile_fail
use std::fmt::Debug;

fn foo(x: &i32) -> impl Debug { // error!
    x
}

fn bar(x: &i32) -> Box<dyn Debug> { // error!
    Box::new(x)
}
```

添加 `'static` 要求以修复它们：

```
# use std::fmt::Debug;
fn foo(x: &'static i32) -> impl Debug + 'static { // ok!
    x
}

fn bar(x: &'static i32) -> Box<dyn Debug + 'static> { // ok!
    Box::new(x)
}
```

在返回类型的 [`dyn Trait`] 和 [`impl Trait`] 中都有隐式的 `'static` 要求，意味着被返回的实现这些 trait 的值必须是 `'static` 借用值或拥有值。

为了将要求从 `'static` 改为由其参数派生的生命周期，你可以添加显式边界，可以是匿名生命周期 `'_` 或某个合适的命名生命周期。

```
# use std::fmt::Debug;
fn foo(x: &i32) -> impl Debug + '_ {
    x
}
fn bar(x: &i32) -> Box<dyn Debug + '_> {
    Box::new(x)
}
```

这等同于以下显式的生命周期注解：

```
# use std::fmt::Debug;
fn foo<'a>(x: &'a i32) -> impl Debug + 'a {
    x
}
fn bar<'a>(x: &'a i32) -> Box<dyn Debug + 'a> {
    Box::new(x)
}
```

[`impl Trait`]: https://doc.rust-lang.org/book/ch10-02-traits.html#returning-types-that-implement-traits
