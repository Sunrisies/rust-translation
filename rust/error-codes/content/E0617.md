试图将无效类型的变量传递给变长参数函数。

错误的代码示例：

```compile_fail,E0617
# use std::os::raw::{c_char, c_int};
extern "C" {
    fn printf(format: *const c_char, ...) -> c_int;
}

unsafe {
    printf("%f\n\0".as_ptr() as _, 0f32);
    // error: cannot pass an `f32` to variadic function, cast to `c_double`
}
```

由于 C 标准规定的复杂的 ABI 规则，某些 Rust 类型在传递给变长参数函数之前必须进行转换。要解决此错误，需将值转换为错误信息中指定的类型（您可能需要从 `std::os::raw` 导入该类型）。

在这种情况下，`c_double` 与 `f64` 具有相同的大小，因此可以直接使用它：

```no_run
# use std::os::raw::{c_char, c_int};
# extern "C" {
#     fn printf(format: *const c_char, ...) -> c_int;
# }

unsafe {
    printf("%f\n\0".as_ptr() as _, 0f64); // ok!
}
```
