只有当前 crate 中定义的特质才能被用于任意类型。

错误的代码示例：

```compile_fail,E0117
impl Drop for u32 {}
```

此错误表明违反了 Rust 中关于特质实现的“孤儿规则”之一。该规则禁止对外部特质（在另一个 crate 中定义的特质）进行实现，其中

 - 实现该特质的类型是外部的 - 传递给该特质的所有参数（如果有的话）也是外部的。

为了避免此类错误，请确保至少有一个本地类型被 `impl` 引用：

```
pub struct Foo; // you define your type in your crate

impl Drop for Foo { // and you can implement the trait on it!
    // code of trait implementation here
#   fn drop(&mut self) { }
}

impl From<Foo> for i32 { // or you use a type from your crate as
                         // a type parameter
    fn from(i: Foo) -> i32 {
        0
    }
}
```

或者，在本地定义该特质并进行实现：

```
trait Bar {
    fn get(&self) -> usize;
}

impl Bar for u32 {
    fn get(&self) -> usize { 0 }
}
```

有关“孤儿规则”设计的更多信息，请参阅 [RFC 1023]。

[RFC 1023]: https://rust-lang.github.io/rfcs/1023-rebalancing-coherence.html
