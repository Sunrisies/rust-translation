一个用于 `#[marker]` 习性的 `impl` 试图覆盖一个关联项。

错误的代码示例：

```compile_fail,E0715
#![feature(marker_trait_attr)]

#[marker]
trait Marker {
    const N: usize = 0;
    fn do_something() {}
}

struct OverrideConst;
impl Marker for OverrideConst { // error!
    const N: usize = 1;
}
# fn main() {}
```

由于标记习性允许对同一类型有多种实现，因此不允许在这些实现中覆盖任何内容，因为无法明确应该使用哪个覆盖版本。
