在 `#[derive]` 中使用了字面值。

错误的代码示例：

```compile_fail,E0777
#[derive("Clone")] // error!
struct Foo;
```

在 `#[derive]` 中，仅允许传递对 trait 的引用作为参数。您可以在 [Rust 手册] 中找到关于 `#[derive]` 属性的更多信息。


```
#[derive(Clone)] // ok!
struct Foo;
```

[Rust Book]: https://doc.rust-lang.org/book/appendix-03-derivable-traits.html
