尝试了对包含内部可变性内容的常量进行借用。

错误的代码示例：

```compile_fail,E0492
use std::sync::atomic::AtomicUsize;

const A: AtomicUsize = AtomicUsize::new(0);
const B: &'static AtomicUsize = &A;
// error: cannot borrow a constant which may contain interior mutability,
//        create a static instead
```

`const` 表示永远不应改变的常量值。如果对一个常量取 `&` 引用，则相当于获取指向包含该值的内存位置的指针。通常这是完全可以的：大多数值无法通过共享的 `&` 指针进行更改，但内部可变性却允许这样做。也就是说，常量值可以被修改。另一方面，`static` 明确指的是一个单独的内存位置，可以随意被修改。

因此，要解决此错误，应使用实现 `Sync` 的静态类型：

```
use std::sync::atomic::AtomicUsize;

static A: AtomicUsize = AtomicUsize::new(0);
static B: &'static AtomicUsize = &A; // ok!
```

使用单元格类型时也会出现此错误：

```compile_fail,E0492
use std::cell::Cell;

const A: Cell<usize> = Cell::new(1);
const B: &Cell<usize> = &A;
// error: cannot borrow a constant which may contain interior mutability,
//        create a static instead

// or:
struct C { a: Cell<usize> }

const D: C = C { a: Cell::new(1) };
const E: &Cell<usize> = &D.a; // error

// or:
const F: &C = &D; // error
```

这是因为单元格类型执行的操作不是线程安全的。由于这一点，它们不实现 `Sync`，因此无法被归类为静态类型。

然而，如果您仍然希望使用这些类型，可以通过一个不安全包装器来实现：

```
use std::cell::Cell;

struct NotThreadSafe<T> {
    value: Cell<T>,
}

unsafe impl<T> Sync for NotThreadSafe<T> {}

static A: NotThreadSafe<usize> = NotThreadSafe { value : Cell::new(1) };
static B: &'static NotThreadSafe<usize> = &A; // ok!
```

请记住，这种解决方案是不安全的！您必须确保对单元格的访问是同步的。
