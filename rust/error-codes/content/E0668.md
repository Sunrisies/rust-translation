#### 注意：此错误代码已不再由编译器生成。

LLVM 拒绝了格式错误的内联汇编代码。

错误的代码示例：

```ignore (no longer emitted)
#![feature(llvm_asm)]

fn main() {
    let rax: u64;
    unsafe {
        llvm_asm!("" :"={rax"(rax));
        println!("Accumulator is: {}", rax);
    }
}
```

LLVM 会检查传递给它的约束条件及汇编字符串的有效性。此错误表明内联汇编调用存在问题。

特别是，如果忘记了寄存器约束的闭合括号（参见问题 #51430），如之前的代码示例所示，就可能出现这种情况。
