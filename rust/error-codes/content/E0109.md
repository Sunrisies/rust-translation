您试图向不需要该参数的类型提供通用参数。

错误的代码示例：

```compile_fail,E0109
type X = u32<i32>; // error: type arguments are not allowed for this type
type Y = bool<'static>; // error: lifetime parameters are not allowed on
                        //        this type
```

请确认您使用了正确的参数，并且定义正确。

Example:

```
type X = u32; // ok!
type Y = bool; // ok!
```

请注意，枚举变体构造器的通用参数应放在变体之后，而不是枚举之后。例如，您应该写 `Option::None::<u32>`，而不是 `Option::<u32>::None`。
