#### 注意：此错误代码不再由编译器生成。

`self` 导入在列表中出现了多次。

错误的代码示例：

```ignore (error is no longer emitted)
use something::{self, self}; // error: `self` import can only appear once in
                             //        the list
```

请确认你没有拼错导入名称，或者删除了重复的 `self` 导入。示例：

```
# mod something {}
# fn main() {
use something::{self}; // ok!
# }
```
