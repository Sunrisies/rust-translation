编译器无法推断类型，因此要求添加类型注解。

错误的代码示例：

```compile_fail,E0282
let x = Vec::new();
```

此错误表明类型推理未能得出唯一的可能类型，需要额外的信息。通常可以通过添加类型注解来提供这些信息。有时则需要手动指定泛型类型参数。

在上面的示例中，类型 `Vec` 有一个类型参数 `T`。当调用 `Vec::new` 时，除非后续使用变量 `x` 使编译器能够推断出 `T` 的类型，否则编译器需要知道具体的类型。

可以在变量上指定类型：

```
let x: Vec<i32> = Vec::new();
```

也可以在表达式的路径中指定类型：

```
let x = Vec::<i32>::new();
```

对于更复杂的类型，无需标注完整的类型。一旦歧义得到解决，编译器就可以推断其余部分。

```
let x: Vec<_> = "hello".chars().rev().collect();
```

另一种向编译器提供足够信息的方式是指定泛型类型参数：

```
let x = "hello".chars().rev().collect::<Vec<char>>();
```

同样，如果编译器能够推断出完整类型，则无需指定。

```
let x = "hello".chars().rev().collect::<Vec<_>>();
```

除了具有泛型类型参数的方法或函数外，当结构体或 trait 的类型参数无法被推断时也会出现此错误。在这种情况下，通常无法使用类型注解，因为所有候选类型都具有相同的返回类型。例如：

```compile_fail,E0282
struct Foo<T> {
    num: T,
}

impl<T> Foo<T> {
    fn bar() -> i32 {
        0
    }

    fn baz() {
        let number = Foo::bar();
    }
}
```

这将失败，因为编译器不知道应该调用 `bar` 的 `Foo` 的哪个实例。将 `Foo::bar()` 改为 `Foo::<T>::bar()` 可以解决此错误。
