#### 注意：此错误代码不再由编译器生成。

在非项目声明语句之后，例如变量声明和表达式语句之后，不允许使用导入（`use` 语句）。

以下示例展示了该错误：

```
fn f() {
    // Variable declaration before import
    let x = 0;
    use std::io::Read;
    // ...
}
```

解决方案是在块、函数或文件的顶部声明导入。

以下是正确顺序的先前示例：

```
fn f() {
    use std::io::Read;
    let x = 0;
    // ...
}
```

有关项目声明的定义及不视为项目声明的内容，请参阅参考手册中的 [Declaration Statements][declaration-statements] 部分。

[declaration-statements]: https://doc.rust-lang.org/reference/statements.html#declaration-statements
