某个值从非可复制固定大小数组中被移动了。

错误的代码示例：

```compile_fail,E0508
struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    let _value = array[0]; // error: cannot move out of type `[NonCopy; 1]`,
                           //        a non-copy fixed-size array
}
```

第一个元素被从数组中移出了，但这是不可能的，因为 `NonCopy` 没有实现 `Copy` trait。

考虑通过借用元素而不是将其移动：

```
struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    let _value = &array[0]; // Borrowing is allowed, unlike moving.
}
```

或者，如果您的类型实现了 `Clone`，并且您需要拥有该值，可以考虑先借用再克隆：

```
#[derive(Clone)]
struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    // Now you can clone the array element.
    let _value = array[0].clone();
}
```

如果您确实想要将值移出，可以使用解构数组模式来移动它：

```
struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    // Destructuring the array
    let [_value] = array;
}
```
