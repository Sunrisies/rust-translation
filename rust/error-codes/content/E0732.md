具有判别度的 `enum` 必须指定 `#[repr(inttype)]`。

错误的代码示例：

```compile_fail,E0732
enum Enum { // error!
    Unit = 1,
    Tuple() = 2,
    Struct{} = 3,
}
# fn main() {}
```

如果 `enum` 存在具有判别度的非单位变体，或者同时有具有判别度的单位变体和非单位变体，`enum` 上必须提供 `#[repr(inttype)]`。这一限制确保可以从值中明确提取变体的判别度；例如：

```
#[repr(u8)]
enum Enum {
    Unit = 3,
    Tuple(u16) = 2,
    Struct {
        a: u8,
        b: u16,
    } = 1,
}

fn discriminant(v : &Enum) -> u8 {
    unsafe { *(v as *const Enum as *const u8) }
}

fn main() {
    assert_eq!(3, discriminant(&Enum::Unit));
    assert_eq!(2, discriminant(&Enum::Tuple(5)));
    assert_eq!(1, discriminant(&Enum::Struct{a: 7, b: 11}));
}
```
