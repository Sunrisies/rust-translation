一种特质类型已被解引用。

错误的代码示例：

```compile_fail,E0033
# trait SomeTrait { fn method_one(&self){} fn method_two(&self){} }
# impl<T> SomeTrait for T {}
let trait_obj: &SomeTrait = &"some_value";

// This tries to implicitly dereference to create an unsized local variable.
let &invalid = trait_obj;

// You can call methods without binding to the value being pointed at.
trait_obj.method_one();
trait_obj.method_two();
```

指向特质类型的指针无法被模式隐式解引用。每个特质都定义了一种类型，但由于实现者的数量不固定，该类型没有编译时的大小。因此，对特质类型的所有访问必须通过指针进行。如果遇到此错误，应尽量避免解引用指针。

您可以在参考资料的 [trait Objects] 部分了解更多关于特质对象的信息。
