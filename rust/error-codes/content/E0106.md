此错误表明某个类型缺少生命周期。如果这是函数签名中的错误，则可能是没有遵守生命周期省略规则（见下文）。

错误的代码示例：

```compile_fail,E0106
struct Foo1 { x: &bool }
              // ^ expected lifetime parameter
struct Foo2<'a> { x: &'a bool } // correct

struct Bar1 { x: Foo2 }
              // ^^^^ expected lifetime parameter
struct Bar2<'a> { x: Foo2<'a> } // correct

enum Baz1 { A(u8), B(&bool), }
                  // ^ expected lifetime parameter
enum Baz2<'a> { A(u8), B(&'a bool), } // correct

type MyStr1 = &str;
           // ^ expected lifetime parameter
type MyStr2<'a> = &'a str; // correct
```

生命周期省略是函数签名中生命周期的一种特殊且有限的推理机制，它允许在某些情况下省略生命周期。关于生命周期省略的更多背景信息，请参阅[这本书][book-le]。

生命周期省略规则要求任何具有被省略输出生命周期的函数签名必须满足以下条件之一：

 - 恰好有一个输入生命周期——或者多个输入生命周期，但该函数必须是带有 `&self` 或 `&mut self` 接收器的方法。

在第一种情况下，输出生命周期被推断为与唯一的输入生命周期相同。在第二种情况下，生命周期则被推断为与 `&self` 或 `&mut self` 上的生命周期相同。

以下是一些省略错误的示例：

```compile_fail,E0106
// error, no input lifetimes
fn foo() -> &str { }

// error, `x` and `y` have distinct lifetimes inferred
fn bar(x: &str, y: &str) -> &str { }

// error, `y`'s lifetime is inferred to be distinct from `x`'s
fn baz<'a>(x: &'a str, y: &str) -> &str { }
```
