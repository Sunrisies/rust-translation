向内禀函数传递了无效的泛型参数数量。

错误的代码示例：

```compile_fail,E0094
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
fn size_of<T, U>() -> usize; // error: intrinsic has wrong number
                             //        of type parameters
```

请检查是否提供了正确的类型参数数量，并对照 Rust 源代码中函数的声明进行验证。示例：

```
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
fn size_of<T>() -> usize; // ok!
```
