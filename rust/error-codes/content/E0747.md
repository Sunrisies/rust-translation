通用参数没有按照对应通用参数的声明顺序提供，或者在预期为常量时提供了类型。

错误的代码示例：

```compile_fail,E0747
struct S<'a, T>(&'a T);

type X = S<(), 'static>; // error: the type argument is provided before the
                         // lifetime argument
```

参数顺序应改为与参数声明顺序一致，如下所示：

```
struct S<'a, T>(&'a T);

type X = S<'static, ()>; // ok
```

另一个错误的代码示例：

```compile_fail,E0747
struct Foo<const N: usize>;

fn foo() -> Foo<usize> {} // error: type provided when a constant was
                          // expected
```

当声明常量通用参数时，必须提供常量表达式，而不是类型，如下所示：

```
struct Foo<const N: usize>;

fn foo() -> Foo<3> { Foo }
```
