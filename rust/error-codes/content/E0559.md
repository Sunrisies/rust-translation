在枚举的结构变体中指定了一个未知字段。

错误的代码示例：

```compile_fail,E0559
enum Field {
    Fool { x: u32 },
}

let s = Field::Fool { joke: 0 };
// error: struct variant `Field::Fool` has no field named `joke`
```

请确认你没有拼错字段名称或该字段确实存在。示例：

```
enum Field {
    Fool { joke: u32 },
}

let s = Field::Fool { joke: 0 }; // ok!
```
