一个不可变变量被重新赋值了。

错误的代码示例：

```compile_fail,E0384
fn main() {
    let x = 3;
    x = 5; // error, reassignment of immutable variable
}
```

默认情况下，Rust 中的变量是不可变的。要修正此错误，在声明变量时，在 `let` 关键字后添加 `mut` 关键字。例如：

```
fn main() {
    let mut x = 3;
    x = 5;
}
```

或者，你可以考虑初始化一个新的变量：要么使用新的绑定名称，要么（通过[遮蔽]）使用现有变量的绑定名称。例如：


```
fn main() {
    let x = 3;
    let x = 5;
}
```

[shadowing]: https://doc.rust-lang.org/book/ch03-01-variables-and-mutability.html#shadowing
