为某个特质定义的一个相关函数是一个方法（即接受 `self` 参数），但该特质的实现声明该方法是静态的。

错误的代码示例：

```compile_fail,E0186
trait Foo {
    fn foo(&self);
}

struct Bar;

impl Foo for Bar {
    // error, method `foo` has a `&self` declaration in the trait, but not in
    // the impl
    fn foo() {}
}
```

当一个类型实现了特质的相关函数时，必须使用相同的签名。因此在这种情况下，由于 `Foo::foo` 接受 `self` 作为参数且不返回任何值，其在 `Bar` 上的实现也应该是相同的：

```
trait Foo {
    fn foo(&self);
}

struct Bar;

impl Foo for Bar {
    fn foo(&self) {} // ok!
}
```
