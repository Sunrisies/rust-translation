私有模块不能被公开重新导出。此错误表明您试图对并非公开的模块执行 `pub use` 操作。

错误的代码示例：

```compile_fail,E0365
mod foo {
    pub const X: u32 = 1;
}

pub use foo as foo2;

fn main() {}
```

解决此问题的方法是确保您重新导出的模块本身带有 `pub` 标记：

```
pub mod foo {
    pub const X: u32 = 1;
}

pub use foo as foo2;

fn main() {}
```

有关此主题的更多信息，请参阅参考手册中的 [Use Declarations][use-declarations] 部分。
