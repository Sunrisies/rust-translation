#### 注意：此错误代码不再由编译器生成

您实现了某个特质，并覆盖了其一个或多个关联类型，但并未重新实现其默认方法。

错误代码示例：

```
#![feature(associated_type_defaults)]

pub trait Foo {
    type Assoc = u8;
    fn bar(&self) {}
}

impl Foo for i32 {
    // error - the following trait items need to be reimplemented as
    //         `Assoc` was overridden: `bar`
    type Assoc = i32;
}
```

要解决此问题，需为该特质中的每个默认方法添加相应的实现：

```
#![feature(associated_type_defaults)]

pub trait Foo {
    type Assoc = u8;
    fn bar(&self) {}
}

impl Foo for i32 {
    type Assoc = i32;
    fn bar(&self) {} // ok!
}
```
