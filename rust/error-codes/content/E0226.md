在 trait 对象上使用了多个显式的生命周期限制。

错误代码示例：

```compile_fail,E0226
trait Foo {}

type T<'a, 'b> = dyn Foo + 'a + 'b; // error: Trait object `arg` has two
                                    //        lifetime bound, 'a and 'b.
```

在这里，`T` 是一个具有两个显式生命周期限制的 trait 对象，分别为 'a 和 'b。

在 trait 对象上只允许使用一个显式的生命周期限制。要修复此错误，请移除其中一个生命周期限制。

```
trait Foo {}

type T<'a> = dyn Foo + 'a;
```
