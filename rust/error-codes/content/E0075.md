已将 `#[simd]` 属性应用于空结构或多字段结构。

错误的代码示例：

```compile_fail,E0075
#![feature(repr_simd)]

#[repr(simd)]
struct Bad; // error!
```

```compile_fail,E0075
#![feature(repr_simd)]

#[repr(simd)]
struct Bad([u32; 1], [u32; 1]); // error!
```

`#[simd]` 属性只能应用于单字段结构，因为该字段必须是向量中的值数组。

修复后的示例：

```
#![feature(repr_simd)]

#[repr(simd)]
struct Good([u32; 2]); // ok!
```
