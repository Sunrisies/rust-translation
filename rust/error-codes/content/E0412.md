#### 注意：此错误代码不再由编译器生成。

错误的代码示例：

```compile_fail,E0425
impl Something {} // error: type name `Something` is not in scope

// or:

trait Foo {
    fn bar(N); // error: type name `N` is not in scope
}

// or:

fn foo(x: T) {} // type name `T` is not in scope
```

要解决此错误，请确认您没有拼错类型名称，或者已声明该类型或将其导入到作用域中。示例如下：

```
struct Something;

impl Something {} // ok!

// or:

trait Foo {
    type N;

    fn bar(_: Self::N); // ok!
}

// or:

fn foo<T>(x: T) {} // ok!
```

导致此错误的另一种情况是当某个类型被导入到父模块中时。要解决这个问题，您可以按照建议直接使用 `File` 类型，或者使用 `use super::File;`，这样就能从父命名空间导入该类型。下面是一个引发此错误的示例：

```compile_fail,E0425
use std::fs::File;

mod foo {
    fn some_function(f: File) {}
}
```

```
use std::fs::File;

mod foo {
    // either
    use super::File;
    // or
    // use std::fs::File;
    fn foo(f: File) {}
}
# fn main() {} // don't insert it for us; that'll break imports
```
