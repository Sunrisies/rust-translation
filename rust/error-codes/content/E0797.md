使用了无基础表达式的结构体更新语法。

错误的代码示例：

```compile_fail,E0797
struct Foo {
    fizz: u8,
    buzz: u8
}

let f1 = Foo { fizz: 10, buzz: 1};
let f2 = Foo { fizz: 10, .. }; // error
```

使用结构体更新语法时需要有一个“基础表达式”，该表达式将用于填充剩余的字段。

```
struct Foo {
    fizz: u8,
    buzz: u8
}

let f1 = Foo { fizz: 10, buzz: 1};
let f2 = Foo { fizz: 10, ..f1 };
```
