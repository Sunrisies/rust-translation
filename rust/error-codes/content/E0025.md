在模式中，结构体的每个字段只能绑定一次。

错误的代码示例：

```compile_fail,E0025
struct Foo {
    a: u8,
    b: u8,
}

fn main(){
    let x = Foo { a:1, b:2 };

    let Foo { a: x, a: y } = x;
    // error: field `a` bound multiple times in the pattern
}
```

字段名称的每次出现都会绑定该字段的值，因此要修复此错误，必须删除或修改对字段名称的重复使用。或许您误拼了另一个字段名称？例如：

```
struct Foo {
    a: u8,
    b: u8,
}

fn main(){
    let x = Foo { a:1, b:2 };

    let Foo { a: x, b: y } = x; // ok!
}
```
