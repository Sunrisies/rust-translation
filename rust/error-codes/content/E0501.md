使用了可变变量，但该变量已经被闭包捕获了。

错误的代码示例：

```compile_fail,E0501
fn inside_closure(x: &mut i32) {
    // Actions which require unique access
}

fn outside_closure(x: &mut i32) {
    // Actions which require unique access
}

fn foo(a: &mut i32) {
    let mut bar = || {
        inside_closure(a)
    };
    outside_closure(a); // error: cannot borrow `*a` as mutable because previous
                        //        closure requires unique access.
    bar();
}
```

此错误表明在闭包仍然捕获该变量时使用了可变变量。由于闭包已经借用了该变量，因此直到闭包超出作用域之前都无法使用该变量。

请注意，捕获操作会移动或借用变量，但在这种情况下，是闭包在借用该变量。有关更多信息，请参阅《Rust 示例：[捕获]》一章。


要解决此错误，可以在使用被捕获的变量之前结束闭包的使用：

```
fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    let mut bar = || {
        inside_closure(a)
    };
    bar();
    // borrow on `a` ends.
    outside_closure(a); // ok!
}
```

或者可以将该变量作为参数传递给闭包：

```
fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    let mut bar = |s: &mut i32| {
        inside_closure(s)
    };
    outside_closure(a);
    bar(a);
}
```

也可能在之后定义该闭包：

```
fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    outside_closure(a);
    let mut bar = || {
        inside_closure(a)
    };
    bar();
}
```
