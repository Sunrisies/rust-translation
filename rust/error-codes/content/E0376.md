#### 注意：此错误代码不再由编译器生成。

`CoerceUnsized`或`DispatchFromDyn`是在非结构体类型之间实现的。

错误的代码示例：

```compile_fail,E0377
#![feature(coerce_unsized)]
use std::ops::CoerceUnsized;

struct Foo<T: ?Sized> {
    a: T,
}

// error: The type `U` is not a struct
impl<T, U> CoerceUnsized<U> for Foo<T> {}
```

`CoerceUnsized`或`DispatchFromDyn`只能在非结构体类型之间实现。
