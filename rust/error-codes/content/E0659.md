项目使用方式存在歧义。

错误的代码示例：

```compile_fail,edition2018,E0659
pub mod moon {
    pub fn foo() {}
}

pub mod earth {
    pub fn foo() {}
}

mod collider {
    pub use crate::moon::*;
    pub use crate::earth::*;
}

fn main() {
    crate::collider::foo(); // ERROR: `foo` is ambiguous
}
```

当两个同名项被导入到同一个模块时，通常会出现此错误。在此示例中，`foo`函数从`collider`模块被导入并重新导出，因此当我们使用`collider::foo()`时，这两个函数会发生冲突。

解决此错误的最佳方法通常是在使用该项目时保留其路径。示例：

```edition2018
pub mod moon {
    pub fn foo() {}
}

pub mod earth {
    pub fn foo() {}
}

mod collider {
    pub use crate::moon;
    pub use crate::earth;
}

fn main() {
    crate::collider::moon::foo(); // ok!
    crate::collider::earth::foo(); // ok!
}
```
