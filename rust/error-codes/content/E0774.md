`derive` 被应用于并非结构体、联合类型或枚举的类型。

错误的代码示例：

```compile_fail,E0774
trait Foo {
    #[derive(Clone)] // error!
    type Bar;
}
```

如上所述，`derive` 属性仅允许用于结构体、联合类型或枚举：

```
#[derive(Clone)] // ok!
struct Bar {
    field: u32,
}
```

您可以在 [Rust Book] 中找到关于 `derive` 的更多信息。
