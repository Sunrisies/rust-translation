某个类型或生命周期参数已被声明，但实际上并未被使用。

错误的代码示例：

```compile_fail,E0392
enum Foo<T> {
    Bar,
}
```

如果类型参数被误加，可以通过删除该类型参数来修复此错误，如下所示：

```
enum Foo {
    Bar,
}
```

或者，如果类型参数是故意插入的，则必须实际使用它。以下是一个简单的修复方法：

```
enum Foo<T> {
    Bar(T),
}
```

在处理不安全代码时，也常会出现此错误。例如，使用原始指针时，可能需要指定指向数据有效的生命周期。最初的尝试（如下）会导致此错误：

```compile_fail,E0392
struct Foo<'a, T> {
    x: *const T,
}
```

我们希望表达这样的约束：Foo 不应超过 `'a` 的生命周期，因为 `T` 所指向的数据仅在该生命周期内有效。问题在于实际上没有对 `'a' 的使用。可以通过在结构体中添加 PhantomData 类型来绕过这个问题，利用它让编译器认为该结构体包含一个借用的引用 `&'a T`：

```
use std::marker::PhantomData;

struct Foo<'a, T: 'a> {
    x: *const T,
    phantom: PhantomData<&'a T>
}
```

[PhantomData] 也可以用来表达关于未使用类型参数的信息。

[PhantomData]: https://doc.rust-lang.org/std/marker/struct.PhantomData.html
