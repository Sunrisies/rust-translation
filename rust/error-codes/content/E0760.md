#### 注意：此错误代码已不再由编译器生成。

`async fn`/`impl trait` 的返回类型不能包含投影或 `Self`，而 `Self` 引用了来自父作用域的生命周期。

错误的代码示例：

```ignore,edition2018
struct S<'a>(&'a i32);

impl<'a> S<'a> {
    async fn new(i: &'a i32) -> Self {
        S(&22)
    }
}
```

为了修复此错误，需要将 `Self` 明确写为 `S<'a>`：

```edition2018
struct S<'a>(&'a i32);

impl<'a> S<'a> {
    async fn new(i: &'a i32) -> S<'a> {
        S(&22)
    }
}
```

未来某时会允许这种写法，但当前实现尚未完成。关于此限制，请参见 [issue-61949]。

[issue-61949]: https://github.com/rust-lang/rust/issues/61949
