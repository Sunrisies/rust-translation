`+` 类型运算符在模糊的语境中被使用。

错误的代码示例：

```compile_fail,E0178
trait Foo {}

struct Bar<'a> {
    x: &'a Foo + 'a,     // error!
    y: &'a mut Foo + 'a, // error!
    z: fn() -> Foo + 'a, // error!
}
```

在类型中，`+` 类型运算符的优先级较低，因此通常需要使用括号：

```
trait Foo {}

struct Bar<'a> {
    x: &'a (Foo + 'a),     // ok!
    y: &'a mut (Foo + 'a), // ok!
    z: fn() -> (Foo + 'a), // ok!
}
```

更多细节可参见 [RFC 438]。

[RFC 438]: https://github.com/rust-lang/rfcs/pull/438
