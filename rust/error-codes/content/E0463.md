声明了一个 crate，但无法找到它。

错误的代码示例：

```compile_fail,E0463
extern crate foo; // error: can't find crate
```

你需要将代码链接到相关的 crate 中才能使用它（例如通过 Cargo 或 rustc 的 `-L` 选项）。

## 常见原因

- 该 crate 根本不存在。如果使用 Cargo，请在 Cargo.toml 中的 `[dependencies]` 中添加它。 - 该 crate 存在，但名称不同。如果使用 Cargo，请查看 Cargo.toml 中 `[dependencies]` 下的 `package =`。

## `std` 或 `core` 缺失的常见原因

- 你正在为没有预编译的 `std` 的目标进行交叉编译。可以考虑以下方法： + 使用 `rustup target add` 添加预编译的 std 版本。 + 使用 `cargo build -Z build-std` 从源代码构建 std。 + 在 crate 根处使用 `#![no_std]`，这样就不需要 `std` 了。 - 你正在开发编译器本身，且尚未从源代码构建 libstd。通常可以使用 `x.py build library/std` 来构建它。关于 x.py 的更多信息可在 [rustc-dev-guide] 中查找。
