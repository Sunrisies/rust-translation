#### 注意：此错误代码已不再由编译器生成。

该错误表明在 match 分支中的绑定需要将一个值移动到多个位置，从而违反唯一所有权原则。如下代码是无效的，因为它要求将整个 `Option<String>` 移动到名为 `op_string` 的变量中，同时要求将内部的 `String` 移动到名为 `s` 的变量中。

错误的代码示例：

```compile_fail,E0382
#![feature(bindings_after_at)]

let x = Some("s".to_string());

match x {
    op_string @ Some(s) => {}, // error: use of moved value
    None => {},
}
```

另请参阅错误 E0303。
