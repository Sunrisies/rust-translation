使用了非结构匹配类型作为常量泛型参数的类型。

错误的代码示例：

```compile_fail,E0741
#![feature(adt_const_params)]

struct A;

struct B<const X: A>; // error!
```

只有结构匹配类型才能被用作常量泛型参数的类型，这些类型必须派生自 `PartialEq`、`Eq` 并实现 `ConstParamTy`。

为了修复之前的代码示例，我们需要派生出 `PartialEq`、`Eq` 和 `ConstParamTy`。

```
#![feature(adt_const_params)]

use std::marker::ConstParamTy;

#[derive(PartialEq, Eq, ConstParamTy)] // We derive both traits here.
struct A;

struct B<const X: A>; // ok!
```
