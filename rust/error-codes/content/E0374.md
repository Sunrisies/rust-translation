在不包含可未指定大小字段的结构上实现了 `CoerceUnsized` 或 `DispatchFromDyn`。

错误代码示例：

```compile_fail,E0374
#![feature(coerce_unsized)]
use std::ops::CoerceUnsized;

struct Foo<T: ?Sized> {
    a: i32,
}

// error: Struct `Foo` has no unsized fields that need to be coerced.
impl<T, U> CoerceUnsized<Foo<U>> for Foo<T>
    where T: CoerceUnsized<U> {}
```

`CoerceUnsized` 用于将具有可未指定大小字段的结构进行转换，例如将自定义 `MyBox<T>` 转换为 `MyBox<dyn Trait>`。而 `DispatchFromDyn` 则用于在与动态类型兼容的 trait 中，从 `MyBox<dyn Trait>` 调用到 `MyBox<Self>`。

如果结构没有任何可未指定大小类型的字段，那么就没有有效的方法来实现 `CoerceUnsized` 或 `DispatchFromDyn`，因为不存在任何转换操作。

请注意，`CoerceUnsized` 和 `DispatchFromDyn` 主要被智能指针如 `Box`、`Rc` 和 `Arc` 使用，以便标记它们能够转换其所指向的可未指定大小类型。
