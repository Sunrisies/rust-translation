#### 注意：此错误代码不再由编译器生成。

在 Rust 1.3 中，默认对象生命周期限制预计会发生变化，如 [RFC 1156] 所述。您收到警告是因为编译器认为这种变化可能导致您的代码出现编译错误。虽然不太可能，但这可能是误报。

这一变化的核心在于，`&'a Box<SomeTrait>` 的默认值从 `&'a Box<SomeTrait+'a>` 变为 `&'a Box<SomeTrait+'static>`（此处 `SomeTrait` 是某种特质类型的名称）。请注意，只有指向盒子的引用类型受到影响，例如 `&Box<SomeTrait>` 或 `&[Box<SomeTrait>]`。更常见的类型如 `&SomeTrait` 或 `Box<SomeTrait>` 则不受影响。

要消除此警告，请修改代码以使用明确的生命周期限制。大多数情况下，这意味着您需要更改正在调用的函数的签名。例如，如果错误是在类似 `foo(x)` 的调用中报告的，且 `foo` 的定义如下：

```
# trait SomeTrait {}
fn foo(arg: &Box<SomeTrait>) { /* ... */ }
```

您可以将其改为：

```
# trait SomeTrait {}
fn foo<'a>(arg: &'a Box<SomeTrait+'a>) { /* ... */ }
```

这明确表明您期望特质对象 `SomeTrait` 包含引用（其最大生命周期为 `'a'`）。

[RFC 1156]: https://rust-lang.github.io/rfcs/1156-adjust-default-object-bounds.html
