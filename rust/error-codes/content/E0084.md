在零变体枚举上尝试了不支持的表示方式。

错误的代码示例：

```compile_fail,E0084
#[repr(i32)]
enum NightsWatch {} // error: unsupported representation for zero-variant enum
```

由于不存在零变体枚举值，因此无法定义用于表示零变体枚举值的整数类型。无法通过安全代码构造该类型的实例。因此有两种解决方案：要么在枚举中添加变体；要么移除枚举的整数表示形式。

```
#[repr(i32)]
enum NightsWatch {
    JonSnow,
    Commander,
}
```

或者移除枚举的整数表示方式：

```
enum NightsWatch {}
```
