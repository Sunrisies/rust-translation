不支持的裸函数定义。

错误的代码示例：

```compile_fail,E0787
#[unsafe(naked)]
pub extern "C" fn f() -> u32 {
    42
}
```

裸函数必须使用单个 `naked_asm!` 汇编块来定义。

执行过程绝不能超出汇编代码的末尾，因此必须返回或中断。汇编块可以使用 `att_syntax` 和 `raw` 选项，但其他选项是不允许的。

汇编块中不得包含除 `const` 和 `sym` 之外的任何操作数。
