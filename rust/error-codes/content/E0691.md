#### 注意：此错误代码已不再由编译器生成。

具有 `repr(transparent)` 表示提示的结构体、枚举或联合包含了一个零大小字段，该字段需要非平凡的对齐方式。

错误的代码示例：

```ignore (error is no longer emitted)
#![feature(repr_align)]

#[repr(align(32))]
struct ForceAlign32;

#[repr(transparent)]
struct Wrapper(f32, ForceAlign32); // error: zero-sized field in transparent
                                   //        struct has alignment of 32, which
                                   //        is larger than 1
```

透明结构体、枚举或联合应像其包含的数据一样被表示。具有不同对齐要求的零大小字段可能会破坏这一特性。在上面的示例中，`Wrapper` 必须对齐到 32 字节，即使 `f32` 的对齐要求更严格。

考虑移除过度对齐的零大小字段：

```
#[repr(transparent)]
struct Wrapper(f32);
```

或者，`PhantomData<T>` 对所有 `T` 类型都有对齐数为 1，因此如果出于某种原因需要保留该字段，可以使用它：

```
#![feature(repr_align)]

use std::marker::PhantomData;

#[repr(align(32))]
struct ForceAlign32;

#[repr(transparent)]
struct Wrapper(f32, PhantomData<ForceAlign32>);
```

请注意，空数组 `[T; 0]` 的对齐要求与元素类型 `T` 相同。此外，即使零大小类型的对齐小于数据字段的对齐，错误也会被保守地报告。
