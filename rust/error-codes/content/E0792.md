类型别名 实现 trait 只有在完全泛化（并在其定义范围内）的情况下才能被赋予其隐藏类型。这意味着

```compile_fail,E0792
#![feature(type_alias_impl_trait)]

type Foo<T> = impl std::fmt::Debug;

#[define_opaque(Foo)]
fn foo() -> Foo<u32> {
    5u32
}
```

是不被接受的。如果接受这种形式，就会产生如

```compile_fail,E0792
#![feature(type_alias_impl_trait)]

type Foo<T> = impl Default;

#[define_opaque(Foo)]
fn foo() -> Foo<u32> {
    5u32
}

fn main() {
    let x = Foo::<&'static mut String>::default();
}
```


这样的不合理情况。因此，你需要将函数改为泛型：

```
#![feature(type_alias_impl_trait)]

type Foo<T> = impl std::fmt::Debug;

#[define_opaque(Foo)]
fn foo<U>() -> Foo<U> {
    5u32
}

fn main() {}
```

这意味着无论 `foo` 的泛型参数是什么，隐藏类型始终为 `u32`。如果你希望将泛型参数与隐藏类型关联起来，也可以这样做：


```
#![feature(type_alias_impl_trait)]

use std::fmt::Debug;

type Foo<T: Debug> = impl Debug;

#[define_opaque(Foo)]
fn foo<U: Debug>() -> Foo<U> {
    Vec::<U>::new()
}

fn main() {}
```
