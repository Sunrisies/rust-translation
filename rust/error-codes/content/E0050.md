对Trait方法的实现使用了错误的函数参数数量。

错误代码示例：

```compile_fail,E0050
trait Foo {
    fn foo(&self, x: u8) -> bool;
}

struct Bar;

// error: method `foo` has 1 parameter but the declaration in trait `Foo::foo`
// has 2
impl Foo for Bar {
    fn foo(&self) -> bool { true }
}
```

例如，`Foo` Trait有一个带有两个函数参数（`&self`和`u8`）的`foo`方法，但`Bar`类型对`foo`的实现却省略了`u8`参数。要修复此错误，这两个方法的参数必须相同：

```
trait Foo {
    fn foo(&self, x: u8) -> bool;
}

struct Bar;

impl Foo for Bar {
    fn foo(&self, x: u8) -> bool { // ok!
        true
    }
}
```
