一个 `if` 表达式缺少 `else` 块。

错误的代码示例：

```compile_fail,E0317
let x = 5;
let a = if x == 5 {
    1
};
```

当没有 `else` 块的 `if` 表达式被用于预期为 `()` 之外的类型时，就会出现此错误。在之前的代码示例中，`let` 表达式期望一个值，但由于没有 `else`，因此没有返回任何值。

没有 `else` 块的 `if` 表达式的类型为 `()`，因此这是一个类型错误。要解决这个问题，需要添加一个与 `if` 块具有相同类型的 `else` 块。

因此，要修复之前的代码示例：

```
let x = 5;
let a = if x == 5 {
    1
} else {
    2
};
```
