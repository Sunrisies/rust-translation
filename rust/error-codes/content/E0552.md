#### 注意：此错误代码已不再由编译器发出。该错误代码已被`E0539`取代。

使用了未识别的表示属性。

错误的代码示例：

```compile_fail
#[repr(D)] // error: unrecognized representation hint
struct MyStruct {
    my_field: usize
}
```

你可以使用`repr`属性来告诉编译器你希望结构体或枚举在内存中的布局方式。

请确保你使用了支持的选项之一：

```
#[repr(C)] // ok!
struct MyStruct {
    my_field: usize
}
```

关于指定表示的更多信息，请参阅Rustonomicon中的["替代表示"章节]。

["Alternative Representations" section]: https://doc.rust-lang.org/nomicon/other-reprs.html
