某个标识符被用作函数名，或者期望一个值但该标识符存在，但它属于不同的命名空间。

错误的代码示例：

```compile_fail,E0423
struct Foo { a: bool };

let f = Foo();
// error: expected function, tuple struct or tuple variant, found `Foo`
// `Foo` is a struct name, but this expression uses it like a function name
```

请确认您没有拼错实际要使用的名称。例如：

```
fn Foo() -> u32 { 0 }

let f = Foo(); // ok!
```

在宏调用时常常忘记最后的 `!` 符号，这也会引发此错误：

```compile_fail,E0423
println("");
// error: expected function, tuple struct or tuple variant,
// found macro `println`
// did you mean `println!(...)`? (notice the trailing `!`)
```

另一种出现此错误的情况是当期望一个值，却发现了其他内容：

```compile_fail,E0423
pub mod a {
    pub const I: i32 = 1;
}

fn h1() -> i32 {
    a.I
    //~^ ERROR expected value, found module `a`
    // did you mean `a::I`?
}
```

### 用作值的枚举类型

枚举属于类型，不能直接作为值使用。

```compile_fail,E0423
fn main(){
    let x = Option::<i32>;
    //~^ ERROR expected value,found enum `Option`
}
```
