某个项目声明名称与外部 crate 的名称冲突。

错误的代码示例：

```compile_fail,E0260
extern crate core;

struct core;

fn main() {}
```

有两种可能的解决方案：

方案 #1：重命名该项目。

```
extern crate core;

struct xyz;
```

方案 #2：使用不同的名称导入该 crate。

```
extern crate core as xyz;

struct abc;
```

有关什么是有效的项目声明以及什么不是的更多信息，请参阅参考手册中的 [Declaration Statements][declaration-statements] 部分。

[declaration-statements]: https://doc.rust-lang.org/reference/statements.html#declaration-statements
