#### 注意：此错误代码不再由编译器生成

这是因为该错误代码对 `optimize` 属性过于具体。其他属性也会出现类似的诊断信息。此时示例将输出 `E0539`

`optimize` 属性存在格式错误。

错误的代码示例：

```compile_fail,E0539
#![feature(optimize_attribute)]

#[optimize(something)] // error: invalid argument
pub fn something() {}
```

`#[optimize]` 属性应如下使用：

- `#[optimize(size)]` -- 指示优化流程生成更小的代码而非更快的代码

- `#[optimize(speed)]` -- 指示优化流程生成更快的代码而非更小的代码

例如：

```
#![feature(optimize_attribute)]

#[optimize(size)]
pub fn something() {}
```

更多细节请参见 [RFC 2412]。
