对一种模糊的数字类型调用了方法。

错误的代码示例：

```compile_fail,E0689
2.0.neg(); // error!
```

此错误表明所传递的方法的数值存在，但该数值的类型或绑定无法被识别。

当数字字面量及没有具体类型标识的数字绑定出现时，就会引发此错误：

```compile_fail,E0689
let x = 2.0;
x.neg();  // same error as above
```

因此，你必须为数字字面量或绑定指定一个类型。

```
use std::ops::Neg;

let _ = 2.0_f32.neg(); // ok!
let x: f32 = 2.0;
let _ = x.neg(); // ok!
let _ = (2.0 as f32).neg(); // ok!
```
