#### 注意：此错误代码已不再由编译器生成

某个元素上使用了多个 `deprecated` 属性。

错误的代码示例：

```compile_fail
#[deprecated(note = "because why not?")]
#[deprecated(note = "right?")] // error!
fn the_banished() {}
```

`deprecated` 属性在某个元素上只能出现 **一次**。

```
#[deprecated(note = "because why not, right?")]
fn the_banished() {} // ok!
```
