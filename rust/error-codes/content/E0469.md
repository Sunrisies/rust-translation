未找到用于导入的宏。

错误的代码示例：

```compile_fail,E0469
#[macro_use(drink, be_merry)] // error: imported macro not found
extern crate alloc;

fn main() {
    // ...
}
```

要么所列出的宏并未包含在被导入的 crate 中，要么该 crate 没有导出该宏。

这可能是由于拼写错误造成的。你是否拼错了宏的名称？

请仔细核对用于导入的宏名称，并确保相关 crate 确实导出了这些宏。

一个可运行的版本应该是：

```ignore (cannot-doctest-multicrate-project)
// In some_crate crate:
#[macro_export]
macro_rules! eat {
    ...
}

#[macro_export]
macro_rules! drink {
    ...
}

// In your crate:
#[macro_use(eat, drink)]
extern crate some_crate; //ok!
```
