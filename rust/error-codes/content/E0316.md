`where` 子句包含对生命周期的嵌套量化。

错误的代码示例：

```compile_fail,E0316
trait Tr<'a, 'b> {}

fn foo<T>(t: T)
where
    for<'a> &'a T: for<'b> Tr<'a, 'b>, // error: nested quantification
{
}
```

Rust 语法允许在 `where` 子句中于两个位置进行生命周期量化：一种是在特质边界上量化（如 `Ty: for<'l> Trait<'l>`），另一种是在整个子句上量化（如 `for<'l> &'l Ty: Trait<'l>`）。如果在同一子句中同时使用这两种方式，会导致嵌套的生命周期量化，而这是不被支持的。

以下示例可以编译，因为带有嵌套量化的子句已被重写成仅使用一个 `for<>`：

```
trait Tr<'a, 'b> {}

fn foo<T>(t: T)
where
    for<'a, 'b> &'a T: Tr<'a, 'b>, // ok
{
}
```
