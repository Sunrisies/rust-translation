尝试将 `u8` 类型转换为 `char` 类型，但对象并非 `u8` 类型。

错误的代码示例：

```compile_fail,E0604
0u32 as char; // error: only `u8` can be cast as `char`, not `u32`
```

`char` 是一种 Unicode 标量值，其整数范围为 0 到 0xD7FF，以及 0xE000 到 0x10FFFF。（中间的空白用于表示替代对。）只有 `u8` 始终符合这些范围，因此只能将 `u8` 转换为 `char`。

若需要处理更大的数值，请使用 `char::from_u32`，该方法会检查数值是否有效。

```
assert_eq!(86u8 as char, 'V'); // ok!
assert_eq!(char::from_u32(0x3B1), Some('α')); // ok!
assert_eq!(char::from_u32(0xD800), None); // not a USV.
```

关于类型转换的更多信息，请参阅 [参考手册][1] 中的“类型转换表达式”部分。

[1]: https://doc.rust-lang.org/reference/expressions/operator-expr.html#type-cast-expressions
