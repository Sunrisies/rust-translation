联合表达式并不恰好包含一个字段。

错误的代码示例：

```compile_fail,E0784
union Bird {
    pigeon: u8,
    turtledove: u16,
}

let bird = Bird {}; // error
let bird = Bird { pigeon: 0, turtledove: 1 }; // error
```

联合的关键特性是联合中的所有字段共享相同的存储空间。因此，对联合中某个字段的修改可能会覆盖其他字段，而联合的大小由其中最大的字段大小决定。

您可以在 [Rust 参考手册] 中找到关于联合类型的更多信息。

实际示例：

```
union Bird {
    pigeon: u8,
    turtledove: u16,
}

let bird = Bird { pigeon: 0 }; // OK
```
