#### 注意：此错误代码不再由编译器生成。

`not` 配置谓词存在格式错误。

错误的代码示例（使用 `cargo doc`）：

```ignore, E0536 (only triggers on cargo doc)
#![feature(doc_cfg)]
#[doc(cfg(not()))]
pub fn main() {

}
```

`not` 谓词期望一个配置模式。示例：

```
#![feature(doc_cfg)]
#[doc(cfg(not(target_os = "linux")))] // ok!
pub fn main() {

}
```

关于 `cfg` 宏的更多信息，请阅读参考手册中的 [条件编译][conditional-compilation] 章节。

[conditional-compilation]: https://doc.rust-lang.org/reference/conditional-compilation.html
