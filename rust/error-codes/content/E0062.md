某个结构体或类枚举变体的字段被指定了多次。

错误的代码示例：

```compile_fail,E0062
struct Foo {
    x: i32,
}

fn main() {
    let x = Foo {
                x: 0,
                x: 0, // error: field `x` specified more than once
            };
}
```

此错误表明在尝试构建结构体或类枚举变体时，某个字段被指定了多次。每个字段应仅被指定一次。示例：

```
struct Foo {
    x: i32,
}

fn main() {
    let x = Foo { x: 0 }; // ok!
}
```
