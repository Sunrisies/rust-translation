私有项无法被公开重新导出。此错误表明您试图对并非公开的类型或值执行 `pub use` 操作。

错误的代码示例：

```compile_fail,E0364
mod a {
    fn foo() {}

    mod a {
        pub use super::foo; // error!
    }
}
```

解决此问题的方法是确保您重新导出的项本身带有 `pub` 标记：

```
mod a {
    pub fn foo() {} // ok!

    mod a {
        pub use super::foo;
    }
}
```

有关此主题的更多信息，请参阅参考手册中的 [Use Declarations][use-declarations] 章节。
