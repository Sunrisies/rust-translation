内置函数特质对函数参数的元组具有泛型特性。如果使用花括号符号（`Fn<(T,), Output=U>`）来表示函数特质，而不是圆括号（`Fn(T) -> U`），则类型参数应是一个元组。否则无法使用函数调用符号，且该特质不会通过闭包实现。

此错误最可能的来源是未将函数参数类型包裹在元组中而直接使用花括号符号，例如：

```compile_fail,E0059
#![feature(unboxed_closures)]

fn foo<F: Fn<i32>>(f: F) -> F::Output { f(3) }
```

可以通过调整特质边界来修复这个问题：

```
#![feature(unboxed_closures)]

fn foo<F: Fn<(i32,)>>(f: F) -> F::Output { f(3) }
```

请注意，`(T,)` 始终表示包含类型为 `T` 的元素的 1-元组类型。逗号用于语法上的歧义消除。
