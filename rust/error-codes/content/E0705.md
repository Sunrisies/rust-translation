#### 注意：此错误代码不再由编译器生成。

使用了 `#![feature]` 属性来引入当前版本中稳定的功能，但并非所有版本都支持该特性。

错误的代码示例：

```compile_fail
#![feature(rust_2018_preview)]
#![feature(test_2018_feature)] // error: the feature
                               // `test_2018_feature` is
                               // included in the Rust 2018 edition
```
