遇到了类型依赖循环。

错误的代码示例：

```compile_fail,E0391
trait FirstTrait : SecondTrait {

}

trait SecondTrait : FirstTrait {

}
```

之前的示例中存在两个特质之间的循环依赖：`FirstTrait` 依赖于 `SecondTrait`，而 `SecondTrait` 又依赖于 `FirstTrait`。

更多信息请参见 https://rustc-dev-guide.rust-lang.org/overview.html#queries 和 https://rustc-dev-guide.rust-lang.org/query.html。
