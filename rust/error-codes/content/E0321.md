在并非结构体或枚举类型的对象上实现了跨 crate 的 opt-out trait。

错误的代码示例：

```compile_fail,E0321
#![feature(auto_traits)]

struct Foo;

impl !Sync for Foo {}

unsafe impl Send for &'static Foo {}
// error: cross-crate traits with a default impl, like `core::marker::Send`,
//        can only be implemented for a struct/enum type, not
//        `&'static Foo`
```

只有结构体和枚举才被允许实现 Send、Sync及其他 opt-out trait，且该结构体或枚举必须属于当前 crate 内部。因此，例如 `unsafe impl Send for Rc<Foo>` 是不允许的。
