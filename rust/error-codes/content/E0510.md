匹配值在 match 保护语句中被赋值。

错误的代码示例：

```compile_fail,E0510
let mut x = Some(0);
match x {
    None => {}
    Some(_) if { x = None; false } => {} // error!
    Some(_) => {}
}
```

当对变量进行匹配时，不能在 match 保护语句中修改它，因为这可能会导致匹配不是穷尽的。

在这里执行 `x = None` 会修改被匹配的值，我们需要“回到过去”到 `None` 分支。为了解决这个问题，需要更改 match 分支中的值：

```
let mut x = Some(0);
match x {
    None => {}
    Some(_) => {
        x = None; // ok!
    }
}
```
