在模式中使用了元组结构或元组变体，其行为就像是一个结构或结构变体一样。

错误的代码示例：

```compile_fail,E0769
enum E {
    A(i32),
}

let e = E::A(42);

match e {
    E::A { number } => { // error!
        println!("{}", number);
    }
}
```

要修复此错误，可以使用元组模式：

```
# enum E {
#     A(i32),
# }
# let e = E::A(42);
match e {
    E::A(number) => { // ok!
        println!("{}", number);
    }
}
```

或者，也可以使用结构模式，通过使用正确的字段名称并将它们绑定到新的标识符来实现。

```
# enum E {
#     A(i32),
# }
# let e = E::A(42);
match e {
    E::A { 0: number } => { // ok!
        println!("{}", number);
    }
}
```
