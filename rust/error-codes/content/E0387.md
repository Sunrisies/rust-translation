#### 注意：此错误代码已不再由编译器生成。

当尝试对闭包不可变捕获的数据进行修改或可变引用时，就会出现此错误。

错误的代码示例：

```compile_fail
// Accepts a function or a closure that captures its environment immutably.
// Closures passed to foo will not be able to mutate their closed-over state.
fn foo<F: Fn()>(f: F) { }

// Attempts to mutate closed-over data. Error message reads:
// `cannot assign to data in a captured outer variable...`
fn mutable() {
    let mut x = 0u32;
    foo(|| x = 2);
}

// Attempts to take a mutable reference to closed-over data. Error message
// reads: `cannot borrow data mutably in a captured outer variable...`
fn mut_addr() {
    let mut x = 0u32;
    foo(|| { let y = &mut x; });
}
```

这里的问题在于 `foo` 被定义为接受 `Fn` 类型的参数。因此传入 `foo` 的闭包会被推断为 `Fn` 类型，意味着它们不可变地捕获了上下文。

如果 `foo` 的定义由你控制，最简单的解决方案是可变地捕获数据。可以通过将 `foo` 定义为接受 `FnMut` 而不是 `Fn` 来实现这一点：

```
fn foo<F: FnMut()>(f: F) { }
```

或者，我们可以考虑使用 `Cell` 和 `RefCell` 类型通过共享引用实现内部可变性。我们的 `mutable` 函数可以重新定义如下：

```
use std::cell::Cell;

fn foo<F: Fn()>(f: F) { }

fn mutable() {
    let x = Cell::new(0u32);
    foo(|| x.set(2));
}
```

您可以在 [Cell][std-cell] 的 API 文档中阅读更多内容。

[std-cell]: https://doc.rust-lang.org/std/cell/
