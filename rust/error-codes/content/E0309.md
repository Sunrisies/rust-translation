某个参数类型缺少明确的生命周期约束，可能无法持续存在足够长的时间。

错误的代码示例：

```compile_fail,E0309
// This won't compile because the applicable impl of
// `SomeTrait` (below) requires that `T: 'a`, but the struct does
// not have a matching where-clause.
struct Foo<'a, T> {
    foo: <T as SomeTrait<'a>>::Output,
}

trait SomeTrait<'a> {
    type Output;
}

impl<'a, T> SomeTrait<'a> for T
where
    T: 'a,
{
    type Output = u32;
}
```

类型定义中包含某些字段，其类型需要“超出生命周期”的注解。超出生命周期的注解（例如 `T: 'a`）用于确保 `T` 中的所有数据在至少生命周期 `'a'` 内都是有效的。这种情况通常出现在类型包含关联类型引用时，如前面的代码中所示 `<T as SomeTrait<'a>>::Output`。

在这里，`impl` 中的 where 子句 `T: 'a` 并不确定在结构体上会被满足。要使这个示例能够编译，必须在结构体定义中添加类似 `T: 'a` 的 where 子句：

```
struct Foo<'a, T>
where
    T: 'a,
{
    foo: <T as SomeTrait<'a>>::Output
}

trait SomeTrait<'a> {
    type Output;
}

impl<'a, T> SomeTrait<'a> for T
where
    T: 'a,
{
    type Output = u32;
}
```
