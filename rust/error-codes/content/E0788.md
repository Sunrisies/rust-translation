#### 注意：此错误代码已不再由编译器生成。

在不允许使用 `#[coverage(off|on)]` 属性的位置发现了该属性。

覆盖度属性可以应用于： - 具有主体的函数和方法声明，包括具有默认实现的特质方法。 - 可以在表达式上应用属性的闭包表达式。 - `impl` 块（固有或特质）以及模块。

错误代码示例：

```ignore (no longer emitted)
unsafe extern "C" {
    #[coverage(off)]
    fn foreign_fn();
}
```

当使用 `-C instrument-coverage` 标志时，覆盖度属性会向编译器提供提示，告诉编译器是否应对相应的函数或嵌套函数进行Instrument化。应用覆盖度属性的具体效果无法保证，且可能在未来的编译器版本中发生变化。
