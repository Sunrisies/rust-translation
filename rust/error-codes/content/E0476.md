转换后的类型不会超过被转换的值的生命周期。

错误代码示例：

```compile_fail,E0476
#![feature(coerce_unsized)]
#![feature(unsize)]

use std::marker::Unsize;
use std::ops::CoerceUnsized;

// error: lifetime of the source pointer does not outlive lifetime bound of the
//        object type
impl<'a, 'b, T, S> CoerceUnsized<&'a T> for &'b S where S: Unsize<T> {}
```

在转换过程中，“源指针”（转换后的类型）没有超过“对象类型”（被转换的值）的生命周期。在上述示例中，`'b` 不是 `'a` 的子类型。目前，这种错误仅出现在不稳定的 `CoerceUnsized` trait 中，该Trait允许通过智能指针实现未大小类型自定义转换。
