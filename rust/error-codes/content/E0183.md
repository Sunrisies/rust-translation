对 `Fn*` trait 的手动实现。

错误的代码示例：

```compile_fail,E0183
struct MyClosure {
    foo: i32
}

impl FnOnce<()> for MyClosure {  // error
    type Output = ();
    extern "rust-call" fn call_once(self, args: ()) -> Self::Output {
        println!("{}", self.foo);
    }
}
```

手动实现 `Fn`、`FnMut` 或 `FnOnce` 是不稳定的，需要启用 `#![feature(fn_traits, unboxed_closures)]`。

```
#![feature(fn_traits, unboxed_closures)]

struct MyClosure {
    foo: i32
}

impl FnOnce<()> for MyClosure {  // ok!
    type Output = ();
    extern "rust-call" fn call_once(self, args: ()) -> Self::Output {
        println!("{}", self.foo);
    }
}
```

参数必须是一个表示参数列表的元组。有关更多信息，请参见 [跟踪问题][iss29625]：

[iss29625]: https://github.com/rust-lang/rust/issues/29625
