模式绑定是指使用与类型变体之一相同的名称。

错误的代码示例：

```compile_fail,E0170
# #![deny(warnings)]
enum Method {
    GET,
    POST,
}

fn is_empty(s: Method) -> bool {
    match s {
        GET => true,
        _ => false
    }
}

fn main() {}
```

枚举变体默认是带限定名的。例如，对于以下类型：

```
enum Method {
    GET,
    POST,
}
```

您可以使用以下方式进行匹配：

```
enum Method {
    GET,
    POST,
}

let m = Method::GET;

match m {
    Method::GET => {},
    Method::POST => {},
}
```

如果您不限定名称，代码将绑定名为“GET”和“POST”的新变量。这种行为很可能不是您想要的，`rustc` 会在这种情况出现时发出警告。

带限定名的名称是良好的实践，大多数代码也适合使用这种方式。但如果您更喜欢未限定的名称，可以将变体导入到作用域中：

```
use Method::*;
enum Method { GET, POST }
# fn main() {}
```

如果您希望其他用户能够直接从您的模块中导入变体，请使用 `pub use` 语法。

```
pub use Method::*;
pub enum Method { GET, POST }
# fn main() {}
```
