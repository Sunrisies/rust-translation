较低的范围并不小于上限范围。

错误的代码示例：

```compile_fail,E0579

fn main() {
    match 5u32 {
        // This range is ok, albeit pointless.
        1..2 => {}
        // This range is empty, and the compiler can tell.
        5..5 => {} // error!
    }
}
```

当与排他性范围进行匹配时，编译器会验证该范围非空。排他性范围模式包括起点但不包含终点，因此这相当于要求范围的起点小于范围的终点。
