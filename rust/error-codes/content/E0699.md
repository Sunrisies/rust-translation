#### 注意：此错误代码已不再由编译器生成。

在类型尚未完全确定的原始指针上调用了方法。

错误的代码示例：

```compile_fail,edition2018
# #![deny(warnings)]
# fn main() {
let foo = &1;
let bar = foo as *const _;
if bar.is_null() {
    // ...
}
# }
```

在这里，`bar`的类型未知；它可能是指向任何对象的指针。因此，应为该指针指定一个类型（最好是与所指向对象相关的类型）：

```
let foo = &1;
let bar = foo as *const i32;
if bar.is_null() {
    // ...
}
```

尽管 `is_null()` 是任何原始指针上的方法，但 Rust 显示此错误是因为 Rust 允许 `self` 具有任意类型（通过 arbitrary_self_types 特性标志实现）。

这意味着可以定义这样的函数：

```ignore (cannot-doctest-feature-doesnt-exist-yet)
impl Foo {
    fn is_null(self: *const Self) -> bool {
        // do something else
    }
}
```

现在，当对 `Foo` 的原始指针调用 `.is_null()` 时，就会出现歧义。

由于我们不知道指针的类型，且某些类型可能存在歧义，因此当类型未知时，禁止对原始指针调用方法。
