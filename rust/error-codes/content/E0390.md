在基本类型上实现了一种方法或常量。

错误的代码示例：

```compile_fail,E0390
struct Foo {
    x: i32
}

impl *mut Foo {}
// error: cannot define inherent `impl` for primitive types
```

这是不允许的，但使用特质来实现方法或常量是更好的解决方案。示例：

```
struct Foo {
    x: i32
}

trait Bar {
    fn bar();
}

impl Bar for *mut Foo {
    fn bar() {} // ok!
}
```

除了在引用上定义固有的实现外，您也可以将引用移入实现中：

```compile_fail,E0390
struct Foo;

impl &Foo { // error: no nominal type found for inherent implementation
    fn bar(self, other: Self) {}
}
```

becomes

```
struct Foo;

impl Foo {
    fn bar(&self, other: &Self) {}
}
```
