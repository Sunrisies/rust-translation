此错误表明，该结构体、枚举或枚举变体无法在定义库之外实例化，因为其被标记为 `non_exhaustive`，未来可能会添加更多字段/变体，从而对该代码产生不良副作用。

错误的代码示例：

```ignore (it only works cross-crate)
#[non_exhaustive]
pub struct NormalStruct {
    pub first_field: u16,
    pub second_field: u16,
}

let ns = NormalStruct { first_field: 640, second_field: 480 }; // error!
```

建议您在库的文档中查找 `new` 函数或等效功能。
