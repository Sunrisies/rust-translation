#### 注意：此错误代码已不再由编译器生成。

有人试图通过通用类型参数或 `Self` 访问关联常量，但目前此功能尚未支持。导致该错误的示例如下：

```
trait Foo {
    const BAR: f64;
}

struct MyStruct;

impl Foo for MyStruct {
    const BAR: f64 = 0f64;
}

fn get_bar_bad<F: Foo>(t: F) -> f64 {
    F::BAR
}
```

当前，特定类型的 `BAR` 值只能通过具体类型来访问，如下所示：

```
trait Foo {
    const BAR: f64;
}

struct MyStruct;

impl Foo for MyStruct {
    const BAR: f64 = 0f64;
}

fn get_bar_good() -> f64 {
    <MyStruct as Foo>::BAR
}
```
