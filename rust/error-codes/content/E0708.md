#### 注意：此错误代码已不再由编译器生成。

当前不支持带有参数的 `async` 非 `move` 闭包。

错误的代码示例：

```edition2018
fn main() {
    let add_one = async |num: u8| {
        num + 1
    };
}
```

当前版本不支持使用非 `move` 的 `async`，但可以通过使用 `move` 来成功使用。

```edition2018
fn main() {
    let add_one = async move |num: u8| { // ok!
        num + 1
    };
}
```
