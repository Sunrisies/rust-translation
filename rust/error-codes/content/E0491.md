引用对象的生命周期比其引用的数据更长。

错误的代码示例：

```compile_fail,E0491
struct Foo<'a> {
    x: fn(&'a i32),
}

trait Trait<'a, 'b> {
    type Out;
}

impl<'a, 'b> Trait<'a, 'b> for usize {
    type Out = &'a Foo<'b>; // error!
}
```

这里的问题在于，编译器无法确保 `'b' 的生命周期会超过 `'a'`，而这是必须的，以确保 `trait::Out` 始终有一个指向现有类型的引用。因此，在这种情况下，我们只需要告诉编译器 `'b'` 必须比 `'a'` 的生命周期长：

```
struct Foo<'a> {
    x: fn(&'a i32),
}

trait Trait<'a, 'b> {
    type Out;
}

impl<'a, 'b: 'a> Trait<'a, 'b> for usize { // we added the lifetime enforcement
    type Out = &'a Foo<'b>; // it now works!
}
```
