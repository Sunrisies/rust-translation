某种模式试图从一个变体中提取错误的字段数量。

错误的代码示例：

```compile_fail,E0023
enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

match x {
    Fruit::Apple(a) => {}, // error!
    _ => {}
}
```

用于与枚举变体进行匹配的模式必须为枚举变体的每个字段提供一个子模式。

这里 `Apple` 变体有两个字段，应该这样进行匹配：

```
enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

// Correct.
match x {
    Fruit::Apple(a, b) => {},
    _ => {}
}
```

使用错误数量的字段进行匹配没有合理的含义：

```compile_fail,E0023
enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

// Incorrect.
match x {
    Fruit::Apple(a) => {},
    Fruit::Apple(a, b, c) => {},
}
```

检查枚举声明的字段数量，并确保你的模式使用的字段数量一致。
