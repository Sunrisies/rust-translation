数组或切片模式中的元素数量与所匹配的数组中的元素数量不一致。

错误代码示例：

```compile_fail,E0527
let r = &[1, 2, 3, 4];
match r {
    &[a, b] => { // error: pattern requires 2 elements but array
                 //        has 4
        println!("a={}, b={}", a, b);
    }
}
```

确保模式与所匹配的数组的大小一致。可以通过 `..` 来匹配额外的元素。

```
let r = &[1, 2, 3, 4];
match r {
    &[a, b, ..] => { // ok!
        println!("a={}, b={}", a, b);
    }
}
```
