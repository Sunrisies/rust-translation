在当前 crate 之外，为某个类型定义了固有的实现。

错误的代码示例：

```compile_fail,E0116
impl Vec<u8> { } // error
```

您只能在同一 crate 中为该类型定义固有的实现。例如，由于 `Vec` 定义在标准库中，像上述 `impl` 块这样的做法是不允许的。

要解决此问题，您可以选择以下方法之一：

 - 定义一个包含所需关联函数、类型或常量的 trait，并为相关类型实现该 trait；或者 - 定义一个新的类型来封装原类型，并在新类型上定义实现。

请注意，在这里使用 `type` 关键字无效，因为 `type` 仅用于引入类型别名。

```compile_fail,E0116
type Bytes = Vec<u8>;

impl Bytes { } // error, same as above
```
