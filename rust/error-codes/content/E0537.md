#### 注意：此错误代码已不再由编译器生成，因为 `cfg` 属性中使用了未知的谓词。

错误的代码示例：

```compile_fail,E0539
#[cfg(unknown())] // error: invalid predicate `unknown`
pub fn something() {}

pub fn main() {}
```

`cfg` 属性仅支持三种类型的谓词：

 * 任意 * 全部 * 非

Example:

```
#[cfg(not(target_os = "linux"))] // ok!
pub fn something() {}

pub fn main() {}
```

关于 `cfg` 属性的更多信息，请阅读参考手册中的 [条件编译][conditional-compilation] 部分。
