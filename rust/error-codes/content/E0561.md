使用了非识别符或非通配符模式作为函数指针类型的参数。

错误的代码示例：

```compile_fail,E0561
type A1 = fn(mut param: u8); // error!
type A2 = fn(&param: u32); // error!
```

当在函数类型上使用别名时，无法将参数标记为可变的。

要解决此问题，可以移除模式（虽然使用 `_` 也是允许的）。示例：

```
type A1 = fn(param: u8); // ok!
type A2 = fn(_: u32); // ok!
```

您也可以省略参数名称：

```
type A3 = fn(i16); // ok!
```
