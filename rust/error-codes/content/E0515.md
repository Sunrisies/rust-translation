返回了对局部变量的引用。

错误的代码示例：

```compile_fail,E0515
fn get_dangling_reference() -> &'static i32 {
    let x = 0;
    &x
}
```

```compile_fail,E0515
use std::slice::Iter;
fn get_dangling_iterator<'a>() -> Iter<'a, i32> {
    let v = vec![1, 2, 3];
    v.iter()
}
```

局部变量、函数参数和临时变量都在函数体结束前被销毁。对如此被销毁值的返回引用（或包含引用的结构体）会立即变得无效。因此，不允许返回这样的引用。

考虑返回一个拥有本地数据所有权的值，而不是仅对其进行引用：

```
use std::vec::IntoIter;

fn get_integer() -> i32 {
    let x = 0;
    x
}

fn get_owned_iterator() -> IntoIter<i32> {
    let v = vec![1, 2, 3];
    v.into_iter()
}
```
