#### 注意：此错误代码不再由编译器生成

这是因为该错误对 `inline` 属性过于具体。其他属性也会出现类似的诊断信息。此时示例将输出 `E0805`

`inline` 属性存在格式错误。

错误的代码示例：

```compile_fail,E0805
#[inline()] // error: expected one argument
pub fn something() {}

fn main() {}
```

带括号的 `inline` 属性要求指定参数：

```
#[inline(always)]
fn something() {}
```

or:

```
#[inline(never)]
fn something() {}
```

或者，可以使用不带括号的版本来提示编译器关于内联的机会：

```
#[inline]
fn something() {}
```

有关更多信息，请参阅参考手册中的 [`inline` 属性][inline-attribute]部分。

[inline-attribute]: https://doc.rust-lang.org/reference/attributes/codegen.html#the-inline-attribute
