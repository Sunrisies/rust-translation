#### 注意：此错误代码已不再由编译器生成。

编译器发现了多个包含所请求库名的库文件。

```compile_fail
// aux-build:crateresolve-1.rs
// aux-build:crateresolve-2.rs
// aux-build:crateresolve-3.rs

extern crate crateresolve;
//~^ ERROR multiple candidates for `rlib` dependency `crateresolve` found

fn main() {}
```

此错误可能在多种不同情况下出现——例如，当使用 `extern crate` 或传递 `--extern` 选项但未提供库路径时。它也可能由构建目录的缓存问题引起，在这种情况下，`cargo clean` 可能有助于解决问题。

在上述示例中，有三个不同的库文件，它们都定义了相同的库名。如果不提供完整路径，编译器就无法知道应该使用哪个库。
