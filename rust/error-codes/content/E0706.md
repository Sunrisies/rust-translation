#### 注意：此错误代码已不再由编译器生成。

在 Rust 中，特质中尚未支持 `async fn`。

错误的代码示例：

```ignore,edition2018
trait T {
    // Neither case is currently supported.
    async fn foo() {}
    async fn bar(&self) {}
}
```

`async fn` 返回一个 `impl Future`，使得以下两个示例等效：

```ignore,edition2018 (example-of-desugaring-equivalence)
async fn foo() -> User {
    unimplemented!()
}
// The async fn above gets desugared as follows:
fn foo(&self) -> impl Future<Output = User> + '_ {
    unimplemented!()
}
```

但在支持特质中使用此功能时，存在[一些实现问题][异步-is-hard]。其中之一是特质中返回 `impl Trait` 是不被支持的，因为这将需要[泛型关联类型]的支持：

```edition2018,ignore (example-of-desugaring-equivalence)
impl MyDatabase {
    async fn get_user(&self) -> User {
        unimplemented!()
    }
}

impl MyDatabase {
    fn get_user(&self) -> impl Future<Output = User> + '_ {
        unimplemented!()
    }
}
```

在解决这些问题之前，你可以使用 [`async-trait` crate]，通过去解析化为“盒化未来”（`Pin<Box<dyn Future + Send + 'async>>`），从而在特质中使用 `async fn`。

请注意，使用这些特质方法会导致每次函数调用时进行堆分配。对于绝大多数应用程序来说，这不是显著的成本，但在决定是否将此功能用于预期每秒调用数百万次的低级函数的公共 API时，应予以考虑。
