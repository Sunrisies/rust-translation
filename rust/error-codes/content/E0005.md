用于绑定名称的模式必须不可抵赖，也就是说，它们必须确保在任何情况下都能提取出该名称。

错误的代码示例：

```compile_fail,E0005
let x = Some(1);
let Some(y) = x;
// error: refutable pattern in local binding: `None` not covered
```

如果您遇到此错误，可能需要使用 `match` 或 `if let` 来处理失败的可能性。示例：

```
let x = Some(1);

match x {
    Some(y) => {
        // do something
    },
    None => {}
}

// or:

if let Some(y) = x {
    // do something
}
```
