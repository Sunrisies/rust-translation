发现了一个不提供任何说明的文档注释。

错误的代码示例：

```compile_fail,E0585
fn main() {
    // The following doc comment will fail:
    /// This is a useless doc comment!
}
```

文档注释后需要跟随各项内容，包括函数、类型、模块等。示例：

```
/// I'm documenting the following struct:
struct Foo;

/// I'm documenting the following function:
fn foo() {}
```
