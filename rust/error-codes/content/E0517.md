#### 注意：此错误代码不再由编译器生成。该错误代码已被替换为`attribute cannot be used on...`诊断信息，没有错误代码。

在不受支持的类型上使用了 `#[repr(..)]` 属性。

错误的代码示例：

```compile_fail
#[repr(C)]
type Foo = u8;

#[repr(packed)]
enum Foo {Bar, Baz}

#[repr(u8)]
struct Foo {bar: bool, baz: bool}

#[repr(C)]
impl Foo {
    // ...
}
```

* `#[repr(C)]` 属性只能用于结构体和枚举。 * `#[repr(packed)]` 和 `#[repr(simd)]` 属性仅适用于结构体。 * `#[repr(u8)]`、`#[repr(i16)]` 等属性仅适用于枚举。

这些属性不适用于 typedef，因为 typedef 只是别名而已。

如 `#[repr(u8)]`、 `#[repr(i64)]` 这样的表示方式用于选择枚举的判别式大小。对于没有任何数据字段的枚举变体，例如 `enum Color {Red, Blue, Green}`，这实际上将枚举的大小设置为所提供类型的大小。这种枚举也可以转换为相同类型的值。简而言之，`#[repr(u8)]` 使无字段枚举表现得像具有有限允许值的整数。

关于 `#[repr(C)]` 和类似 `#[repr(u8)]` 的表示方式如何影响具有数据字段的枚举布局，请参阅 [RFC 2195][rfc2195]。

只有无字段枚举才能被转换为数值基本类型。如 `#[repr(u8)]` 这样的表示方式不适用于结构体。

`#[repr(packed)]` 减少填充量以缩小结构体大小。Rust 中枚举的表示方式并未严格定义，因此此属性无法用于枚举。

`#[repr(simd)]` 将为由同构机器类型系列（即 `u8`、`i32` 等）组成的结构体提供允许通过 SIMD 进行向量化的表示方式。对于枚举来说这没有太大意义，因为枚举并不由单一数据列表组成。

[rfc2195]: https://rust-lang.github.io/rfcs/2195-really-tagged-unions.html
