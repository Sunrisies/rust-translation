针对并非结构体、枚举、联合类型或特质对象的对象，定义了一个固有的实现方式。

错误的代码示例：

```compile_fail,E0118
impl<T> T { // error: no nominal type found for inherent implementation
    fn get_state(&self) -> String {
        // ...
    }
}
```

要修复此错误，请在该类型上实现一个特质或将它封装在一个结构体中。示例：

```
// we create a trait here
trait LiveLongAndProsper {
    fn get_state(&self) -> String;
}

// and now you can implement it on T
impl<T> LiveLongAndProsper for T {
    fn get_state(&self) -> String {
        "He's dead, Jim!".to_owned()
    }
}
```

或者，你可以创建一个新类型。新类型是一种包装元组结构体。例如，`NewType`是`Foo`的一个新类型，具体实现为`struct NewType(Foo)`。示例：

```
struct TypeWrapper<T>(T);

impl<T> TypeWrapper<T> {
    fn get_state(&self) -> String {
        "Fascinating!".to_owned()
    }
}
```
