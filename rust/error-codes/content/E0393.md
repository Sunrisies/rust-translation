在默认值中引用 `Self` 的类型参数未被指定。

错误的代码示例：

```compile_fail,E0393
trait A<T = Self> {}

fn together_we_will_rule_the_galaxy(son: &dyn A) {}
// error: the type parameter `T` must be explicitly specified
```

trait 对象是在一个完全定义的 trait 上定义的。对于常规默认参数，该参数可以直接在实例化中使用。然而，如果默认参数是 `Self`，则每个具体类型对应的 trait 都会发生变化；例如，`i32` 将被期望实现 `A<i32>`，`bool` 将被期望实现 `A<bool》等……这些类型不会共享同一个完全定义的 trait 的实现，而是共享不同参数在每种实现中生成的Trait对象。这与我们使Trait对象正常工作的需求不可调和，因此是不允许的。通过明确指定默认参数的值来使Trait具体化可以解决此问题。修正后的示例：

```
trait A<T = Self> {}

fn together_we_will_rule_the_galaxy(son: &dyn A<i32>) {} // Ok!
```
