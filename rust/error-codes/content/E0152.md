一个语言项已被重新定义。

错误的代码示例：

```compile_fail,E0152
#![feature(lang_items)]

#[lang = "owned_box"]
struct Foo<T>(T); // error: duplicate lang item found: `owned_box`
```

语言项已在标准库中实现。除非您正在编写独立应用程序（例如内核），否则无需自行实现这些项。

您可以通过在 crate 属性中添加 `#![no_std]` 来构建独立的 crate：

```ignore (only-for-syntax-highlight)
#![no_std]
```

另请参阅 [Rustonomicon 中的此部分][beneath std]。
