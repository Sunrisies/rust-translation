#### 注意：此错误代码已不再由编译器生成。

`where` 子句必须使用泛型类型参数：否则是没有意义的。导致此错误的示例如下：

```
trait Foo {
    fn bar(&self);
}

#[derive(Copy,Clone)]
struct Wrapper<T> {
    Wrapped: T
}

impl Foo for Wrapper<u32> where Wrapper<u32>: Clone {
    fn bar(&self) { }
}
```

这种使用 `where` 子句的方式很奇怪——更常见的用法类似如下：

```
trait Foo {
    fn bar(&self);
}

#[derive(Copy,Clone)]
struct Wrapper<T> {
    Wrapped: T
}
impl <T> Foo for Wrapper<T> where Wrapper<T>: Clone {
    fn bar(&self) { }
}
```

这里的意思是，只有当被包装的类型 `T` 实现了 `Clone` 时，`Wrapper` 才有该实现。`where` 子句很重要，因为有些类型不会实现 `Clone`，因此也不会获得此方法。

然而，在我们的错误示例中，我们引用的是单个具体类型。由于我们可以肯定 `Wrapper<u32>` 实现了 `Clone`，就没有必要在 `where` 子句中再次指定它。
