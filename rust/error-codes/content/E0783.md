不再允许使用 `...` 的范围模式。

错误的代码示例：

```edition2021,compile_fail,E0783
match 2u8 {
    0...9 => println!("Got a number less than 10"), // error!
    _ => println!("Got a number 10 or more"),
}
```

旧版本的 Rust 代码使用 `...` 来表示包含范围，而现在则使用 `..=` 来表示。

要使此代码能够编译，请将 `...` 替换为 `..=`。

```edition2021
match 2u8 {
    0..=9 => println!("Got a number less than 10"), // ok!
    _ => println!("Got a number 10 or more"),
}
```
