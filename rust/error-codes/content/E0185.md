为某个特质定义的一个相关函数被声明为静态，但该特质的实现却将同一个函数声明为方法（即需要接受一个 `self` 参数）。

错误的代码示例：

```compile_fail,E0185
trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {
    // error, method `foo` has a `&self` declaration in the impl, but not in
    // the trait
    fn foo(&self) {}
}
```

当一个类型实现了特质的相关函数时，必须使用相同的签名。因此在这种情况下，由于 `Foo::foo` 不接受任何参数也不返回任何值，其在 `Bar` 上的实现也应该是相同的：

```
trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {
    fn foo() {} // ok!
}
```
