生命周期仅存在于关联类型绑定中，而不存在于 trait 的输入类型中。

错误的代码示例：

```compile_fail,E0582
fn bar<F>(t: F)
    // No type can satisfy this requirement, since `'a` does not
    // appear in any of the input types (here, `i32`):
    where F: for<'a> Fn(i32) -> Option<&'a i32>
{
}

fn main() { }
```

要解决此问题，要么在输入中使用生命周期，要么使用 `'static`。示例：

```
fn bar<F, G>(t: F, u: G)
    where F: for<'a> Fn(&'a i32) -> Option<&'a i32>,
          G: Fn(i32) -> Option<&'static i32>,
{
}

fn main() { }
```

该错误还涉及使用带有生命周期参数的关联类型。
```compile_fail,E0582
trait Foo {
    type Assoc<'a>;
}

struct Bar<X, F>
where
    X: Foo,
    F: for<'a> Fn(X::Assoc<'a>) -> &'a i32
{
    x: X,
    f: F
}
```
后一种情况出现错误是因为 `Foo::Assoc<'a>` 可以由不使用 `'a` 参数的类型实现，因此无法保证 `X::Assoc<'a>` 实际上使用了 `'a`。

为了解决这个问题，我们可以传递一个虚拟参数：
```
# trait Foo {
#     type Assoc<'a>;
# }
struct Bar<X, F>
where
    X: Foo,
    F: for<'a> Fn(X::Assoc<'a>, /* dummy */ &'a ()) -> &'a i32
{
    x: X,
    f: F
}
```

注意：上述示例过去被编译器错误地接受了，但现在已经修正。更多细节请参见 [issue #33685]。
