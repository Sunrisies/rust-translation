#### 注意：此错误代码不再由编译器生成。

使用了 `#[main]` 属性声明了多个函数。

错误的代码示例：

```compile_fail
#![feature(main)]

#[main]
fn foo() {}

#[main]
fn f() {} // error: multiple functions with a `#[main]` attribute
```

此错误表明编译器发现了多个带有 `#[main]` 属性的函数。这是一个错误，因为 Rust 程序必须有一个唯一的入口点。示例：

```compile_fail
#![feature(main)]

#[main]
fn f() {} // ok!
```
