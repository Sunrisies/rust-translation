在不支持该二元运算的类型上尝试执行了二元运算。

错误的代码示例：

```compile_fail,E0369
let x = 12f32; // error: binary operation `<<` cannot be applied to
               //        type `f32`

x << 2;
```

要修复此错误，请确认该类型实现了该二元运算。示例：

```
let x = 12u32; // the `u32` type does implement it:
               // https://doc.rust-lang.org/stable/std/ops/trait.Shl.html

x << 2; // ok!
```

你也可以通过从 `std::ops` 中实现特征来为自定义类型重载大多数运算符。

字符串连接会将右侧的字符串追加到左侧的字符串上，并可能需要重新分配内存。这要求对左侧的字符串拥有所有权。如果需要对字符串字面量进行添加操作，请使用 `to_owned()` 将其移动到堆上，例如 `"Your text".to_owned()`。
