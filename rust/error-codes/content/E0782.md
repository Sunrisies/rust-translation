特征对象必须包含 `dyn` 关键字。

错误的代码示例：

```edition2021,compile_fail,E0782
trait Foo {}
fn test(arg: Box<Foo>) {} // error!
```

特征对象是一种在运行时才知晓且符合某些特征的类型上调用方法的方式。

特征对象应该使用 `Box<dyn Foo>` 来创建，但在上述代码中省略了 `dyn`。

这使得难以识别 `arg` 是一个特征对象，而不是一个名为 `Foo` 的堆分配类型。

要解决此问题，请在特征名称前添加 `dyn`。

```edition2021
trait Foo {}
fn test(arg: Box<dyn Foo>) {} // ok!
```

在 2021 版本之前这是被允许的，但现在会引发错误。
