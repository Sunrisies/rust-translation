调用闭包时提供了无效的参数数量。

错误的代码示例：

```compile_fail,E0057
let f = |x| x * 3;
let a = f();        // invalid, too few parameters
let b = f(4);       // this works!
let c = f(2, 3);    // invalid, too many parameters
```

当使用调用符号调用 `Fn`、`FnMut` 或 `FnOnce` 这些函数特质实现的闭包或其他实现时，传递给函数的参数数量必须与其定义一致。

泛型函数也需遵循同样的原则：

```
fn foo<F: Fn()>(f: F) {
    f(); // this is valid, but f(3) would not work
}
```
