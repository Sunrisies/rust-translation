数组或切片模式所需的元素数量超过了匹配数组中实际存在的元素数量。

错误代码的示例：

```compile_fail,E0528
let r = &[1, 2];
match r {
    &[a, b, c, rest @ ..] => { // error: pattern requires at least 3
                               //        elements but array has 2
        println!("a={}, b={}, c={} rest={:?}", a, b, c, rest);
    }
}
```

确保匹配数组的元素数量至少与模式要求的数量相同。你可以使用 `..` 来匹配任意数量的剩余元素。

```
let r = &[1, 2, 3, 4, 5];
match r {
    &[a, b, c, rest @ ..] => { // ok!
        // prints `a=1, b=2, c=3 rest=[4, 5]`
        println!("a={}, b={}, c={} rest={:?}", a, b, c, rest);
    }
}
```
