使用了闭包，但并未实现预期的特质。

错误的代码示例：

```compile_fail,E0525
struct X;

fn foo<T>(_: T) {}
fn bar<T: Fn(u32)>(_: T) {}

fn main() {
    let x = X;
    let closure = |_| foo(x); // error: expected a closure that implements
                              //        the `Fn` trait, but this closure only
                              //        implements `FnOnce`
    bar(closure);
}
```

在上面的示例中，`closure` 是一个 `FnOnce` 闭包，而 `bar` 函数期望的是一个 `Fn` 闭包。在这种情况下，只需在 `struct X` 上实现 `Copy` 和 `Clone` 特质即可解决此问题：

```
#[derive(Clone, Copy)] // We implement `Clone` and `Copy` traits.
struct X;

fn foo<T>(_: T) {}
fn bar<T: Fn(u32)>(_: T) {}

fn main() {
    let x = X;
    let closure = |_| foo(x);
    bar(closure); // ok!
}
```

为了更好地理解这些概念在 Rust 中的运作方式，请阅读《Book》中的 [Closures][closures] 章节。
