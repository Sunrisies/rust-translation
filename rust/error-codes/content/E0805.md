某个属性被传递了无效的参数数量

错误的代码示例：

```compile_fail,E0805
#[inline()] // error! should either have a single argument, or no parentheses
fn foo() {}

#[inline(always, never)] // error! should have only one argument, not two
fn bar() {}
```

要解决这个问题，需要为该属性提供正确的参数数量。在内联情况下，可以完全不传递参数：

```
#[inline]
fn foo() {}
```

或者只传递一个参数：

```
#[inline(always)]
fn foo() {}
```
