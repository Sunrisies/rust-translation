包含未实现 `Copy` trait 字段的类型上实现了 `Copy` trait。

错误的代码示例：

```compile_fail,E0204
struct Foo {
    foo: Vec<u32>,
}

impl Copy for Foo { } // error!
```

默认情况下，`Copy` trait 仅适用于基本类型。如果您的类型只包含基本类型，则可以在其上实现 `Copy`。否则则无法实现。

以下是另一个会失败的示例：

```compile_fail,E0204
#[derive(Copy)] // error!
struct Foo<'a> {
    ty: &'a mut bool,
}
```

此代码失败是因为即使 `T` 实现了 `Copy`，`&mut T` 也不属于 `Copy`（这与 `&T` 的行为不同，`&T` 始终属于 `Copy`）。
