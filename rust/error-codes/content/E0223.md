尝试获取关联类型，但该类型具有歧义。

错误的代码示例：

```compile_fail,E0223
trait Trait { type X; }

fn main() {
    let foo: Trait::X;
}
```

这里的问题在于我们试图从 `Trait` 中获取 `X` 的关联类型。不幸的是，`X` 的类型并未被定义，因为它仅在 `Trait` 的实现中被具体化。此代码的可用版本可能如下所示：

```
trait Trait { type X; }

struct Struct;
impl Trait for Struct {
    type X = u32;
}

fn main() {
    let foo: <Struct as Trait>::X;
}
```

该语法指定了我们希望从 `Struct` 对 `Trait` 的实现中获取关联类型 `X`。

由于当前编译器实现的内部限制，我们无法简单地使用 `Struct::X`。
