#### 注意：此错误代码不再由编译器生成。

`#[cmse_nonsecure_entry]` 仅适用于具有 TrustZone-M 扩展的目标。

错误的代码示例：

```ignore (no longer emitted)
#![feature(cmse_nonsecure_entry)]

pub extern "cmse-nonsecure-entry" fn entry_function() {}
```

要修复此错误，请为支持 TrustZone-M 扩展的 Rust 目标编译您的代码。当前可用的目标包括：* `thumbv8m.main-none-eabi` * `thumbv8m.main_none-eabihf` * `thumbv8m.base_NONE-eabi`
