在 `dyn` trait 对象类型中使用了多个特质作为边界。

错误的代码示例：

```compile_fail,E0225,edition2024
struct Example {
    file: Box<dyn std::io::Read + std::io::Write>,
}
```

Rust 目前不支持在单个 trait 对象中临时组合特质。不过有一些例外情况和替代方案：

*   任意数量的自动特质（如 `Send` 和 `Sync`）都可以与单个普通特质一起使用。例如，以下代码是被接受的：

    ```edition2024
    struct Example {
        file: Box<dyn std::io::Read + Send + Sync>,
    }
    ```

*   单个非自动特质的 supertrait 也是被允许的，无需明确指定。例如，即使 `read_to_string()` 是 `Read` 的方法而非 `BufRead` 的方法，因为 `Read` 是 `BufRead` 的 supertrait，以下代码也是被允许的。

    ```edition2024
    struct Example {
        file: Box<dyn std::io::BufRead>,
    }

    impl Example {
        fn read(mut self, string: &mut String) -> std::io::Result<usize> {
            self.file.read_to_string(string)
        }
    }
    ```

    因此，如果您正在定义用于 trait 对象的特质，添加 supertraits 可能是解决此问题的合适方案。

*   如果您无法或不应该修改任一特质的定义，可以定义一个针对该组合实现的新的特质：

    ```edition2024
    trait ReadWrite: std::io::Read + std::io::Write {}

    impl<T: std::io::Read + std::io::Write> ReadWrite for T {}

    struct Example {
        file: Box<dyn ReadWrite>,
    }
    ```
