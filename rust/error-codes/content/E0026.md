一种结构体模式试图从结构中提取不存在的字段。

错误的代码示例：

```compile_fail,E0026
struct Thing {
    x: u32,
    y: u32,
}

let thing = Thing { x: 0, y: 0 };

match thing {
    Thing { x, z } => {} // error: `Thing::z` field doesn't exist
}
```

如果您使用简写字段模式，但希望用不同的名称引用结构体字段，则应该显式地重命名该字段。结构体字段通过冒号 `:` 前的名称来识别，因此结构体模式应类似于所匹配的结构体类型的声明。

```
struct Thing {
    x: u32,
    y: u32,
}

let thing = Thing { x: 0, y: 0 };

match thing {
    Thing { x, y: z } => {} // we renamed `y` to `z`
}
```
