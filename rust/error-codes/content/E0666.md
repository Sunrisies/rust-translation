`impl Trait` 类型不能嵌套在其他 `impl Trait` 类型的泛型参数中。

错误的代码示例：

```compile_fail,E0666
trait MyGenericTrait<T> {}
trait MyInnerTrait {}

fn foo(
    bar: impl MyGenericTrait<impl MyInnerTrait>, // error!
) {}
```

`impl Trait` 类型的类型参数必须被明确定义为有名称的泛型参数。

```
trait MyGenericTrait<T> {}
trait MyInnerTrait {}

fn foo<T: MyInnerTrait>(
    bar: impl MyGenericTrait<T>, // ok!
) {}
```
