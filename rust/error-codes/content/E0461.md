未能找到具有预期目标三元组 `..` 的 `crate `..` 模块。

错误代码示例：

`a.rs`
```ignore (cannot-link-with-other-tests)
#![crate_type = "lib"]

fn foo() {}
```

`main.rs`
```ignore (cannot-link-with-other-tests)
extern crate a;

fn main() {
    a::foo();
}
```

`a.rs` 使用 `--target powerpc-unknown-linux-gnu` 编译，`b.rs` 使用 `--target x86_64-unknown-linux-gnu` 编译。`a.rs` 被编译成与 `b.rs` 不兼容的二进制格式；PowerPC 和 x86 是完全不同的架构。此问题也适用于任何目标三元组的变化，因为 `std` 是特定于操作系统的。

可以通过以下方式解决此错误：* 使用 [Cargo](../cargo/index.html)（Rust 包管理器），它可以自动修复此问题。* 重新编译这两个 crate，使其采用一致的目标三元组。
