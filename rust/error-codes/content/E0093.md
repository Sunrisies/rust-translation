定义了一个未知的内核函数。

错误的代码示例：

```compile_fail,E0093
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn foo(); // error: unrecognized intrinsic function: `foo`

fn main() {
    unsafe {
        foo();
    }
}
```

请检查是否误写了函数的名称。所有内核函数都定义在 Rust 源代码的 `library/core/src/intrinsics` 中。
