某个函数错误地使用了 `continue` 关键字。

错误的代码示例：

```compile_fail,E0696
fn continue_simple() {
    'b: {
        continue; // error!
    }
}
fn continue_labeled() {
    'b: {
        continue 'b; // error!
    }
}
fn continue_crossing() {
    loop {
        'b: {
            continue; // error!
        }
    }
}
```

在这里，我们错误地使用了 `continue` 关键字。正如上文所述，`continue` 指向一个带标签的块。

为了修复这个问题，我们必须正确使用带标签的块。例如：

```
fn continue_simple() {
    'b: loop {
        continue ; // ok!
    }
}
fn continue_labeled() {
    'b: loop {
        continue 'b; // ok!
    }
}
fn continue_crossing() {
    loop {
        'b: loop {
            continue; // ok!
        }
    }
}
```
