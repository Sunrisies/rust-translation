#### 注意：此错误代码不再由编译器生成。

此错误表明空匹配表达式无效，因为其匹配的类型是非空的（存在该类型的值）。在安全代码中无法创建空类型的实例，因此几乎不希望使用空匹配表达式。通常可以通过在匹配表达式中添加一个或多个情况来修复此错误。

一个空类型的例子是 `enum Empty { }`。因此，以下代码可以正常工作：

```
enum Empty {}

fn foo(x: Empty) {
    match x {
        // empty
    }
}
```

然而，这样却不行：

```compile_fail
fn foo(x: Option<String>) {
    match x {
        // empty
    }
}
```
