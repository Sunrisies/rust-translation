#### 注意：此错误代码已不再由编译器生成。

您使用了不符合使用场景要求的函数或类型。错误的代码示例如下：

```compile_fail
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn unreachable(); // error: intrinsic has wrong type

// or:

fn main() -> i32 { 0 }
// error: main function expects type: `fn() {main}`: expected (), found i32

// or:

let x = 1u8;
match x {
    0u8..=3i8 => (),
    // error: mismatched types in range: expected u8, found i8
    _ => ()
}

// or:

use std::rc::Rc;
struct Foo;

impl Foo {
    fn x(self: Rc<Foo>) {}
    // error: mismatched self type: expected `Foo`: expected struct
    //        `Foo`, found struct `alloc::rc::Rc`
}
```

对于第一个代码示例，请检查函数定义。示例：

```
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn unreachable() -> !; // ok!
```

第二个案例有些特殊：主函数必须始终具有以下定义形式：

```compile_fail
fn main();
```

它们既不接收参数也不返回类型。

对于第三个示例，在匹配时，所有模式的类型必须与匹配时的类型相同。示例：

```
let x = 1u8;

match x {
    0u8..=3u8 => (), // ok!
    _ => ()
}
```

最后，对于最后一个示例，只有 `Box<Self>`、`&Self`、`Self` 或 `&mut Self` 可以作为显式的 self 参数。示例：

```
struct Foo;

impl Foo {
    fn x(self: Box<Foo>) {} // ok!
}
```
