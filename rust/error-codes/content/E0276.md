trait 实现对参数的要求比 trait 定义更为严格。

错误的代码示例：

```compile_fail,E0276
trait Foo {
    fn foo<T>(x: T);
}

impl Foo for bool {
    fn foo<T>(x: T) where T: Copy {}
}
```

在这里，所有实现 `Foo` 的类型都必须有一个可以接受任意类型 `T` 的 `foo<T>(x: T)` 方法。然而，在 `bool` 的 `impl` 中，我们添加了一个额外的约束条件，即 `T` 是 `Copy` 类型的，这与原始 trait 不兼容。

可以考虑从方法中移除该约束条件，或者将约束条件添加到 trait 中的原始方法定义中。
