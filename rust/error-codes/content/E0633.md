#### 注意：此错误代码已不再由编译器生成。

`unwind` 属性存在格式错误。

错误的代码示例：

```compile_fail
#![feature(unwind_attributes)]

#[unwind()] // error: expected one argument
pub extern "C" fn something() {}

fn main() {}
```

`#[unwind]` 属性应如下使用：

- `#[unwind(aborts)]` -- 指定如果非 Rust ABI 函数尝试展开时，应终止进程。这是更安全且推荐的选择。

- `#[unwind(allowed)]` -- 指定允许非 Rust ABI 函数展开。这很容易导致未定义行为（UB），因此需谨慎使用。

注意：默认行为是“允许”，但此设置是未指定的，未来可能会发生变化。
