在 trait 对象中指定了多个关联项。

错误的代码示例：

```compile_fail,E0719
trait FooTrait {}
trait BarTrait {}

// error: associated type `Item` in trait `Iterator` is specified twice
type Foo = dyn Iterator<Item = u32, Item = u32>;
```

要解决此问题，需移除重复的指定方式：

修正后的示例：

```
type Foo = dyn Iterator<Item = u32>; // ok!
```

有关关联类型的更多信息，请参阅 [这本书][bk-at]。关于关联类型边界的更多信息，请参阅 [RFC 2289][rfc-2289]。
