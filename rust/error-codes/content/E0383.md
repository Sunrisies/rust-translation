#### 注意：此错误代码不再由编译器生成。

当尝试部分重新初始化当前未初始化的结构时，就会出现此错误。

例如，在发生丢弃操作时可能会出现这种情况：

```compile_fail
struct Foo {
    a: u32,
}
impl Drop for Foo {
    fn drop(&mut self) { /* ... */ }
}

let mut x = Foo { a: 1 };
drop(x); // `x` is now uninitialized
x.a = 2; // error, partial reinitialization of uninitialized structure `t`
```

通过完全重新初始化该结构，可以解决此错误。

```
struct Foo {
    a: u32,
}
impl Drop for Foo {
    fn drop(&mut self) { /* ... */ }
}

let mut x = Foo { a: 1 };
drop(x);
x = Foo { a: 2 };
```
