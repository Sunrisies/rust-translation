在外部函数声明中，将模式作为参数进行声明。

错误的代码示例：

```compile_fail,E0130
extern "C" {
    fn foo((a, b): (u32, u32)); // error: patterns aren't allowed in foreign
                                //        function declarations
}
```

要解决此错误，请将模式参数替换为普通参数。示例：

```
struct SomeStruct {
    a: u32,
    b: u32,
}

extern "C" {
    fn foo(s: SomeStruct); // ok!
}
```

Or:

```
extern "C" {
    fn foo(a: (u32, u32)); // ok!
}
```
