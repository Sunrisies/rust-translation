`CoerceUnsized` 或 `DispatchFromDyn` 只能用于同一类型结构之间的实现。

错误代码示例：

```compile_fail,E0377
#![feature(coerce_unsized)]
use std::ops::CoerceUnsized;

pub struct Foo<T: ?Sized> {
    field_with_unsized_type: T,
}

pub struct Bar<T: ?Sized> {
    field_with_unsized_type: T,
}

// error: the trait `CoerceUnsized` may only be implemented for a coercion
//        between structures with the same definition
impl<T, U> CoerceUnsized<Bar<U>> for Foo<T> where T: CoerceUnsized<U> {}
```

`CoerceUnsized` 用于将具有不可量化字段的结构进行转换，例如将自定义的 `MyBox<T>` 不可量化转换为 `MyBox<dyn Trait>`。`DispatchFromDyn` 则用于在 dyn-兼容特质中从 `MyBox<dyn Trait>` 分发到 `MyBox<Self>`。

编译器无法支持不同类型结构之间的转换，因此 `CoerceUnsized` 或 `DispatchFromDyn` 的有效实现应针对具有不同泛型参数的同一结构进行设计。

请注意，`CoerceUnsized` 和 `DispatchFromDyn` 主要被智能指针如 `Box`、`Rc` 和 `Arc` 使用，以便标记它们能够转换其指向的不可量化类型。
