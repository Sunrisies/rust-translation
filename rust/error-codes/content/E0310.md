某个参数类型缺少生命周期约束，或者其生命周期不够长。

错误的代码示例：

```compile_fail,E0310
// This won't compile because T is not constrained to the static lifetime
// the reference needs
struct Foo<T> {
    foo: &'static T
}
```

类型定义中的类型参数具有与之相关的生命周期，表示其中存储的数据保证存在的时长。该生命周期必须与数据所需的存在时间一致，缺失表示此生命周期的约束会导致错误。

这将能够编译，因为类型参数具有相应的约束：

```
struct Foo<T: 'static> {
    foo: &'static T
}
```
