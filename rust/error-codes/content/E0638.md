此错误表明结构体、枚举或枚举变体必须非穷尽地匹配，因为其被标记为 `non_exhaustive`。

当在 crate 内部使用时，下游用户在匹配枚举时需要使用 `_` 模式，而在匹配结构体时则使用 `..` 模式。下游 crate 无法针对非穷尽枚举变体进行匹配。

例如，在下面的示例中，由于枚举被标记为 `non_exhaustive`，因此下游 crate 必须对其进行非穷尽匹配。

```rust,ignore (pseudo-Rust)
#[non_exhaustive]
pub enum Error {
    Message(String),
    Other,
}

impl Display for Error {
    fn fmt(&self, formatter: &mut fmt::Formatter) -> fmt::Result {
        // This will not error, despite being marked as non_exhaustive, as this
        // enum is defined within the current crate, it can be matched
        // exhaustively.
        let display = match self {
            Message(s) => s,
            Other => "other or unknown error",
        };
        formatter.write_str(display)
    }
}
```

下面提供了一个关于如何对非穷尽地匹配上述枚举的示例：

```rust,ignore (pseudo-Rust)
use mycrate::Error;

// This will not error as the non_exhaustive Error enum has been matched with a
// wildcard.
match error {
    Message(s) => ...,
    Other => ...,
    _ => ...,
}
```

同样，对于结构体，使用 `..` 模式进行匹配可以避免此错误。
