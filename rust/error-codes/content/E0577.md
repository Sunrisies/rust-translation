在可见性作用域中发现了模块之外的其他内容。

错误的代码示例：

```compile_fail,E0577,edition2018
pub enum Sea {}

pub (in crate::Sea) struct Shark; // error!

fn main() {}
```

`Sea` 不是模块，因此将其用于可见性路径是无效的。要解决此错误，需确保 `sea` 是一个模块。

请注意，可见性作用域只能应用于祖先节点！

```edition2018
pub mod sea {
    pub (in crate::sea) struct Shark; // ok!
}

fn main() {}
```
