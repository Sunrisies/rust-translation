方法中的 `self` 参数具有无效的泛型“接收者类型”。

错误的代码示例：

```compile_fail,E0801
struct Foo;

impl Foo {
    fn foo<R: std::ops::Deref<Target=Self>>(self: R) {}
}
```

或者，

```compile_fail,E0801
struct Foo;

impl Foo {
    fn foo(self: impl std::ops::Deref<Target=Self>) {}
}
```

方法接受一个特殊的第一个参数，称为 `self`。通常可以使用 `self`、`&self` 或 `&mut self`，它们分别是 `self: Self`、`self: &Self` 和 `self: &mut Self` 的语法糖。但也可以使用更复杂的 `self` 参数类型，例如 `std::rc::Rc<Self>`。通过夜间特性 [任意 self 类型][AST]，允许的 `Self` 类型集合可以扩展。这将使有效的 `Self` 类型扩展到任何实现 `std::ops::Deref<Target=Self>` 的类型，例如 `Rc<Self>`、`Box<Self>` 或您自己的智能指针。

然而，即使有该特性，`self` 类型也必须是具体的。不允许使用泛型 `self` 类型。具体来说，如果 `self` 类型是在方法上定义的类型参数，则会被拒绝。

以下情况是可以的：

```
struct Foo;

impl Foo {
    fn foo(self) {}
    fn foo2(self: std::rc::Rc<Self>) {} // or some other similar
        // smart pointer if you enable arbitrary self types and
        // the pointer implements Deref<Target=Self>
}
```

[AST]: https://doc.rust-lang.org/unstable-book/language-features/arbitrary-self-types.html
