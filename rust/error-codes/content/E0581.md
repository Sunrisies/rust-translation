在 `fn` 类型中，生命周期仅出现在返回类型中，而不出现在参数类型中。

错误的代码示例：

```compile_fail,E0581
fn main() {
    // Here, `'a` appears only in the return type:
    let x: for<'a> fn() -> &'a i32;
}
```

这里的问题在于生命周期没有被任何参数约束，因此无法确定其应该持续的时间。

为了解决这个问题，要么在参数中使用生命周期，要么使用 `'static` 生命周期。示例：

```
fn main() {
    // Here, `'a` appears only in the return type:
    let x: for<'a> fn(&'a i32) -> &'a i32;
    let y: fn() -> &'static i32;
}
```

注意：上述示例过去被编译器错误地接受了，但现在已经修正了。更多细节请参见 [issue #33685]。

[issue #33685]: https://github.com/rust-lang/rust/issues/33685
