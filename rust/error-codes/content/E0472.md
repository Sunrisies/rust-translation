此目标不支持内联汇编（`asm!`）。

错误代码示例：

```ignore (cannot-change-target)
// compile-flags: --target sparc64-unknown-linux-gnu
#![no_std]

use core::arch::asm;

fn main() {
    unsafe {
        asm!(""); // error: inline assembly is not supported on this target
    }
}
```

Rust 编译器并不支持所有目标上的内联汇编及 `asm!` 宏（之前为 `llvm_asm!`）。所有 Tier 1 目标都支持该宏，但 Tier 2 和 Tier 3 目标的支持情况无法保证（即使它们具有 `std` 支持）。请注意，此错误与 `error[E0658]: 内联汇编在此架构上尚未稳定` 相关，不同之处在于没有计划或正在进行 `E0472` 的支持工作。

目前没有简单的方法可以解决此问题，不过您可以考虑：* 确认是否真的需要内联汇编，是否有其他方法可以实现目标（如内联函数等）？ * 考虑将汇编代码外部编写，并在 Rust 中链接调用它。 * 考虑为 <https://github.com/rust-lang/rust> 贡献代码，帮助集成该目标的支持功能！
