类型别名中使用了不必要的类型参数。

错误的代码示例：

```compile_fail,E0091
type Foo<T> = u32; // error: type parameter `T` is never used
```
or:
```compile_fail,E0091
type Foo<A, B> = Box<A>; // error: type parameter `B` is never used
```

请检查是否编写了过多的参数。例如：

```
type Foo = u32; // ok!
```
```
type Foo<A> = Box<A>; // ok!
```
