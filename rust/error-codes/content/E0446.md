在公共关联类型签名中使用了私有类型或特质。

错误的代码示例：

```compile_fail,E0446
struct Bar;

pub trait PubTr {
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar; // error private type in public interface
}

fn main() {}
```

解决此错误有两种方式。第一种方法是仅将公共类型签名对同时拥有私有类型的模块公开。这可以通过使用 `pub(crate)` 或 `pub(in crate::my_mod::etc)` 来实现。示例：

```
struct Bar;

pub(crate) trait PubTr { // only public to crate root
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar;
}

fn main() {}
```

另一种解决此错误的方法是将私有类型公开。示例：

```

pub struct Bar; // we set the Bar trait public

pub trait PubTr {
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar;
}

fn main() {}
```
