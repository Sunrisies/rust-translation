# E08x 系列错误码

共 7 个错误码。

- [E0800](E0800.md) — 给定名称的类型或常量参数不在作用域内。
- [E0801](E0801.md) — 方法中的 self 参数具有无效的泛型“接收者类型”。
- [E0802](E0802.md) — derive(CoercePointee) 宏的目标对于有效使用存在不合适的规范。
- [E0803](E0803.md) — 某种特质实现返回了一个引用，但没有明确的生命周期将其与 self 关联起来。这种情况常见于需要明确生命周期边界的泛型特质实现中。
- [E0804](E0804.md) — 无法通过指针转换将自动特质添加到 dyn Trait 类型的边界中。
- [E0805](E0805.md) — 某个属性被传递了无效的参数数量
- [E0806](E0806.md) — 外部可实现的项与其声明不兼容。
