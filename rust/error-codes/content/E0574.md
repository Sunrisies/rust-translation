当预期使用某种结构、变体或联合类型时，却使用了其他类型的元素。

错误的代码示例：

```compile_fail,E0574
mod mordor {}

let sauron = mordor { x: () }; // error!

enum Jak {
    Daxter { i: isize },
}

let eco = Jak::Daxter { i: 1 };
match eco {
    Jak { i } => {} // error!
}
```

在所有这些错误中，都期望有一个类型。例如，在第一个错误中，我们试图实例化 `mordor` 模块，这是不可能的。如果您希望在模块内部实例化一个类型，可以按以下方式操作：

```
mod mordor {
    pub struct TheRing {
        pub x: usize,
    }
}

let sauron = mordor::TheRing { x: 1 }; // ok!
```

在第二个错误中，我们试图直接绑定 `Jak` 枚举，这也是不可能的：只能绑定其中的一个变体。具体操作如下：

```
enum Jak {
    Daxter { i: isize },
}

let eco = Jak::Daxter { i: 1 };
match eco {
    Jak::Daxter { i } => {} // ok!
}
```
