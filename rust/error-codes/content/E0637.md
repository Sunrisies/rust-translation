在非法位置使用了没有显式生命周期名称的 `'_` 或 `&T`。

错误的代码示例：

```compile_fail,E0106,E0637
fn underscore_lifetime<'_>(str1: &'_ str, str2: &'_ str) -> &'_ str {
                     //^^ `'_` is a reserved lifetime name
    if str1.len() > str2.len() {
        str1
    } else {
        str2
    }
}

fn without_explicit_lifetime<T>()
where
    T: Iterator<Item = &u32>,
                     //^ `&` without an explicit lifetime name
{
}

fn without_hrtb<T>()
where
    T: Into<&u32>,
          //^ `&` without an explicit lifetime name
{
}
```

首先，在某些地方不能将 `'_` 用作生命周期标识符，因为它被保留用于匿名生命周期。其次，没有显式生命周期名称的 `&T` 也不可在某些地方使用。要解决这些问题，可以使用小写字母如 `'a'，或者一系列小写字母如 `'foo'`。关于生命周期标识符的更多信息，请参阅 [这本书][bk-no]。关于在 Rust 2018 中使用匿名生命周期的更多信息，请参阅 [Rust 2018 博客文章][blog-al]。

修正后的示例：

```
fn underscore_lifetime<'a>(str1: &'a str, str2: &'a str) -> &'a str {
    if str1.len() > str2.len() {
        str1
    } else {
        str2
    }
}

fn without_explicit_lifetime<'a, T>()
where
    T: Iterator<Item = &'a u32>,
{
}

fn without_hrtb<T>()
where
    T: for<'foo> Into<&'foo u32>,
{
}
```
