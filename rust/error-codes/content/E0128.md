具有默认值的类型参数会使用前向声明的标识符。

错误的代码示例：

```compile_fail,E0128
struct Foo<T = U, U = ()> {
    field1: T,
    field2: U,
}
// error: generic parameters with a default cannot use forward declared
//        identifiers
```

类型参数的默认值只能使用在其之前出现的参数。由于类型参数是按顺序评估的，可以通过以下方式解决此问题：

```
struct Foo<U = (), T = U> {
    field1: T,
    field2: U,
}
```

请同时确认是否是由于名称冲突导致的现象，如果是的话，请重命名该类型参数。
