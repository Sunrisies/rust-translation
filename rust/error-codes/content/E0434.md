内部函数中使用的变量来自动态环境。

错误的代码示例：

```compile_fail,E0434
fn foo() {
    let y = 5;
    fn bar() -> u32 {
        y // error: can't capture dynamic environment in a fn item; use the
          //        || { ... } closure form instead.
    }
}
```

内部函数无法访问其所在的外部环境。要解决此错误，可以将该函数替换为闭包：

```
fn foo() {
    let y = 5;
    let bar = || {
        y
    };
}
```

或者将捕获的变量替换为一个常量或静态项：

```
fn foo() {
    static mut X: u32 = 4;
    const Y: u32 = 5;
    fn bar() -> u32 {
        unsafe {
            X = 3;
        }
        Y
    }
}
```
