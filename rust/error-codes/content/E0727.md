在 `async` 上下文中使用了 `yield` 子句。

错误的代码示例：

```compile_fail,E0727,edition2018
#![feature(coroutines, stmt_expr_attributes)]

fn main() {
    let coroutine = #[coroutine] || {
        async {
            yield;
        }
    };
}
```

在此示例中，`yield` 关键字被用于一个尚未支持的 `async` 块中。

要解决此错误，必须将 `yield` 移出 `async` 块中：

```edition2018
#![feature(coroutines, stmt_expr_attributes)]

fn main() {
    let coroutine = #[coroutine] || {
        yield;
    };
}
```
