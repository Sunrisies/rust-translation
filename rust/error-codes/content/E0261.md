使用了未声明的生命周期。

错误的代码示例：

```compile_fail,E0261
// error, use of undeclared lifetime name `'a`
fn foo(x: &'a str) { }

struct Foo {
    // error, use of undeclared lifetime name `'a`
    x: &'a str,
}
```

可以通过声明生命周期参数来修复这些问题：

```
struct Foo<'a> {
    x: &'a str,
}

fn foo<'a>(x: &'a str) {}
```

`impl` 块会单独声明生命周期参数。如果您实现的类型本身具有自己的生命周期参数，则需要在 `impl` 块中添加该参数。例如：

```compile_fail,E0261
struct Foo<'a> {
    x: &'a str,
}

// error,  use of undeclared lifetime name `'a`
impl Foo<'a> {
    fn foo<'a>(x: &'a str) {}
}
```

通过这样声明 `impl` 块即可解决此问题：

```
struct Foo<'a> {
    x: &'a str,
}

// correct
impl<'a> Foo<'a> {
    fn foo(x: &'a str) {}
}
```
