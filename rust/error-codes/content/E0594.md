一个不可变值被赋予了一个值。

错误的代码示例：

```compile_fail,E0594
struct SolarSystem {
    earth: i32,
}

let ss = SolarSystem { earth: 3 };
ss.earth = 2; // error!
```

要解决此错误，请使用 `mut` 关键字将 `ss` 声明为可变的：

```
struct SolarSystem {
    earth: i32,
}

let mut ss = SolarSystem { earth: 3 }; // declaring `ss` as mutable
ss.earth = 2; // ok!
```
