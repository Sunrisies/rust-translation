#### 注意：此错误代码已不再由编译器生成。

该类型未满足所需的生命周期要求。

错误的代码示例：

```compile_fail
use std::sync::Mutex;

struct MyString<'a> {
    data: &'a str,
}

fn i_want_static_closure<F>(a: F)
    where F: Fn() + 'static {}

fn print_string<'a>(s: Mutex<MyString<'a>>) {

    i_want_static_closure(move || {     // error: this closure has lifetime 'a
                                        //        rather than 'static
        println!("{}", s.lock().unwrap().data);
    });
}
```

在此示例中，闭包不满足 `'static` 生命周期约束。要解决此错误，需再次确认类型的生命周期。在这里，我们可以通过给 `s` 赋予静态生命周期来修复这个问题。

```
use std::sync::Mutex;

struct MyString<'a> {
    data: &'a str,
}

fn i_want_static_closure<F>(a: F)
    where F: Fn() + 'static {}

fn print_string(s: Mutex<MyString<'static>>) {

    i_want_static_closure(move || {     // ok!
        println!("{}", s.lock().unwrap().data);
    });
}
```
