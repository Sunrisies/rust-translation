#### 注意：此错误代码不再由编译器生成。

具有 `packed` 表示提示的类型包含带有 `align` 表示提示的字段。

错误的代码示例：

```ignore (no longer emitted)
#[repr(align(16))]
struct Aligned(i32);

#[repr(packed)] // error!
struct Packed(Aligned);
```

就像不能在同一类型上同时拥有 `align` 和 `packed` 表示提示一样，一个 `packed` 类型也不能包含带有 `align` 表示提示的其他类型。然而，你可以做相反的操作：

```
#[repr(packed)]
struct Packed(i32);

#[repr(align(16))] // ok!
struct Aligned(Packed);
```
