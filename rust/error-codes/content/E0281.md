#### 注意：此错误代码已不再由编译器生成。

您试图在期望该特质的位置提供未实现某些特质的类型。当使用基于 `Fn` 的类型时，通常会出现此错误。错误的代码示例如下：

```compile_fail
fn foo<F: Fn(usize)>(x: F) { }

fn main() {
    // type mismatch: ... implements the trait `core::ops::Fn<(String,)>`,
    // but the trait `core::ops::Fn<(usize,)>` is required
    // [E0281]
    foo(|y: String| { });
}
```

在这种情况下，问题在于 `foo` 被定义为接受一个类型为 `String` 的单个参数 `Fn`，但我们尝试传递给它的闭包需要一个类型为 `usize` 的单个参数。
