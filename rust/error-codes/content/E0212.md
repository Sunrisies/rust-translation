不能将 trait 的关联类型与无法推断的泛型参数一起使用。

错误的代码示例：

```compile_fail,E0212
pub trait Foo<T> {
    type A;

    fn get(&self, t: T) -> Self::A;
}

fn foo2<I : for<'x> Foo<&'x isize>>(
    field: I::A) {} // error!
```

在这个示例中，我们必须实例化 `'x'，而我们不知道应该使用哪种生命周期来实例化它。要解决这个问题，需要明确说明所涉及的具体生命周期。示例：

```
pub trait Foo<T> {
    type A;

    fn get(&self, t: T) -> Self::A;
}

fn foo3<I : for<'x> Foo<&'x isize>>(
    x: <I as Foo<&isize>>::A) {} // ok!


fn foo4<'a, I : for<'x> Foo<&'x isize>>(
    x: <I as Foo<&'a isize>>::A) {} // ok!
```
