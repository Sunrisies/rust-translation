在常量中使用了可变引用。

错误的代码示例：

```compile_fail,E0764
fn main() {
    const OH_NO: &'static mut usize = &mut 1; // error!
}
```

可变引用（`&mut`）只能用于常量函数，而不能用于静态或常量。这种限制是为了防止创建最终值中包含可变引用的常量。如果你有一个类型为 `&mut i32` 的常量，你可以通过该引用修改其值，从而使该常量本质上具有可变性。

虽然未来可能会有一种更精细的方案允许使用不可变引用，但目前选择了一种更为保守的方法。`const fn` 没有这个问题，因为借用检查器会防止 `const fn` 返回新的可变引用。

记住：不能在常量或静态中使用函数调用。然而，你可以在常量函数中完全使用它。

```
const fn foo(x: usize) -> usize {
    let mut y = 1;
    let z = &mut y;
    *z += x;
    y
}

fn main() {
    const FOO: usize = foo(10); // ok!
}
```
