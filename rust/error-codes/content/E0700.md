`impl Trait` 返回类型能够捕获那些未在 `impl Trait` 内部出现的生命周期参数。

错误的代码示例：

```compile_fail,E0700
use std::cell::Cell;

trait Trait<'a> { }

impl<'a, 'b> Trait<'b> for Cell<&'a u32> { }

fn foo<'x, 'y>(x: Cell<&'x u32>) -> impl Trait<'y>
where 'x: 'y
{
    x
}
```

在此示例中，函数 `foo` 返回一个类型为 `Cell<&'x u32>` 的值，该值引用了生命周期 `'x`。然而，返回类型被声明为 `impl Trait<'y>`，这意味着 `foo` 返回的是“一个实现了 `Trait<'y>` 的某种类型”，但这也表明返回类型**仅能捕获引用生命周期 `'y'` 的数据**。不过在这种情况下，我们实际上是在引用具有生命周期 `'x'` 的数据，因此该函数存在错误。

要解决这个问题，必须在返回类型中明确引用生命周期 `'x'`。例如，将返回类型改为 `impl Trait<'y> + 'x` 即可生效：

```
use std::cell::Cell;

trait Trait<'a> { }

impl<'a,'b> Trait<'b> for Cell<&'a u32> { }

fn foo<'x, 'y>(x: Cell<&'x u32>) -> impl Trait<'y> + 'x
where 'x: 'y
{
    x
}
```
