不应直接实现 Unsize trait。所有 Unsize 的实现均由编译器自动提供。

错误的代码示例：

```compile_fail,E0328
#![feature(unsize)]

use std::marker::Unsize;

pub struct MyType;

impl<T> Unsize<T> for MyType {}
```

如果您正在定义自己的智能指针类型，并希望使用 [DST 强制转换系统][RFC 982] 将有大小的类型转换为无大小的类型，请使用 [`CoerceUnsized`]。

```
#![feature(coerce_unsized)]

use std::ops::CoerceUnsized;

pub struct MyType<T: ?Sized> {
    field_with_unsized_type: T,
}

impl<T, U> CoerceUnsized<MyType<U>> for MyType<T>
    where T: CoerceUnsized<U> {}
```

[RFC 982]: https://rust-lang.github.io/rfcs/0982-dst-coercion.html
[`CoerceUnsized`]: https://doc.rust-lang.org/std/ops/trait.CoerceUnsized.html
