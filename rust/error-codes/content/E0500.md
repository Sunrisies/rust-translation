一个被借用的变量被一个闭包使用。

错误的代码示例：

```compile_fail,E0500
fn you_know_nothing(jon_snow: &mut i32) {
    let nights_watch = &jon_snow;
    let starks = || {
        *jon_snow = 3; // error: closure requires unique access to `jon_snow`
                       //        but it is already borrowed
    };
    println!("{}", nights_watch);
}
```

在这里，`jon_snow` 已经被 `nights_watch` 引用借用，因此它无法同时被 `starks` 闭包借用。要解决此问题，可以在借用结束之后创建该闭包：

```
fn you_know_nothing(jon_snow: &mut i32) {
    let nights_watch = &jon_snow;
    println!("{}", nights_watch);
    let starks = || {
        *jon_snow = 3;
    };
}
```

或者，如果类型实现了 `Clone` trait，你可以在两个闭包之间进行克隆操作：

```
fn you_know_nothing(jon_snow: &mut i32) {
    let mut jon_copy = jon_snow.clone();
    let starks = || {
        *jon_snow = 3;
    };
    println!("{}", jon_copy);
}
```
