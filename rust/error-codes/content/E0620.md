尝试将值转换为非大小类型。

错误的代码示例：

```compile_fail,E0620
let x = &[1_usize, 2] as [usize]; // error: cast to unsized type: `&[usize; 2]`
                                  //        as `[usize]`
```

在 Rust 中，某些类型在编译时没有已知的大小。例如，像 `[u32]` 这样的切片类型，其元素数量在编译时无法确定，因此也无法计算整体大小。因此，这类类型只能通过引用（如 `&T` 或 `&mut T`）或其他指针类型（如 `Box` 或 `Rc`）来操作。尝试将值转换为引用试试：

```
let x = &[1_usize, 2] as &[usize]; // ok!
```
