#### 注意：此错误代码不再由编译器生成。

当试图修改存储在不可变容器中的可变引用目标时，就会出现此错误。

例如，将 `&mut` 存储在不可变的 `Box` 中时可能会出现这种情况：

```
let mut x: i64 = 1;
let y: Box<_> = Box::new(&mut x);
**y = 2; // error, cannot assign to data in an immutable container
```

可以通过使容器变为可变来修复此错误：

```
let mut x: i64 = 1;
let mut y: Box<_> = Box::new(&mut x);
**y = 2;
```

也可以使用具有内部可变性类型的类型，如 `Cell` 或 `RefCell` 来修复此问题。

```
use std::cell::Cell;

let x: i64 = 1;
let y: Box<Cell<_>> = Box::new(Cell::new(x));
y.set(2);
```
