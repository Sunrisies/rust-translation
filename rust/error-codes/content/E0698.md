#### 注意：此错误代码不再由编译器生成。

使用协程（或异步）时，所有类型变量必须被绑定，才能构建出一个协程。

错误的代码示例：

```edition2018,compile_fail,E0282
async fn bar<T>() -> () {}

async fn foo() {
    bar().await; // error: cannot infer type for `T`
}
```

在上述示例中，`T` 是编译器无法确定的。要解决这个问题，你必须将 `T` 绑定到一个具体的类型，例如 `String`，这样才能构建出协程：

```edition2018
async fn bar<T>() -> () {}

async fn foo() {
    bar::<String>().await;
    //   ^^^^^^^^ specify type explicitly
}
```
