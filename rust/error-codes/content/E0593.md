您尝试传递一个基于 `Fn` 的类型，但提供的参数数量与预期不符。

错误的代码示例：

```compile_fail,E0593
fn foo<F: Fn()>(x: F) { }

fn main() {
    // [E0593] closure takes 1 argument but 0 arguments are required
    foo(|y| { });
}
```

您必须提供与基于 `Fn` 的类型所期望的相同数量的参数。因此，为了修复前面的示例，我们需要移除 `y` 参数：

```
fn foo<F: Fn()>(x: F) { }

fn main() {
    foo(|| { }); // ok!
}
```
