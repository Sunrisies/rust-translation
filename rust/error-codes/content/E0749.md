在负实现中添加了一个项。

错误的代码示例：

```compile_fail,E0749
# #![feature(negative_impls)]
trait MyTrait {
    type Foo;
}

impl !MyTrait for u32 {
    type Foo = i32; // error!
}
```

负实现不允许包含任何项。负实现表明一个特质**未**被实现（也永远无法被实现），因此无需指定特质方法或其他项的值。

解决此问题的一种方法是移除负实现中的项：

```
# #![feature(negative_impls)]
trait MyTrait {
    type Foo;
}

impl !MyTrait for u32 {}
```
