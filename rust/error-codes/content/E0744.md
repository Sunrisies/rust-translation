#### 注意：此错误代码已不再由编译器生成。

在 const 上下文中使用了不受支持的表达式。

错误的代码示例：

```ignore (removed error code)
const _: i32 = {
    async { 0 }.await
};
```

目前，在 `const`、`static` 或 `const fn` 内部禁止使用 `.await`。

未来可能允许使用，但实现尚未完成。请查看关于 [`async`]在 `const fn` 中的跟踪问题。
