判别式值出现了多次。

错误的代码示例：

```compile_fail,E0081
enum Enum {
    P = 3,
    X = 3, // error!
    Y = 5,
}
```

枚举判别式用于区分内存中存储的枚举变体。此错误表明同一个值被用于两个或更多变体，导致无法区分它们。

```
enum Enum {
    P,
    X = 3, // ok!
    Y = 5,
}
```

请注意，没有手动指定判别器的变体会从 0 开始按从上到下的顺序编号，因此与看似不相关的变体可能会产生冲突。

```compile_fail,E0081
enum Bad {
    X,
    Y = 0, // error!
}
```

在这里，当遇到 `Y` 时，`X` 已经被指定了判别式为 0，因此会发生冲突。
