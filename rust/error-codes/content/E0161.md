在编译时无法确定大小的值被移动了。

错误的代码示例：

```compile_fail,E0161
trait Bar {
    fn f(self);
}

impl Bar for i32 {
    fn f(self) {}
}

fn main() {
    let b: Box<dyn Bar> = Box::new(0i32);
    b.f();
    // error: cannot move a value of type dyn Bar: the size of dyn Bar cannot
    //        be statically determined
}
```

在 Rust 中，只有当值的大小在编译时已知时，才能将其移动。

为了绕过这一限制，可以考虑通过引用“隐藏”该值：`&x` 或 `&mut x`。由于引用具有固定的大小，因此你可以像通常那样移动它。示例：

```
trait Bar {
    fn f(&self);
}

impl Bar for i32 {
    fn f(&self) {}
}

fn main() {
    let b: Box<dyn Bar> = Box::new(0i32);
    b.f();
    // ok!
}
```
