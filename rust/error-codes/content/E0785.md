在动态自动特质上编写了固有的 `impl`。

错误的代码示例：

```compile_fail,E0785
#![feature(auto_traits)]

auto trait AutoTrait {}

impl dyn AutoTrait {}
```

动态对象允许任意数量的自动特质，最多包含一个非自动特质。该非自动特质成为“主特质”。

在检查动态特质的 `impl` 是否一致时，通常只考虑主特质。由于错误代码没有主特质，因此根本无法实现。

示例演示：

```
#![feature(auto_traits)]

trait PrincipalTrait {}

auto trait AutoTrait {}

impl dyn PrincipalTrait + AutoTrait + Send {}
```
