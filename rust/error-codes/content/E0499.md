某个变量被多次作为可变引用使用。

错误的代码示例：

```compile_fail,E0499
let mut i = 0;
let mut x = &mut i;
let mut a = &mut i;
x;
// error: cannot borrow `i` as mutable more than once at a time
```

请注意，在 Rust 中，你可以拥有多个不可变引用，或者一个可变引用。如需了解更多细节，您可以阅读[References & 借用][references-and-借用]章节。


Example:

```
let mut i = 0;
let mut x = &mut i; // ok!

// or:
let mut i = 0;
let a = &i; // ok!
let b = &i; // still ok!
let c = &i; // still ok!
b;
a;
```

[references-and-borrowing]: https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html
