尝试获取一个关联类型，但该类型具有歧义。

错误的代码示例：

```compile_fail,E0221
trait T1 {}
trait T2 {}

trait Foo {
    type A: T1;
}

trait Bar : Foo {
    type A: T2;
    fn do_something() {
        let _: Self::A;
    }
}
```

在这个示例中，`Foo` 定义了一个关联类型 `A`。`Bar` 从 `Foo` 继承该类型，并定义了同名的另一个关联类型。因此，当我们尝试使用 `Self::A` 时，无法明确是指 `Foo` 定义的 `A`，还是 `Bar` 定义的 `A`。

有两种方法可以解决此问题。第一种方法是直接重命名其中一个类型。或者，可以使用以下语法指定期望的类型：

```
trait T1 {}
trait T2 {}

trait Foo {
    type A: T1;
}

trait Bar : Foo {
    type A: T2;
    fn do_something() {
        let _: <Self as Bar>::A;
    }
}
```
