#### 注意：此错误代码已不再由编译器生成。

尝试为枚举实现 `Copy` trait 失败，因为其中一个变体未实现 `Copy`。要修复此问题，必须为该变体实现 `Copy`。请注意，这可能不可行，如以下示例所示：

```compile_fail,E0204
enum Foo {
    Bar(Vec<u32>),
    Baz,
}

impl Copy for Foo { }
```

此示例失败是因为 `Vec<T>` 没有为任何 `T` 实现 `Copy`。

以下是另一个会失败的示例：

```compile_fail,E0204
#[derive(Copy)]
enum Foo<'a> {
    Bar(&'a mut bool),
    Baz,
}
```

此示例失败是因为即使 `T` 是 `Copy`，`&mut T` 也不是 `Copy`（这与 `&T` 的行为不同，`&T` 始终为 `Copy`）。
