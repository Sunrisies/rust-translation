在创建 `drop-check 规则` 时达到了递归限制。

错误代码示例：

```compile_fail,E0320
enum A<T> {
    B,
    C(T, Box<A<(T, T)>>)
}

fn foo<T>() {
    A::<T>::B; // error: overflow while adding drop-check rules for A<T>
}
```

Rust 编译器必须能够理解某个类型如何被 [`Drop`]处理，进而理解其字段的类型，以便生成正确丢弃值的逻辑。上述代码示例中的类型无法进行这种推理，因为它具有递归特性。请注意，这*不是*[E0072](E0072.html)的情况，在那种情况下类型的大小是无限的；这里的类型大小是有限的，但任何试图对其执行 `Drop` 的操作都会无限递归。如需了解更多信息，请阅读[`Drop` 文档](../std/ops/trait.Drop.html)。

无法定义具有递归 `drop-check 规则` 的类型。所有此类递归必须被移除。
