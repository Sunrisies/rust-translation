一个绑定遮蔽了它不应该遮蔽的内容。

匹配变量或变量具有已被其他内容使用的名称，例如：

* 结构体名 * 枚举变体 * 静态成员 * 关联常量

当在模式中使用带有字段的枚举变体，但缺少其字段时，也可能会出现此错误。

```compile_fail
enum Enum {
    WithField(i32)
}

use Enum::*;
match WithField(1) {
    WithField => {} // error: missing (_)
}
```

匹配绑定无法遮蔽静态成员：

```compile_fail,E0530
static TEST: i32 = 0;

let r = 123;
match r {
    TEST => {} // error: name of a static
}
```

已修复示例：

```
static TEST: i32 = 0;

let r = 123;
match r {
    some_value => {} // ok!
}
```

or

```
const TEST: i32 = 0; // const, not static

let r = 123;
match r {
    TEST => {} // const is ok!
    other_values => {}
}
```
