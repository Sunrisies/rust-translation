在特质实现中缺少项目。

错误的代码示例：

```compile_fail,E0046
trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {}
// error: not all trait items implemented, missing: `foo`
```

当试图让某种类型实现特质 `Foo` 时，至少必须提供所有 `Foo` 所需方法的实现（即没有默认实现的那些方法），以及任何所需的特质项目，如关联类型或常量。示例：

```
trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {
    fn foo() {} // ok!
}
```
