在枚举上派生 `Default` 特质时，并未指定默认变体。

错误的代码示例：

```compile_fail,E0665
#[derive(Default)]
enum Food {
    Sweet,
    Salty,
}
```

无法在枚举上派生 `Default` 特质，因为编译器不知道默认情况下应选择哪个值，而对于结构体来说则可行，只要其所有字段都实现了 `Default` 特质即可。

如果所需的默认变体没有有效数据，可以使用 `#[default]` 注解来派生它：

```
#[derive(Default)]
enum Food {
    #[default]
    Sweet,
    Salty,
}
```

如果默认变体有有效数据，则必须手动在枚举上实现 `Default` 特质：

```
enum Food {
    Sweet(i32),
    Salty,
}

impl Default for Food {
    fn default() -> Food {
        Food::Sweet(1)
    }
}
```
