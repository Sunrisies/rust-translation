稳定性属性中缺失 `note` 值。

错误的代码示例：

```compile_fail,E0543
#![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[stable(since = "0.1.0", feature = "_deprecated_fn")]
#[deprecated(
    since = "1.0.0"
)] // invalid
fn _deprecated_fn() {}
```

要解决此问题，您需要提供 `note` 字段。示例：

```
#![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[stable(since = "0.1.0", feature = "_deprecated_fn")]
#[deprecated(
    since = "1.0.0",
    note = "explanation for deprecation"
)] // ok!
fn _deprecated_fn() {}
```

有关更多细节，请参阅《Rust 的构建过程与“Nightly Rust”》附录以及 Rustc 开发指南中的[稳定性属性][stability-attributes]部分。
