#### 注意：此错误代码已不再由编译器生成。

试图导入无法导入的类型。当尝试从特质中导入类型时，可能会出现这种情况。

错误的代码示例：

```
#![feature(import_trait_associated_functions)]

mod foo {
    pub trait MyTrait {
        type SomeType;
    }
}

use foo::MyTrait::SomeType;
// error: `SomeType` is not directly importable

fn main() {}
```

直接导入属于特质的类型是无效的。
