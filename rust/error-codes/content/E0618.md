试图调用并非函数或方法的对象。

错误的代码示例：

```compile_fail,E0618
enum X {
    Entry,
}

X::Entry(); // error: expected function, tuple struct or tuple variant,
            // found `X::Entry`

// Or even simpler:
let x = 0i32;
x(); // error: expected function, tuple struct or tuple variant, found `i32`
```

只有函数和方法才能通过 `()` 被调用。例如：

```
// We declare a function:
fn i_am_a_function() {}

// And we call it:
i_am_a_function();
```
