一个常量值未能被正确计算。

错误的代码示例：

```compile_fail,E0080
enum Enum {
    X = (1 << 500),
    Y = (1 / 0),
}
```

此错误表明编译器无法合理计算需要计算的常量表达式。尝试除以 0 或导致整数溢出是引发此错误的两种方式。

确保所给出的表达式可以按期望的整数类型进行计算。

有关使用 [`repr` 属性][repr-attribute] 在枚举上设置自定义整数类型的更多信息，请参阅参考手册中的 [Discriminants] 部分。

[discriminants]: https://doc.rust-lang.org/reference/items/enumerations.html#discriminants
[repr-attribute]: https://doc.rust-lang.org/reference/type-layout.html#representations
