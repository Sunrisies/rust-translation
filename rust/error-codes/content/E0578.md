#### 注意：此错误代码已不再由编译器生成。

无法找到模块，因此无法确定其可见性。

错误的代码示例：

```ignore (no longer emitted)
foo!();

pub (in ::Sea) struct Shark; // error!

fn main() {}
```

由于调用了 `foo` 宏，编译器推测缺失的模块可能位于该宏内部，但由于找不到宏定义而失败。

要修复此错误，请确保模块在作用域内：

```edition2018
pub mod Sea {
    pub (in crate::Sea) struct Shark;
}

fn main() {}
```
