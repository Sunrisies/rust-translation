#### 注意：此错误代码已不再由编译器生成。

`ffi_const` 属性被用于了非外部函数声明的地方。

错误的代码示例：

```ignore (no longer emitted)
#![feature(ffi_const)]

#[unsafe(ffi_const)] // error!
pub fn foo() {}
# fn main() {}
```

`ffi_const` 属性只能用于那些除了返回值外没有副作用的外部函数声明。

```
#![feature(ffi_const)]

extern "C" {
    #[unsafe(ffi_const)] // ok!
    pub fn strlen(s: *const std::ffi::c_char) -> usize;
}
# fn main() {}
```

您可以在 [不稳定的 Rust 手册] 中获取更多相关信息。

[unstable Rust Book]: https://doc.rust-lang.org/nightly/unstable-book/language-features/ffi-const.html
