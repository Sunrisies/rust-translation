使用递归而不进行装箱的 [`async`] 函数。

错误的代码示例：

```edition2018,compile_fail,E0733
async fn foo(n: usize) {
    if n > 0 {
        foo(n - 1).await;
    }
}
```

递归调用可以进行装箱：

```edition2018
async fn foo(n: usize) {
    if n > 0 {
        Box::pin(foo(n - 1)).await;
    }
}
```

`Box<...>` 确保结果具有已知的大小，并且需要 pin 以将其保留在相同的内存位置。

或者，可以将主体进行装箱：

```edition2018
use std::future::Future;
use std::pin::Pin;
fn foo(n: usize) -> Pin<Box<dyn Future<Output = ()>>> {
    Box::pin(async move {
        if n > 0 {
            foo(n - 1).await;
        }
    })
}
```

[`async`]: https://doc.rust-lang.org/std/keyword.async.html
