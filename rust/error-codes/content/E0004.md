此错误表明编译器无法保证匹配表达式对一种或多种可能的输入具有匹配的模式。为了向匹配表达式赋值，或者确定执行流程，需要确保有确定的匹配情况。

错误的代码示例：

```compile_fail,E0004
enum Terminator {
    HastaLaVistaBaby,
    TalkToMyHand,
}

let x = Terminator::HastaLaVistaBaby;

match x { // error: non-exhaustive patterns: `HastaLaVistaBaby` not covered
    Terminator::TalkToMyHand => {}
}
```

如果您遇到此错误，必须修改您的模式，以确保输入类型的每一个可能值都能被匹配。对于变体数量较少的类型（如枚举），您应该明确覆盖所有情况。或者，可以在其他所有模式之后添加下划线 `_` 通配符模式，以匹配“任何其他内容”。示例：

```
enum Terminator {
    HastaLaVistaBaby,
    TalkToMyHand,
}

let x = Terminator::HastaLaVistaBaby;

match x {
    Terminator::TalkToMyHand => {}
    Terminator::HastaLaVistaBaby => {}
}

// or:

match x {
    Terminator::TalkToMyHand => {}
    _ => {}
}
```
