无法在匿名导入中使用 `doc(inline)` 方法

错误的代码示例：

```ignore (cannot-doctest-multicrate-project)

#[doc(inline)] // error: invalid doc argument
pub use foo::Foo as _;
```

匿名导入总是带有 `#[doc(noinline)]` 属性。要修复此错误，请移除 `#[doc(inline)]` 属性。

Example:

```ignore (cannot-doctest-multicrate-project)

pub use foo::Foo as _;
```
