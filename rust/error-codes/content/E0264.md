使用了未知的外部语言项。

错误的代码示例：

```compile_fail,E0264
#![feature(lang_items)]
#![allow(internal_features)]

extern "C" {
    #[lang = "copy"] // error: unknown external lang item: `copy`
    fn copy();
}
```

可用的外部语言项列表位于 `compiler/rustc_hir/src/weak_lang_items.rs` 中。示例：

```
#![feature(lang_items)]
#![allow(internal_features)]

extern "C" {
    #[lang = "panic_impl"] // ok!
    fn cake();
}
```
