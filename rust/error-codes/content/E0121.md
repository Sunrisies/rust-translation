在项目签名中的类型里使用了类型占位符 `_`。

错误的代码示例：

```compile_fail,E0121
fn foo() -> _ { 5 } // error

static BAR: _ = "test"; // error
```

在这种情况下，需要显式地提供类型：

```
fn foo() -> i32 { 5 } // ok!

static BAR: &str = "test"; // ok!
```

类型占位符 `_` 可以在项目签名之外使用，如下所示：

```
let x = "a4a".split('4')
    .collect::<Vec<_>>(); // No need to precise the Vec's generic type.
```
