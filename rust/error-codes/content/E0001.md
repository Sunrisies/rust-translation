#### 注意：此错误代码已不再由编译器生成。

该错误表明，对于所匹配的表达式的所有可能值而言，与指定模式对应的表达式分支永远不会被访问到，因为其中一个前置模式会匹配到该表达式。

这意味着前置模式中的某些可能过于通用，而当前模式则过于具体，或者顺序不正确。

例如，以下 `match` 块具有过多的分支：

```
match Some(0) {
    Some(bar) => {/* ... */}
    x => {/* ... */} // This handles the `None` case
    _ => {/* ... */} // All possible cases have already been handled
}
```

`match` 块中的模式按顺序排列进行匹配，因此，比如将通配符分支放在更具体的分支之上会使得后者变得无关紧要。

确保匹配分支的顺序正确，并删除任何多余的分支。
