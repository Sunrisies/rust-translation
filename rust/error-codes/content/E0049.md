对Trait方法的实现使用了错误的类型或常量参数数量。

错误代码示例：

```compile_fail,E0049
trait Foo {
    fn foo<T: Default>(x: T) -> Self;
}

struct Bar;

// error: method `foo` has 0 type parameters but its trait declaration has 1
// type parameter
impl Foo for Bar {
    fn foo(x: bool) -> Self { Bar }
}
```

例如，`Foo` Trait有一个带有类型参数`T`的方法`foo`，但针对类型`Bar`的`foo`实现缺少该参数。要修复此错误，必须使它们具有相同的类型参数：

```
trait Foo {
    fn foo<T: Default>(x: T) -> Self;
}

struct Bar;

impl Foo for Bar {
    fn foo<T: Default>(x: T) -> Self { // ok!
        Bar
    }
}
```
