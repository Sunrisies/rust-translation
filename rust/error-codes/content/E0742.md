可见性仅限于不是当前项目的祖先的模块。

错误的代码示例：

```compile_fail,E0742,edition2018
pub mod sea {}

pub (in crate::sea) struct Shark; // error!

fn main() {}
```

要解决此错误，需要将 `Shark` 结构体移动到 `sea` 模块中：

```edition2018
pub mod sea {
    pub (in crate::sea) struct Shark; // ok!
}

fn main() {}
```

当然，只要您引用的模块是祖先模块，就可以这样做。

```edition2018
pub mod earth {
    pub mod sea {
        pub (in crate::earth) struct Shark; // ok!
    }
}

fn main() {}
```
