编译时常量变量指的是线程局部静态变量。

错误的代码示例：

```compile_fail,E0625
#![feature(thread_local)]

#[thread_local]
static X: usize = 12;

const Y: usize = 2 * X;
```

静态和常量变量可以引用其他常量变量，但常量变量不能引用线程局部静态变量。在示例中，`Y`无法引用`X`。为了解决这个问题，可以将值提取为常量并使用：

```
#![feature(thread_local)]

const C: usize = 12;

#[thread_local]
static X: usize = C;

const Y: usize = 2 * C;
```
