依赖项使用不同版本的 `rustc` 进行编译。

错误代码示例：

`a.rs`
```ignore (cannot-link-with-other-tests)
// compiled with stable `rustc`

#[crate_type = "lib"]
```

`b.rs`
```ignore (cannot-link-with-other-tests)
// compiled with nightly `rustc`

#[crate_type = "lib"]

extern crate a; // error: found crate `a` compiled by an incompatible version
                //        of rustc
```

当用于编译库的 `rustc` 版本与二进制文件元数据中存储的依赖项版本不一致时，就会引发此错误。Rust 二进制文件的许多部分都不稳定。例如，Rust ABI 在不同编译器版本之间并不稳定。这意味着编译器无法确定在不同编译器版本之间如何调用函数，因此会出现此错误。

可以通过以下方法解决此问题：* 使用 [Cargo](../cargo/index.html)——Rust 包管理器及 [Rustup](https://rust-lang.github.io/rustup/)——Rust 工具链安装程序来自动修复该问题。* 使用统一的 `rustc` 版本重新编译库组件。
