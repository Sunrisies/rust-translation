#### 注意：此错误代码不再由编译器生成

插件 `..` 仅存在于 rlib 格式中，但必须以 dylib 格式提供。

错误的代码示例：

`rlib-plugin.rs`
```ignore (needs-linkage-with-other-tests)
#![crate_type = "rlib"]
#![feature(rustc_private)]

extern crate rustc_middle;
extern crate rustc_driver;

use rustc_driver::plugin::Registry;

#[no_mangle]
fn __rustc_plugin_registrar(_: &mut Registry) {}
```

`main.rs`
```ignore (needs-linkage-with-other-tests)
#![feature(plugin)]
#![plugin(rlib_plugin)] // error: plugin `rlib_plugin` only found in rlib
                        //        format, but must be available in dylib

fn main() {}
```

编译器提供了插件接口，以便修改编译过程（添加检查器等）。插件必须定义在其自己的 crates 中（类似于 [proc-宏](../reference/procedural-macros.html) 的隔离方式），然后被编译并链接到另一个 crate 中。Plugin crates *必须* 以动态链接的 dylib 格式进行编译，而不是静态链接的 rlib 格式。有关不同输出类型的更多信息，请参阅 Rust 参考手册中的 [此部分](../reference/linkage.html)。

通过以 dylib 格式重新编译插件 crate，即可轻松修复此错误。
