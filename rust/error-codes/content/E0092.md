#### 注意：此错误代码不再由编译器生成。

定义了一个未定义的原子操作函数。

错误的代码示例：

```ignore (no longer emitted)
#![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn atomic_foo(); // error: unrecognized atomic operation
                        //        function
```

请检查是否误写了函数的名称。所有内联函数均定义在 Rust 源代码的 `library/core/src/intrinsics` 中。
