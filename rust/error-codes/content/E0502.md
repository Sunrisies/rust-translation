一个已经以特定可变性（可变或不可变）被引用的变量，再次以不同的可变性被引用。

错误的代码示例：

```compile_fail,E0502
fn bar(x: &mut i32) {}
fn foo(a: &mut i32) {
    let y = &a; // a is borrowed as immutable.
    bar(a); // error: cannot borrow `*a` as mutable because `a` is also borrowed
            //        as immutable
    println!("{}", y);
}
```

要解决此错误，在尝试使用不同可变性访问该变量之前，确保没有对该变量的其他引用：

```
fn bar(x: &mut i32) {}
fn foo(a: &mut i32) {
    bar(a);
    let y = &a; // ok!
    println!("{}", y);
}
```
