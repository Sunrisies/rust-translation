#### 注意：此错误代码已不再由编译器生成。

为某个函数提供的类型参数数量不足。例如：

```compile_fail,E0107
fn foo<T, U>() {}

fn main() {
    foo::<f64>(); // error: wrong number of type arguments: expected 2, found 1
}
```

请注意，如果一个函数需要多个类型参数，但您希望编译器自动推断其中一些参数，可以使用类型占位符：

```compile_fail,E0107
fn foo<T, U>(x: T) {}

fn main() {
    let x: bool = true;
    foo::<f64>(x);    // error: wrong number of type arguments:
                      //        expected 2, found 1
    foo::<_, f64>(x); // same as `foo::<bool, f64>(x)`
}
```
