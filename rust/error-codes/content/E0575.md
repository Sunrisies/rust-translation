给出了一个类型或关联类型之外的其他内容。

错误的代码示例：

```compile_fail,E0575
enum Rick { Morty }

let _: <u8 as Rick>::Morty; // error!

trait Age {
    type Empire;
    fn Mythology() {}
}

impl Age for u8 {
    type Empire = u16;
}

let _: <u8 as Age>::Mythology; // error!
```

在这两种情况下，我们都在声明一个变量（名为 `_`），并为其指定一个类型。然而，`<u8 as Rick>::Morty` 和 `<u8 as Age>::Mythology` 并非类型，因此编译器会抛出错误。

`<u8 as Rick>::Morty` 是一个枚举变体，不能将变体作为类型使用，必须直接使用该枚举：

```
enum Rick { Morty }

let _: Rick; // ok!
```

`<u8 as Age>::Mythology` 是特质方法，显然不是类型。不过，`Age` 特质提供了一个关联类型 `Empire`，可以作为类型使用：

```
trait Age {
    type Empire;
    fn Mythology() {}
}

impl Age for u8 {
    type Empire = u16;
}

let _: <u8 as Age>::Empire; // ok!
```
