在方法调用过程中，值会根据需要自动被解引用多次，以使其类型与方法的接收者相匹配。需要注意的是，编译器仅会尝试解引用最多达到递归限制次数（该限制可通过 `recursion_limit` 属性设置）。

以一个人为设计的示例为例：

```compile_fail,E0055
#![recursion_limit="4"]

struct Foo;

impl Foo {
    fn foo(&self) {}
}

fn main() {
    let foo = Foo;
    let ref_foo = &&&&&Foo;

    // error, reached the recursion limit while auto-dereferencing `&&&&&Foo`
    ref_foo.foo();
}
```

一种解决方案可能是增加递归限制。请注意，可能会出现无限次的解引用递归情况，此时唯一的解决方式就是以某种方式中断递归过程。
