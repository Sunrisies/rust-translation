内部项不会继承其嵌入项的通用参数。

错误的代码示例：

```compile_fail,E0401
fn foo<T>(x: T) {
    fn bar(y: T) { // T is defined in the "outer" function
        // ..
    }
    bar(x);
}
```

如下情况也是如此：

```compile_fail,E0401
fn foo<T>(x: T) {
    type MaybeT = Option<T>;
    // ...
}
```

或者这种情形：

```compile_fail,E0401
fn foo<T>(x: T) {
    struct Foo {
        x: T,
    }
    // ...
}
```

嵌套在其他项中的项基本上与顶层项相同，只是它们只能从其所处的项中使用。

对此有几种解决方案。

如果项是函数，可以使用闭包：

```
fn foo<T>(x: T) {
    let bar = |y: T| { // explicit type annotation may not be necessary
        // ..
    };
    bar(x);
}
```

对于通用项，可以复制参数：

```
fn foo<T>(x: T) {
    fn bar<T>(y: T) {
        // ..
    }
    bar(x);
}
```

```
fn foo<T>(x: T) {
    type MaybeT<T> = Option<T>;
}
```

同时务必复制所有边界条件：

```
fn foo<T: Copy>(x: T) {
    fn bar<T: Copy>(y: T) {
        // ..
    }
    bar(x);
}
```

```
fn foo<T: Copy>(x: T) {
    struct Foo<T: Copy> {
        x: T,
    }
}
```

这可能需要在函数体中添加额外的类型提示。

如果项是 `impl` 中的函数，定义私有辅助函数可能更简便：

```
# struct Foo<T>(T);
impl<T> Foo<T> {
    pub fn foo(&self, x: T) {
        self.bar(x);
    }

    fn bar(&self, y: T) {
        // ..
    }
}
```

对于特质中的默认 `impl`，私有辅助解决方案无法使用，但闭包或复制参数仍然有效。
