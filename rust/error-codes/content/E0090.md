#### 注意：此错误代码已不再由编译器生成。

您提供的生命周期参数数量不足。示例：

```compile_fail,E0107
fn foo<'a: 'b, 'b: 'a>() {}

fn main() {
    foo::<'static>(); // error: wrong number of lifetime arguments:
                      //        expected 2, found 1
}
```

请检查您是否提供了正确的生命周期参数数量。示例：

```
fn foo<'a: 'b, 'b: 'a>() {}

fn main() {
    foo::<'static, 'static>();
}
```
