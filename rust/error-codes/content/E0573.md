当预期需要一个类型时，却使用了其他内容。

错误的代码示例：

```compile_fail,E0573
enum Dragon {
    Born,
}

fn oblivion() -> Dragon::Born { // error!
    Dragon::Born
}

const HOBBIT: u32 = 2;
impl HOBBIT {} // error!

enum Wizard {
    Gandalf,
    Saruman,
}

trait Isengard {
    fn wizard(_: Wizard::Saruman); // error!
}
```

在所有这些错误中，都期望有一个类型。例如，在第一个错误中，如果我们想从 `Dragon` 枚举返回 `Born` 变体，我们必须让函数返回枚举本身而不是其变体：

```
enum Dragon {
    Born,
}

fn oblivion() -> Dragon { // ok!
    Dragon::Born
}
```

在第二个错误中，你不能对项目本身进行实现，只能对类型进行实现。如果想要做类似的事情，我们需要创建一个新的类型：

```
struct Hobbit(u32); // we create a new type

const HOBBIT: Hobbit = Hobbit(2);
impl Hobbit {} // ok!
```

在第三个案例中，我们试图只期望 `Wizard` 枚举的一个变体，这是不可能的。为了让它正常工作，我们需要在 `Wizard` 枚举上使用模式匹配：

```
enum Wizard {
    Gandalf,
    Saruman,
}

trait Isengard {
    fn wizard(w: Wizard) { // ok!
        match w {
            Wizard::Saruman => {
                // do something
            }
            _ => {} // ignore everything else
        }
    }
}
```
