具有自定义 `Drop` 实现的值可能在 const-eval 过程中被丢弃。

错误的代码示例：

```compile_fail,E0493
enum DropType {
    A,
}

impl Drop for DropType {
    fn drop(&mut self) {}
}

struct Foo {
    field1: DropType,
}

static FOO: Foo = Foo { field1: (DropType::A, DropType::A).1 }; // error!
```

这里的问题在于，如果给定的类型或其某个字段实现了 `Drop` trait，则无法在 const 上下文下调用该 `Drop` 实现，因为它可能会执行任意的非 const-checked 代码。为了避免此问题，请确保所有具有自定义 `Drop` 实现的值都能从初始化过程中逸出。

```
enum DropType {
    A,
}

impl Drop for DropType {
    fn drop(&mut self) {}
}

struct Foo {
    field1: DropType,
}

static FOO: Foo = Foo { field1: DropType::A }; // We initialize all fields
                                               // by hand.
```
