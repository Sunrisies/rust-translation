一个非根模块试图从另一个 crate 中导入宏。

错误代码示例：

```compile_fail,E0468
mod foo {
    #[macro_use(debug_assert)]  // error: must be at crate root to import
    extern crate core;          //        macros from another crate
    fn run_macro() { debug_assert!(true); }
}
```

仅在 crate 的根级使用 `extern crate` 来导入宏是允许的。

要么将宏导入移动到 crate 的根位置，要么不使用外部宏。这样即可正常工作：

```
#[macro_use(debug_assert)] // ok!
extern crate core;

mod foo {
    fn run_macro() { debug_assert!(true); }
}
# fn main() {}
```
