递归类型具有无限大小，因为不存在间接引用。

错误的代码示例：

```compile_fail,E0072
struct ListNode {
    head: u8,
    tail: Option<ListNode>, // error: no indirection here so impossible to
                            //        compute the type's size
}
```

在定义递归结构体或枚举时，任何在定义内部使用的类型必须通过指针（如 `Box`、`&` 或 `Rc`）来访问。这是因为结构体和枚举必须有明确的大小，如果没有指针，该类型的尺寸将需要无界。

在示例中，该类型无法拥有明确的大小，因为其大小可以是任意大（因为我们可以将 `ListNode` 嵌套到任意深度）。具体来说，

```plain
size of `ListNode` = 1 byte for `head`
                   + 1 byte for the discriminant of the `Option`
                   + size of `ListNode`
```

一种解决方法是用 `Box` 包裹 `ListNode`，如下所示：

```
struct ListNode {
    head: u8,
    tail: Option<Box<ListNode>>,
}
```

这有效是因为 `Box` 是一个指针，因此其大小是已知的。
