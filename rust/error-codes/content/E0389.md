#### 注意：此错误代码已不再由编译器生成。

试图使用不可变引用修改数据，这是常见的情况。当尝试将值赋给一个不可变的引用所指向的可变引用（`&(&mut T)`）时，就会出现这种情况。

错误的代码示例：

```compile_fail
struct FancyNum {
    num: u8,
}

fn main() {
    let mut fancy = FancyNum{ num: 5 };
    let fancy_ref = &(&mut fancy);
    fancy_ref.num = 6; // error: cannot assign to data in a `&` reference
    println!("{}", fancy_ref.num);
}
```

在这里，`&mut fancy` 是可变的，而 `&(&mut fancy)` 则不是。创建对值的不可变引用会将其不可变地借用。可能存在多个类型为 `&(&mut T)` 的引用指向同一个值，因此这些引用必须保持不可变，以防止存在多个可变的引用指向同一个值。

要解决这个问题，要么移除外部引用：

```
struct FancyNum {
    num: u8,
}

fn main() {
    let mut fancy = FancyNum{ num: 5 };

    let fancy_ref = &mut fancy;
    // `fancy_ref` is now &mut FancyNum, rather than &(&mut FancyNum)

    fancy_ref.num = 6; // No error!

    println!("{}", fancy_ref.num);
}
```

要么将外部引用改为可变：

```
struct FancyNum {
    num: u8
}

fn main() {
    let mut fancy = FancyNum{ num: 5 };

    let fancy_ref = &mut (&mut fancy);
    // `fancy_ref` is now &mut(&mut FancyNum), rather than &(&mut FancyNum)

    fancy_ref.num = 6; // No error!

    println!("{}", fancy_ref.num);
}
```
