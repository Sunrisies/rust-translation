使用了未打包的 trait 对象作为返回值。

错误的代码示例：

```compile_fail,E0746
trait T {
    fn bar(&self);
}
struct S(usize);
impl T for S {
    fn bar(&self) {}
}

// Having the trait `T` as return type is invalid because
// unboxed trait objects do not have a statically known size:
fn foo() -> dyn T { // error!
    S(42)
}
```

返回类型不能是 `dyn Trait`，因为它们必须是 `Sized` 类型。

为了避免错误，有几种选择可以采纳。

如果只涉及一种类型，可以使用 [`impl Trait`]：

```
# trait T {
#     fn bar(&self);
# }
# struct S(usize);
# impl T for S {
#     fn bar(&self) {}
# }
// The compiler will select `S(usize)` as the materialized return type of this
// function, but callers will only know that the return type implements `T`.
fn foo() -> impl T { // ok!
    S(42)
}
```

如果涉及多种类型，且您只能通过 trait 的接口与它们交互，接受动态分派也是可行的，那么可以使用 [trait 对象] 结合 `Box` 或其他容器类型如 `Rc` 或 `Arc`：

```
# trait T {
#     fn bar(&self);
# }
# struct S(usize);
# impl T for S {
#     fn bar(&self) {}
# }
struct O(&'static str);
impl T for O {
    fn bar(&self) {}
}

// This now returns a "trait object" and callers are only be able to access
// associated items from `T`.
fn foo(x: bool) -> Box<dyn T> { // ok!
    if x {
        Box::new(S(42))
    } else {
        Box::new(O("val"))
    }
}
```

最后，如果您仍希望能够访问原始类型，可以创建一个新的 `enum`，并为每种类型提供一个变体：

```
# trait T {
#     fn bar(&self);
# }
# struct S(usize);
# impl T for S {
#     fn bar(&self) {}
# }
# struct O(&'static str);
# impl T for O {
#     fn bar(&self) {}
# }
enum E {
    S(S),
    O(O),
}

// The caller can access the original types directly, but it needs to match on
// the returned `enum E`.
fn foo(x: bool) -> E {
    if x {
        E::S(S(42))
    } else {
        E::O(O("val"))
    }
}
```

您甚至可以在返回的 `enum` 上实现该 `trait`，这样调用者无需在返回值上进行匹配即可调用相关项：

```
# trait T {
#     fn bar(&self);
# }
# struct S(usize);
# impl T for S {
#     fn bar(&self) {}
# }
# struct O(&'static str);
# impl T for O {
#     fn bar(&self) {}
# }
# enum E {
#     S(S),
#     O(O),
# }
impl T for E {
    fn bar(&self) {
        match self {
            E::S(s) => s.bar(),
            E::O(o) => o.bar(),
        }
    }
}
```

如果您决定使用 trait 对象，请注意它们依赖于 [动态分派]，这会对性能产生影响，因为编译器需要在运行时生成代码来决定调用哪个方法，而不是在编译时。使用 trait 对象意味着我们为了性能而牺牲了灵活性。
