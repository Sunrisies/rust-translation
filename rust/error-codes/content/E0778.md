#### 注意：此错误代码已不再由编译器生成，`instruction_set` 属性存在格式错误。

错误的代码示例：

```compile_fail
#![feature(isa_attribute)]

#[instruction_set()] // error: expected one argument
pub fn something() {}
fn main() {}
```

括号包裹的 `instruction_set` 属性要求必须指定参数：

```
#![feature(isa_attribute)]

#[cfg_attr(target_arch="arm", instruction_set(arm::a32))]
fn something() {}
```

or:

```
#![feature(isa_attribute)]

#[cfg_attr(target_arch="arm", instruction_set(arm::t32))]
fn something() {}
```

如需更多信息，请参阅参考手册中的 [`instruction_set` 属性][isa-attribute]章节。

[isa-attribute]: https://doc.rust-lang.org/reference/attributes/codegen.html
