`Self` 关键字在 实现、trait 或类型定义之外被使用。

错误的代码示例：

```compile_fail,E0411
<Self>::foo; // error: use of `Self` outside of an impl, trait, or type
             // definition
```

`Self` 关键字表示当前类型，这解释了为什么它只能用于 实现、trait 或类型定义中。它允许访问类型的相关项：

```
trait Foo {
    type Bar;
}

trait Baz : Foo {
    fn bar() -> Self::Bar; // like this
}
```

然而，当两个类型具有共同的关联类型时，需格外注意：

```compile_fail
trait Foo {
    type Bar;
}

trait Foo2 {
    type Bar;
}

trait Baz : Foo + Foo2 {
    fn bar() -> Self::Bar;
    // error: ambiguous associated type `Bar` in bounds of `Self`
}
```

这个问题可以通过指定想要使用 `Bar` 类型的来自哪个 trait 来解决：

```
trait Foo {
    type Bar;
}

trait Foo2 {
    type Bar;
}

trait Baz : Foo + Foo2 {
    fn bar() -> <Self as Foo>::Bar; // ok!
}
```
