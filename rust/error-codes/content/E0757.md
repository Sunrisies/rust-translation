某个函数同时被赋予了 `ffi_const` 和 `ffi_pure` 属性。

错误的代码示例：

```compile_fail,E0757
#![feature(ffi_const, ffi_pure)]

extern "C" {
    #[unsafe(ffi_const)]
    #[unsafe(ffi_pure)]
    //~^ ERROR `#[ffi_const]` function cannot be `#[ffi_pure]`
    pub fn square(num: i32) -> i32;
}
```

由于 `ffi_const` 提供的保证比 `ffi_pure` 更强，请移除 `ffi_pure` 属性：

```
#![feature(ffi_const)]

extern "C" {
    #[unsafe(ffi_const)]
    pub fn square(num: i32) -> i32;
}
```

您可以在 [GCC 关于常见函数属性的文档] 中获取有关 `const` 和 `pure` 的更多信息。不稳定的 Rust 书籍中有更多关于 [`ffi_const`] 和 [`ffi_pure`] 的信息。
