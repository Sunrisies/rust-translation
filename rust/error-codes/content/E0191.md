对于trait对象，没有指定关联类型。

错误的代码示例：

```compile_fail,E0191
trait Trait {
    type Bar;
}

type Foo = dyn Trait; // error: the value of the associated type `Bar` (from
                      //        the trait `Trait`) must be specified
```

trait对象必须明确指定所有关联类型。请确认该trait的所有关联类型都已指定，并且使用了正确的trait。示例：

```
trait Trait {
    type Bar;
}

type Foo = dyn Trait<Bar=i32>; // ok!
```
