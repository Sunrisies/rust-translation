方法中的 `self` 参数具有无效的“接收者类型”。

错误的代码示例：

```compile_fail,E0307
struct Foo;
struct Bar;

trait Trait {
    fn foo(&self);
}

impl Trait for Foo {
    fn foo(self: &Bar) {}
}
```

方法包含一个特殊的第一个参数，有三种形式：`self`、`&self` 和 `&mut self`。这些分别是 `self: Self`、`self: &Self` 和 `self: &mut Self` 的语法糖。

```
# struct Foo;
trait Trait {
    fn foo(&self);
//         ^^^^^ `self` here is a reference to the receiver object
}

impl Trait for Foo {
    fn foo(&self) {}
//         ^^^^^ the receiver type is `&Foo`
}
```

类型 `Self` 是当前特质实现者的类型或“接收者类型”的别名。除了已提到的 `Self`、`&Self` 和 `&mut Self` 有效的接收者类型外，以下类型也是有效的：`self: Box<Self>`、`self: Rc<Self>`、`self: Arc<Self>` 和 `self: Pin<P>`（其中 P 是上述类型之一，除了 `Self`）。注意，`Self` 也可以作为底层实现类型，如下例中的 `Foo`：

```
# struct Foo;
# trait Trait {
#     fn foo(&self);
# }
impl Trait for Foo {
    fn foo(self: &Foo) {}
}
```

当使用无效的接收者类型时，编译器会发出此错误，如以下示例所示：

```compile_fail,E0307
# struct Foo;
# struct Bar;
# trait Trait {
#     fn foo(&self);
# }
impl Trait for Foo {
    fn foo(self: &Bar) {}
}
```

夜间特性 [任意自类型][AST] 将可接受的接收者类型集合扩展为包括任何实现了 `Receiver` 特质并能够沿着 `Target` 类型链到达 `Self` 的类型。对于 `T: Deref`，存在一个通用的 `Receiver` 实现，因此任何可以引用到 `Self` 的类型都可以使用。

```
#![feature(arbitrary_self_types)]

struct Foo;
struct Bar;

// Because you can dereference `Bar` into `Foo`...
impl std::ops::Deref for Bar {
    type Target = Foo;

    fn deref(&self) -> &Foo {
        &Foo
    }
}

impl Foo {
    fn foo(self: Bar) {}
//         ^^^^^^^^^ ...it can be used as the receiver type
}
```

[AST]: https://doc.rust-lang.org/unstable-book/language-features/arbitrary-self-types.html
