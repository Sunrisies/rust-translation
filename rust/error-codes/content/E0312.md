#### 注意：此错误代码已不再由编译器生成。

引用所借用的内容的生命周期与预期的生命周期不一致。

错误的代码示例：

```compile_fail
pub fn opt_str<'a>(maybestr: &'a Option<String>) -> &'static str {
    if maybestr.is_none() {
        "(none)"
    } else {
        let s: &'a str = maybestr.as_ref().unwrap();
        s  // Invalid lifetime!
    }
}
```

要修复此错误，要么缩短预期的生命周期，要么找到一种方法使其无需在当前作用域之外使用该引用（例如直接在同一个块中运行代码？）：

```
// In this case, we can fix the issue by switching from "static" lifetime to 'a
pub fn opt_str<'a>(maybestr: &'a Option<String>) -> &'a str {
    if maybestr.is_none() {
        "(none)"
    } else {
        let s: &'a str = maybestr.as_ref().unwrap();
        s  // Ok!
    }
}
```
