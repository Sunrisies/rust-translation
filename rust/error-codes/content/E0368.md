对不支持该二进制赋值运算符的类型应用了类似 `+=` 或 `^=` 的运算符。

错误的代码示例：

```compile_fail,E0368
let mut x = 12f32; // error: binary operation `<<` cannot be applied to
                   //        type `f32`

x <<= 2;
```

要修复此错误，请检查该类型是否实现了该二元运算。示例：

```
let mut x = 12u32; // the `u32` type does implement the `ShlAssign` trait

x <<= 2; // ok!
```

你也可以通过实现 `std::ops` 中的 `[OP]Assign` 特征来为你的类型重载大多数运算符。

你可能面临的另一个问题是这样：假设你已经通过为 `Foo` 实现 `std::ops::Add` 特征来重载了 `Foo` 类型的 `+` 运算符，但发现使用 `+=` 并不生效，如以下示例所示：

```compile_fail,E0368
use std::ops::Add;

struct Foo(u32);

impl Add for Foo {
    type Output = Foo;

    fn add(self, rhs: Foo) -> Foo {
        Foo(self.0 + rhs.0)
    }
}

fn main() {
    let mut x: Foo = Foo(5);
    x += Foo(7); // error, `+=` cannot be applied to the type `Foo`
}
```

这是因为 `AddAssign` 没有自动实现，因此你需要手动为你的类型实现它。
