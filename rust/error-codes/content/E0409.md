使用了“或”模式，但变量绑定在不同模式中并不一致。

错误的代码示例：

```compile_fail,E0409
let x = (0, 2);
match x {
    (0, ref y) | (y, 0) => { /* use y */} // error: variable `y` is bound with
                                          //        different mode in pattern #2
                                          //        than in pattern #1
    _ => ()
}
```

在这里，`y` 在一种情况下以值方式绑定，在另一种情况下则以引用方式绑定。

要修复此错误，只需在两种情况中使用相同的绑定模式。通常可以在未使用 `ref` 或 `ref mut` 的情况下使用它们来解决问题：

```
let x = (0, 2);
match x {
    (0, ref y) | (ref y, 0) => { /* use y */}
    _ => ()
}
```

或者，可以将模式拆分：

```
let x = (0, 2);
match x {
    (y, 0) => { /* use y */ }
    (0, ref y) => { /* use y */}
    _ => ()
}
```
