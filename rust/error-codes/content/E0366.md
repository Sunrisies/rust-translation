有人试图在通用类型的具体特化上实现 `Drop` 接口。下面给出一个示例：

```compile_fail,E0366
struct Foo<T> {
    t: T
}

impl Drop for Foo<u32> {
    fn drop(&mut self) {}
}
```

此代码是不合法的：无法将 `Drop` 特化为通用类型实现的子集。一种解决方法是像下面那样包裹该通用类型：

```
struct Foo<T> {
    t: T
}

struct Bar {
    t: Foo<u32>
}

impl Drop for Bar {
    fn drop(&mut self) {}
}
```
