从闭包中借用的数据无法被外部访问。

错误的代码示例：

```compile_fail,E0521
let mut list: Vec<&str> = Vec::new();

let _add = |el: &str| {
    list.push(el); // error: `el` escapes the closure body here
};
```

闭包参数上的类型注解意味着需要声明新的生命周期。如果删除该注解，编译器能够可靠地推断出生命周期。

```
let mut list: Vec<&str> = Vec::new();

let _add = |el| {
    list.push(el);
};
```

更多细节请参阅本书中的[闭包类型推断与注解][闭包-infere-annotation]以及[生命周期省略][生命周期-elision]章节。
