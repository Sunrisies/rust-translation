一种 `repr(transparent)` 类型也被标注了其他不兼容的表示提示。

错误的代码示例：

```compile_fail,E0692
#[repr(transparent, C)] // error: incompatible representation hints
struct Grams(f32);
```

被标注为 `repr(transparent)` 的类型将所有表示相关的问题委托给其他类型，因此添加更多表示提示是矛盾的。移除 `transparent` 提示或其他提示即可：

```
#[repr(transparent)]
struct Grams(f32);
```

或者，将其他属性移动到包含该类型的类型中：

```
#[repr(C)]
struct Foo {
    x: i32,
    // ...
}

#[repr(transparent)]
struct FooWrapper(Foo);
```

请注意，仅仅为了给其他属性提供空间而引入另一个 `struct`，可能会对表示产生意外的副作用：

```
#[repr(transparent)]
struct Grams(f32);

#[repr(C)]
struct Float(f32);

#[repr(transparent)]
struct Grams2(Float); // this is not equivalent to `Grams` above
```

在这里，`Grams2` 并不等同于 `Grams -- 前者是一个透明的包装，包裹着一个仅包含一个浮点的非透明结构体，而 `Grams` 则是一个关于浮点的透明包装。这可能对 ABI 产生影响。
