一种负实现被标记为不安全。

错误的代码示例：

```compile_fail,E0198
struct Foo;

unsafe impl !Clone for Foo { } // error!
```

负实现是指某种类型被排除在特定的 trait 实现之外。无法使用 trait 通常是一种安全操作，因此负实现总是安全的，无需标记为不安全。

此代码可以编译通过：

```ignore (ignore auto_trait future compatibility warning)
#![feature(auto_traits)]

struct Foo;

auto trait Enterprise {}

impl !Enterprise for Foo { }
```

请注意，负 实现 仅允许用于自动 trait。
