#### 注意：此错误代码已不再由编译器生成。

类型检查器需要知道表达式的类型，但该类型尚未被推断出来。

错误的代码示例：

```compile_fail
let mut x = vec![];
match x.pop() {
    Some(v) => {
        // Here, the type of `v` is not (yet) known, so we
        // cannot resolve this method call:
        v.to_uppercase(); // error: the type of this value must be known in
                          //        this context
    }
    None => {}
}
```

类型推断通常从函数的顶部到底部进行，边推导边确定类型。在某些情况下——尤其是方法调用和可重载运算符如 `*`——类型检查器可能目前没有足够的信息来继续处理。即使函数的其余部分提供了足够的上下文（因为类型检查器尚未向前看那么远），这种情况也可能发生。在这种情况下，使用类型注解可以帮助它更好地工作。

要解决此错误，只需指定变量的类型即可。示例：

```
let mut x: Vec<String> = vec![]; // We precise the type of the vec elements.
match x.pop() {
    Some(v) => {
        v.to_uppercase(); // Since rustc now knows the type of the vec elements,
                          // we can use `v`'s methods.
    }
    None => {}
}
```
