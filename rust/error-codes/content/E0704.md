指定了错误的可见性限制。

错误的代码示例：

```compile_fail,E0704
mod foo {
    pub(foo) struct Bar {
        x: i32
    }
}
```

要使结构体 `Bar` 仅在模块 `foo` 中可见，应使用 `in` 关键字：

```
mod foo {
    pub(in crate::foo) struct Bar {
        x: i32
    }
}
# fn main() {}
```

有关更多信息，请参阅 [可见性] 部分的 Rust 参考文档。

[Visibility]: https://doc.rust-lang.org/reference/visibility-and-privacy.html
