属性中相同的元项被重复使用了。

错误的代码示例：

```compile_fail,E0538
#[deprecated(
    since="1.0.0",
    note="First deprecation note.",
    note="Second deprecation note." // error: multiple same meta item
)]
fn deprecated_function() {}
```

元项是指属性内的键值对。每个键在单个属性中只能使用一次。

为了解决这个问题，请移除所有相同键的元项，只保留一个。

Example:

```
#[deprecated(
    since="1.0.0",
    note="First deprecation note."
)]
fn deprecated_function() {}
```
