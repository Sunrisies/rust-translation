当您定义同名的方法或关联函数时，会出现此错误。

错误的代码示例：

```compile_fail,E0592
struct Foo;

impl Foo {
    fn bar() {} // previous definition here
}

impl Foo {
    fn bar() {} // duplicate definition here
}
```

类似的错误是 E0201。区别在于是否存在一个声明块。为了避免此错误，您必须为每个 `fn` 赋予唯一的名称。

```
struct Foo;

impl Foo {
    fn bar() {}
}

impl Foo {
    fn baz() {} // define with different name
}
```
