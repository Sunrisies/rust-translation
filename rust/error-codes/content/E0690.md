具有 `repr(transparent)` 表示提示的结构体包含两个或更多无法保证零大小字段。

错误的代码示例：

```compile_fail,E0690
#[repr(transparent)]
struct LengthWithUnit<U> { // error: transparent struct needs at most one
    value: f32,            //        non-zero-sized field, but has 2
    unit: U,
}
```

由于透明结构体在运行时其表示方式与其某个字段完全相同，因此该字段必须被唯一确定。如果存在多个字段，则不清楚该结构体应如何进行表示。请注意，零大小类型（例如 `PhantomData`）的字段也可以与包含实际数据的字段同时存在，这些字段不会引发此错误。当涉及泛型类型时（如上述示例），会报告错误，因为类型参数可能是非零大小的。

为了将 `repr(transparent)` 与类型参数结合使用，`PhantomData` 可能会很有用：

```
use std::marker::PhantomData;

#[repr(transparent)]
struct LengthWithUnit<U> {
    value: f32,
    unit: PhantomData<U>,
}
```
