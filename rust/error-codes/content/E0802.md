`derive(CoercePointee)` 宏的目标对于有效使用存在不合适的规范。

错误的代码示例：

目标数据不是 `struct`。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
enum NotStruct<'a, T: ?Sized> {
    Variant(&'a T),
}
```

目标数据的布局不可透明，换句话说就是没有 `repr(transparent)`。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
struct NotTransparent<'a, #[pointee] T: ?Sized> {
    ptr: &'a T,
}
```

目标数据中没有任何数据字段。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoField<'a, #[pointee] T: ?Sized> {}
```

目标数据不对任何数据类型具有通用性，也没有通用的类型参数。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoGeneric<'a>(&'a u8);
```

目标数据具有多个通用类型参数，但没有一个被指定为用于强制转换的 pointee。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct AmbiguousPointee<'a, T1: ?Sized, T2: ?Sized> {
    a: (&'a T1, &'a T2),
}
```

目标数据具有多个被指定为强制转换 pointee 的通用类型参数。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct TooManyPointees<
    'a,
    #[pointee] A: ?Sized,
    #[pointee] B: ?Sized>
((&'a A, &'a B));
```

被指定为 pointee 的类型参数没有标记为 `?Sized`。

```compile_fail,E0802
#![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoMaybeSized<'a, #[pointee] T> {
    ptr: &'a T,
}
```

总结来说，`CoercePointee` 宏要求目标数据类型必须是一个至少对一种或多种类型通用的 `struct`，其中有一个标记了 `#[pointee]`，并且至少有一个数据字段，同时采用 `repr(transparent)` 的布局。唯一的通用类型或带有 `#[pointee]` 标记的类型还必须被标记为 `?Sized`。
