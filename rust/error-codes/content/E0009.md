#### 注意：此错误代码已不再由编译器生成。

在模式中，所有未实现 `Copy` 特质的值必须以相同的方式绑定。目的是避免同时使用 by-move 和 by-ref 进行绑定。

这一限制可能在 Rust 的后续版本中被移除。

错误的代码示例：

```
#![feature(move_ref_pattern)]

struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((y, ref z)) => {}, // error: cannot bind by-move and by-ref in the
                            //        same pattern
    None => panic!()
}
```

您有两种解决方案：

方案 #1：以相同的方式绑定模式的值。

```
struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((ref y, ref z)) => {},
    // or Some((y, z)) => {}
    None => panic!()
}
```

方案 #2：为 `X` 结构实现 `Copy` 特质。

不过，请记住应优先选择第一种解决方案。

```
#[derive(Clone, Copy)]
struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((y, ref z)) => {},
    None => panic!()
}
```
