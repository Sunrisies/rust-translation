构造了一个引用其自身类型的闭包或生成器。

错误的代码示例：

```compile_fail,E0644
fn fix<F>(f: &F)
  where F: Fn(&F)
{
    f(&f);
}

fn main() {
    fix(&|y| {
        // Here, when `x` is called, the parameter `y` is equal to `x`.
    });
}
```

Rust 不允许闭包直接引用其自身类型，无论是通过参数（如上述示例）还是通过环境捕获自身。这一限制有助于保持闭包推断的合理性。

最简单的解决方案是将你的闭包重写为顶级函数或方法。在某些情况下，你也可以通过捕获一个指向自身的 `&Fn()` 对象或 `fn()` 指针来让闭包调用自身。这是允许的，因为闭包会通过虚拟调用来调用自身，因此不会直接引用其自身 *类型*。
