在特质对象或引用上实现 `Drop` 是不被允许的；只有结构体、枚举和联合可以实现 `Drop`。

错误的代码示例：

```compile_fail,E0120
trait MyTrait {}

impl Drop for MyTrait {
    fn drop(&mut self) {}
}
```

```compile_fail,E0120
struct Concrete {}

impl Drop for &'_ mut Concrete  {
    fn drop(&mut self) {}
}
```

对特质的一种替代方法是创建一个具有泛型类型的包装结构体，在类型中添加特质约束，并在该包装结构上实现 `Drop`：

```
trait MyTrait {}
struct MyWrapper<T: MyTrait> { foo: T }

impl <T: MyTrait> Drop for MyWrapper<T> {
    fn drop(&mut self) {}
}

```

或者，`Drop` 包装器可以包含特质对象：

```
trait MyTrait {}

// or Box<dyn MyTrait>, if you wanted an owned trait object
struct MyWrapper<'a> { foo: &'a dyn MyTrait }

impl <'a> Drop for MyWrapper<'a> {
    fn drop(&mut self) {}
}
```
