在指定范围内发现了名为“未知工具”的标记。

错误的代码示例：

```compile_fail,E0710
#[allow(clipp::filter_map)] // error!
fn main() {
    // business logic
}
```

```compile_fail,E0710
#[warn(clipp::filter_map)] // error!
fn main() {
    // business logic
}
```

请确认您没有拼错工具名称，也没有忘记在项目中导入该工具。

```
#[allow(clippy::filter_map)] // ok!
fn main() {
    // business logic
}
```

```
#[warn(clippy::filter_map)] // ok!
fn main() {
    // business logic
}
```
