#### 注意：此错误代码不再由编译器生成。


`#[ffi_returns_twice]` 被用于非外部函数声明的情况。

错误的代码示例：

```compile_fail
#![feature(ffi_returns_twice)]
#![crate_type = "lib"]

#[ffi_returns_twice] // error!
pub fn foo() {}
```

`#[ffi_returns_twice]` 只能用于外部函数声明。例如，我们可以通过在 `extern` 块中声明函数来修正之前的示例。

```compile_fail
#![feature(ffi_returns_twice)]

extern "C" {
   #[ffi_returns_twice] // ok!
   pub fn foo();
}
```
