#### 注意：此错误代码已不再由编译器生成。对 `instruction_set` 属性提供了未知的参数。

错误的代码示例：

```compile_fail
#![feature(isa_attribute)]

#[instruction_set(intel::x64)] // error: invalid argument
pub fn something() {}
fn main() {}
```

目前 `instruction_set` 属性仅支持两个参数：

 * arm::a32 * arm::t32

向 `instruction_set` 属性提供的所有其他参数都将引发此错误。示例：

```
#![feature(isa_attribute)]

#[cfg_attr(target_arch="arm", instruction_set(arm::a32))] // ok!
pub fn something() {}
fn main() {}
```

有关更多信息，请参阅参考手册中的 [`instruction_set` 属性][isa-attribute]部分。

[isa-attribute]: https://doc.rust-lang.org/reference/attributes/codegen.html
