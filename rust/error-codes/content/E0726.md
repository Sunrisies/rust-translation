在异步函数中省略了参数生命周期。

错误的代码示例：

当结构体或类型被绑定/声明时，需要明确指定其生命周期，以便 Rust 编译器在使用时能够确定该类型的存在时间。如果未明确说明生命周期，且 Rust 编译器无法确定该类型的生命周期，则会出现以下错误。

```compile_fail,E0726
use futures::executor::block_on;
struct Content<'a> {
    title: &'a str,
    body: &'a str,
}
async fn create(content: Content) { // error: implicit elided
                                    // lifetime not allowed here
    println!("title: {}", content.title);
    println!("body: {}", content.body);
}
let content = Content { title: "Rust", body: "is great!" };
let future = create(content);
block_on(future);
```

应明确指定参数 `content` 所需的生命周期，或者指示匿名生命周期，例如 `content: Content<'_>`。匿名生命周期告诉 Rust 编译器，`content` 仅在 `create` 函数执行完时需要使用。

`隐式省略`指的是在 `pub async fn create<'a>(content: Content<'a>) {}` 中省略了建议的生命周期，因为在此情况下 `content` 的生命周期可能与当前上下文不同。

```ignore (needs futures dependency)
async fn create(content: Content<'_>) { // ok!
    println!("title: {}", content.title);
    println!("body: {}", content.body);
}
```
