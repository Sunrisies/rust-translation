#### 注意：此错误代码已不再由编译器生成。

用于绑定名称的模式必须不可抵赖。也就是说，这些模式必须确保在任何情况下都能提取出该名称。与其使用模式匹配循环变量，不如在循环体内使用 `match` 或 `if let`。例如：

```compile_fail,E0005
let xs : Vec<Option<i32>> = vec![Some(1), None];

// This fails because `None` is not covered.
for Some(x) in xs {
    // ...
}
```

改为在循环内使用 `match`：

```
let xs : Vec<Option<i32>> = vec![Some(1), None];

for item in xs {
    match item {
        Some(x) => {},
        None => {},
    }
}
```

或者可以使用 `if let`：

```
let xs : Vec<Option<i32>> = vec![Some(1), None];

for item in xs {
    if let Some(x) = item {
        // ...
    }
}
```
