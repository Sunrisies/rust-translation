在非安全代码块之外使用了不安全代码。

错误的代码示例：

```compile_fail,E0133
unsafe fn f() { return; } // This is the unsafe code

fn main() {
    f(); // error: call to unsafe function requires unsafe function or block
}
```

使用不安全功能具有潜在危险，且会被安全性检查所禁止。示例包括：

* 解引用原始指针 * 通过 FFI 调用函数 * 调用标记为不安全的函数

可以通过在不安全指令前添加 `unsafe` 块来放宽这部分代码的安全性检查。例如：

```
unsafe fn f() { return; }

fn main() {
    unsafe { f(); } // ok!
}
```

更多细节请参阅书籍中的 [不安全部分][不安全-section]。

#### 函数中的不安全代码

目前，不安全函数在中使用不安全代码是被接受的，但未来将逐步淘汰这种做法，转而要求在此类函数中也使用不安全块。

```
unsafe fn f() { return; }

unsafe fn g() {
    f(); // Is accepted, but no longer recommended
    unsafe { f(); } // Recommended way to write this
}
```

针对此问题的lint检查通过 `unsafe_op_in_unsafe_fn` lint 控制，在 2024 版本中默认为 `warn`，而在更早的版本中默认为 `allow`。
