#### 注意：此错误代码已不再由编译器生成。

`ffi_pure` 属性被用于非外部函数上。

错误的代码示例：

```ignore (no longer emitted)
#![feature(ffi_pure)]

#[unsafe(ffi_pure)] // error!
pub fn foo() {}
# fn main() {}
```

`ffi_pure` 属性只能用于没有副作用或无限循环的外部函数上：

```
#![feature(ffi_pure)]

extern "C" {
    #[unsafe(ffi_pure)] // ok!
    pub fn strlen(s: *const std::ffi::c_char) -> usize;
}
# fn main() {}
```

您可以在 [不稳定的 Rust 书籍] 中找到更多相关信息。
