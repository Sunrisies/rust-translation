发现 `staticlib` `..` 而不是 `rlib` 或 `dylib`。

请考虑以下两个文件：

`a.rs`
```ignore (cannot-link-with-other-tests)
#![crate_type = "staticlib"]

fn foo() {}
```

`main.rs`
```ignore (cannot-link-with-other-tests)
extern crate a;

fn main() {
    a::foo();
}
```

crate `a` 被编译为 `staticlib`。`staticlib` 是一种系统依赖库，仅用于与非 Rust 应用程序（C 程序）链接。请注意，`staticlib` 包含所有上游依赖项（`core`、`std`、其他用户依赖等），因此其大小比 `dylib` 大得多：在与 C 程序链接时优先使用 `staticlib`。有关不同 `crate_type` 的更多信息，请参见 [参考手册的这一部分](../reference/linkage.html)。

可以通过以下方式解决此错误：* 使用 [Cargo](../cargo/index.html)——Rust 包管理器——自动修复该问题。* 将 crate 重新编译为 `rlib` 或 `dylib；适用于 Rust 链接的格式。
