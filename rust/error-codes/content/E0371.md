某个特质在另一个已经自动实现了该特质的类中被实现。

错误的代码示例：

```compile_fail,E0371
trait Foo { fn foo(&self) { } }
trait Bar: Foo { }
trait Baz: Bar { }

impl Bar for dyn Baz { } // error, `Baz` implements `Bar` by definition
impl Foo for dyn Baz { } // error, `Baz` implements `Bar` which implements `Foo`
impl Baz for dyn Baz { } // error, `Baz` (trivially) implements `Baz`
```

这是可以的，因为从定义上来看，`Bar` 并不实现 `Baz`：

```
# trait Foo { fn foo(&self) { } }
# trait Bar: Foo { }
# trait Baz: Bar { }
impl Baz for dyn Bar { } // Note: This is OK
```

当 `Trait2` 是 `Trait1` 的子特质时（例如，`Trait2` 有类似 `trait Trait2: Trait1 { ... }` 的定义），不允许为 `Trait2` 实现 `Trait1`。这是因为从定义上来看，`Trait2` 已经实现了 `Trait1`，因此这样做没有意义。
