该对象类型的生命周期约束无法从上下文中推导，必须手动指定。

错误的代码示例：

```compile_fail,E0228
trait Trait { }

struct TwoBounds<'a, 'b, T: Sized + 'a + 'b> {
    x: &'a i32,
    y: &'b i32,
    z: T,
}

type Foo<'a, 'b> = TwoBounds<'a, 'b, dyn Trait>;
```

当将trait对象作为泛型类型의参数使用时，如果未指定生命周期，Rust会尝试推断其生命周期。但是，当包含类型具有多个生命周期约束时，此操作不可行。

上述示例可以通过减少生命周期约束的数量或明确指定trait对象的生命周期来解决，例如：

```
trait Trait { }

struct TwoBounds<'a, 'b, T: Sized + 'a + 'b> {
    x: &'a i32,
    y: &'b i32,
    z: T,
}

type Foo<'a, 'b> = TwoBounds<'a, 'b, dyn Trait + 'b>;
```

有关更多信息，请参阅[RFC 599]及其修订版[RFC 1156]。

[RFC 599]: https://rust-lang.github.io/rfcs/0599-default-object-bound.html
[RFC 1156]: https://rust-lang.github.io/rfcs/1156-adjust-default-object-bounds.html
