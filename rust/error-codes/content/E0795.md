`offset_of!` 宏的参数无效。

错误的代码示例：

```compile_fail,E0795
#![feature(offset_of_enum)]

let x = std::mem::offset_of!(Option<u8>, Some);
```

`offset_of!` 宏用于返回类型中某个字段的偏移量。它可以遍历枚举变体，但第二个参数的最终组成部分必须是一个字段而非一个变体。

可以通过指定字段名 `0`，获取 `Option<u8>` 中包含的 `u8` 的偏移量：

```
#![feature(offset_of_enum)]

let x: usize = std::mem::offset_of!(Option<u8>, Some.0);
```

枚举的判别式可以通过 `core::mem::discriminant` 读取，但这并不一定是枚举内部实际存在的值。

有关枚举布局的更多信息，请参见 https://rust-lang.github.io/不安全-code-guidelines/layout/enums.html。
