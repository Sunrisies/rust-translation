在特质位置使用了非特质的类型，例如边界条件或 `impl`。

错误的代码示例：

```compile_fail,E0404
struct Foo;
struct Bar;

impl Foo for Bar {} // error: `Foo` is not a trait
fn baz<T: Foo>(t: T) {} // error: `Foo` is not a trait
```

另一个错误的代码示例：

```compile_fail,E0404
type Foo = Iterator<Item=String>;

fn bar<T: Foo>(t: T) {} // error: `Foo` is a type alias
```

请确认特质的名称没有拼写错误，并且使用了正确的标识符。示例：

```
trait Foo {
    // some functions
}
struct Bar;

impl Foo for Bar { // ok!
    // functions implementation
}

fn baz<T: Foo>(t: T) {} // ok!
```

或者，你可以引入一个包含所需约束的新特质作为超级特质：

```
# trait Foo {}
# struct Bar;
# impl Foo for Bar {}
trait Qux: Foo {} // Anything that implements Qux also needs to implement Foo
fn baz<T: Qux>(t: T) {} // also ok!
```

最后，如果你在夜间构建项目，并希望使用特质别名而非类型别名，应使用 `#![feature(trait_alias)]`：

```
#![feature(trait_alias)]
trait Foo = Iterator<Item=String>;

fn bar<T: Foo>(t: T) {} // ok!
```
