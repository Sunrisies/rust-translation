内部文档注释在无效的上下文中被使用。

错误的代码示例：

```compile_fail,E0753
fn foo() {}
//! foo
// ^ error!
fn main() {}
```

内部文档只能在项目之前使用。例如：

```
//! A working comment applied to the module!
fn foo() {
    //! Another working comment!
}
fn main() {}
```

如果您希望在文档注释之后对项目进行说明，可以使用外部文档注释：

```
/// I am an outer doc comment
#[doc = "I am also an outer doc comment!"]
fn foo() {
    // ...
}
```
