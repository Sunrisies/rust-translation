外部可实现的项与其声明不兼容。

错误的代码示例：

```rust,edition2021,compile_fail,E0806
#![feature(extern_item_impls)]

#[eii(foo)]
fn x();

#[foo]
fn y(a: u64) -> u64 {
//~^ ERROR E0806
    a
}


fn main() {}
```

这里的错误是由于 `y` 实现了外部可实现的项 `foo` 造成的。只有实现 `y` 的签名与 `foo` 的声明一致时，才能做到这一点。因此，要解决这个问题，必须将 `y` 的签名更改为与 `x` 的签名匹配。

```rust,edition2021
#![feature(extern_item_impls)]

#[eii(foo)]
fn x();

#[foo]
fn y() {}


fn main() {}
```

一种常见的触发方式是使用错误的 `#[panic_handler]` 签名。该签名由 `core` 提供。

```rust,edition2021,ignore
#![no_std]

#[panic_handler]
fn on_panic() -> ! {
//~^ ERROR E0806

    loop {}
}

fn main() {}
```

应该这样写：

```rust,edition2021,ignore
#![no_std]

#[panic_handler]
fn on_panic(info: &core::panic::PanicInfo<'_>) -> ! {
    loop {}
}

fn main() {}
```
