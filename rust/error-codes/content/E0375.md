在包含多个不可量化字段的结构上实现了 `CoerceUnsized` 或 `DispatchFromDyn`。

错误的代码示例：

```compile_fail,E0375
#![feature(coerce_unsized)]
use std::ops::CoerceUnsized;

struct Foo<T: ?Sized, U: ?Sized> {
    a: i32,
    b: T,
    c: U,
}

// error: Struct `Foo` has more than one unsized field.
impl<T, U> CoerceUnsized<Foo<U, T>> for Foo<T, U> {}
```

`CoerceUnsized` 用于将具有不可量化字段的结构进行转换，例如将自定义 `MyBox<T>` 不可量化转换为 `MyBox<dyn Trait>`。`DispatchFromDyn` 则用于在与动态类型兼容的 trait 中从 `MyBox<dyn Trait>` 调用到 `MyBox<Self>`。

如果结构包含多个必须不可量化的字段，那么编译器无法生成 `CoerceUnsized` 或 `DispatchFromDyn` 的有效实现。

请注意，`CoerceUnsized` 和 `DispatchFromDyn` 主要被智能指针如 `Box`、`Rc` 和 `Arc` 使用，以便标记它们能够转换其指向的不可量化类型。
