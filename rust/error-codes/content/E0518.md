#### 注意：此错误代码已不再由编译器生成。

在并非函数或方法的位置错误地添加了 `#[inline(..)]` 属性。

错误代码示例：

```ignore (no longer emitted)
#[inline(always)]
struct Foo;

#[inline(never)]
impl Foo {
    // ...
}
```

`#[inline]` 指示编译器是否尝试内联该方法或函数。默认情况下，编译器能够自行判断，但如果你需要额外的注释，可以使用 `#[inline(always)]` 和 `#[inline(never)]` 来覆盖或强制编译器的决策。

如果你想将此属性应用于 `impl` 中的所有方法，则必须手动为每个方法添加注释；无法使用 `#[inline]` 属性对整个 `impl` 进行标注。
