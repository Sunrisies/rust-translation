如果某个实现具有带有 `#[may_dangle]` 属性的泛型参数，则该实现必须被声明为 `unsafe impl`。

错误的代码示例：

```compile_fail,E0569
#![feature(dropck_eyepatch)]

struct Foo<X>(X);
impl<#[may_dangle] X> Drop for Foo<X> {
    fn drop(&mut self) { }
}
```

在这个示例中，我们断言 `Foo` 的析构函数不会访问任何类型为 `X` 的数据，并且要求这一断言为真以确保程序的整体安全性。编译器目前并不尝试验证这一断言，因此我们必须将此实现标记为 `unsafe`。
