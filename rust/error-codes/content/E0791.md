在外部块中带有 `#[linkage]` 属性的静态变量必须属于以下类型之一，这些类型与 C 语言中的可空指针相当：

* `*mut T` 或 `*const T`，其中 `T` 可以是任意类型。

* 一种没有 `#[repr]` 属性的枚举器类型，包含两种变体；其中一种变体没有字段，另一种变体中有一个以下非空类型的单个字段：* 引用类型 * 函数指针类型。

  这些变体可以以任意顺序出现。

例如，以下声明是无效的：

```compile_fail,E0791
#![feature(linkage)]

extern "C" {
    #[linkage = "extern_weak"]
    static foo: i8;
}
```

以下声明是有效的：

```
#![feature(linkage)]

extern "C" {
    #[linkage = "extern_weak"]
    static foo: Option<unsafe extern "C" fn()>;

    #[linkage = "extern_weak"]
    static bar: Option<&'static i8>;

    #[linkage = "extern_weak"]
    static baz: *mut i8;
}
```
