`Copy` 特性是在具有 `Drop` 实现的类型上实现的。

错误的代码示例：

```compile_fail,E0184
#[derive(Copy)]
struct Foo; // error!

impl Drop for Foo {
    fn drop(&mut self) {
    }
}
```

目前不允许在类型上显式同时实现 `Drop` 和 `Copy` 特性。虽然这一功能在理论上有一定意义，但当前实现存在错误，可能导致内存不安全（参见 [issue #20126][iss20126]），因此目前已禁用该功能。

[iss20126]: https://github.com/rust-lang/rust/issues/20126
