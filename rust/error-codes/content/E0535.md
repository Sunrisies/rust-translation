#### 注意：此错误代码不再由编译器生成

这是因为该错误对 `inline` 属性过于具体。其他属性也会产生类似的诊断信息。此时示例将输出 `E0539`


错误的代码示例：

```compile_fail,E0539
#[inline(unknown)] // error: invalid argument
pub fn something() {}

fn main() {}
```

`inline` 属性仅支持两个参数：

 * 总是 * 从不

向 `inline` 属性提供的所有其他参数都会返回此错误。示例：

```
#[inline(never)] // ok!
pub fn something() {}

fn main() {}
```

有关更多信息，请参阅参考手册中的 [`inline` Attribute][inline-attribute] 章节。

[inline-attribute]: https://doc.rust-lang.org/reference/attributes/codegen.html#the-inline-attribute
