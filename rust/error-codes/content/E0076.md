当使用 `#[simd]` 属性时，元组结构体中的字段类型不是数组。

错误的代码示例：

```compile_fail,E0076
#![feature(repr_simd)]

#[repr(simd)]
struct Bad(u16); // error!
```

当使用 `#[simd]` 属性在元组结构体中自动执行 SIMD 操作时，如果希望得到一个单通道向量，该字段必须是一个一元素数组，否则编译器会触发此错误。

修复后的示例：

```
#![feature(repr_simd)]

#[repr(simd)]
struct Good([u16; 1]); // ok!
```
