使用了一种既不是元组结构也不是元组变体的对象作为模式。

错误的代码示例：

```compile_fail,E0164
enum A {
    B,
    C,
}

impl A {
    fn new() {}
}

fn bar(foo: A) {
    match foo {
        A::new() => (), // error!
        _ => {}
    }
}
```

此错误表示试图匹配一个既不是元组结构也不是元组变体的对象。仅允许使用这两种元素作为模式。

```
enum A {
    B,
    C,
}

impl A {
    fn new() {}
}

fn bar(foo: A) {
    match foo {
        A::B => (), // ok!
        _ => {}
    }
}
```
