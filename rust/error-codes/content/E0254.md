尝试导入一个项目，但名为此名称的外部 crate 已经被导入过了。

错误的代码示例：

```compile_fail,E0254
extern crate core;

mod foo {
    pub trait core {
        fn do_something();
    }
}

use foo::core;  // error: an extern crate named `core` has already
                //        been imported in this module

fn main() {}
```

要解决此问题，您必须至少重命名其中一个导入项。示例：

```
extern crate core as libcore; // ok!

mod foo {
    pub trait core {
        fn do_something();
    }
}

use foo::core;

fn main() {}
```
