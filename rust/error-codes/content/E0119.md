对于同一类型存在冲突的特质实现。

错误的代码示例：

```compile_fail,E0119
trait MyTrait {
    fn get(&self) -> usize;
}

impl<T> MyTrait for T {
    fn get(&self) -> usize { 0 }
}

struct Foo {
    value: usize
}

impl MyTrait for Foo { // error: conflicting implementations of trait
                       //        `MyTrait` for type `Foo`
    fn get(&self) -> usize { self.value }
}
```

在寻找该特质的实现时，编译器会找到 `impl<T> MyTrait for T`（其中 T 为所有类型）和 `impl MyTrait for Foo` 两种实现方式。由于一个特质不能被多次实现，因此这是一个错误。所以，当你编写如下代码时：

```
trait MyTrait {
    fn get(&self) -> usize;
}

impl<T> MyTrait for T {
    fn get(&self) -> usize { 0 }
}
```

这将使该特质在作用域内的所有类型上都被实现。因此，如果你之后尝试在其他类型上实现它，这些实现将会产生冲突。示例：

```
trait MyTrait {
    fn get(&self) -> usize;
}

impl<T> MyTrait for T {
    fn get(&self) -> usize { 0 }
}

struct Foo;

fn main() {
    let f = Foo;

    f.get(); // the trait is implemented so we can use it
}
```
