一个超级特质已被添加到自动特质中。

错误的代码示例：

```compile_fail,E0568
#![feature(auto_traits)]

auto trait Bound : Copy {} // error!

fn main() {}
```

由于所有现有类型都实现了自动特质，添加超级特质将会排除许多此类类型。在当前示例中，几乎没有任何现有类型能够实现 `Bound` 特性，因为很少有类型具备 `Copy` 特质。

为了解决这个问题，只需移除该超级特质即可：

```
#![feature(auto_traits)]

auto trait Bound {} // ok!

fn main() {}
```
