尝试在泛型类型的特化上实现 `Drop` 接口。

错误的代码示例：

```compile_fail,E0367
trait Foo {}

struct MyStruct<T> {
    t: T
}

impl<T: Foo> Drop for MyStruct<T> {
    fn drop(&mut self) {}
}
```

此代码是不合法的：无法将 `Drop` 特化为泛型类型实现的子集。为了使该代码能够运行， `MyStruct` 还必须要求 `T` 实现 `Foo`。另一种选择是将泛型类型包裹在另一个具有适当特化的类型中：

```
trait Foo{}

struct MyStruct<T> {
    t: T
}

struct MyStructWrapper<T: Foo> {
    t: MyStruct<T>
}

impl <T: Foo> Drop for MyStructWrapper<T> {
    fn drop(&mut self) {}
}
```
