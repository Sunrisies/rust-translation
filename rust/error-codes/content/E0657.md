`impl Trait` 捕获了更高级别的生命周期，这是不被支持的。

目前，`impl Trait` 类型仅允许从其父项中捕获生命周期，而不能从作用域内的任何 `for<'a>` 绑定器中捕获。

错误的代码示例：

```compile_fail,E0657
trait BorrowInto<'a> {
    type Target;

    fn borrow_into(&'a self) -> Self::Target;
}

impl<'a> BorrowInto<'a> for () {
    type Target = &'a ();

    fn borrow_into(&'a self) -> Self::Target {
        self
    }
}

fn opaque() -> impl for<'a> BorrowInto<'a, Target = impl Sized + 'a> {
    ()
}
```
