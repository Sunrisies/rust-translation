某个导入项无法解析。

错误的代码示例：

```compile_fail,E0432
use something::Foo; // error: unresolved import `something::Foo`.
```

在 Rust 2015 中，`use` 语句中的路径相对于库根目录。若要导入当前模块及父模块的成员，请分别使用 `self::` 和 `super::` 前缀。

在 Rust 2018 或更高版本中，`use` 语句中的路径相对于当前模块，除非以库名或字面量 `crate::` 开头，此时则从库根目录开始。与 Rust 2015 代码一样，`self::` 和 `super::` 前缀分别指代当前模块和父模块。

同时确认您没有拼错导入名称，并且该导入项存在于您尝试导入的模块中。示例：

```
use self::something::Foo; // Ok.

mod something {
    pub struct Foo;
}
# fn main() {}
```

如果您试图使用来自外部库的模块，且使用的是 Rust 2015，可能忽略了 `extern crate` 声明（通常位于库根目录）：

```edition2015
extern crate core; // Required to use the `core` crate in Rust 2015.

use core::any;
# fn main() {}
```

自 Rust 2018 起，不再需要 `extern crate` 声明，可以直接使用 `use` 进行导入。

```edition2018
use core::any; // No extern crate required in Rust 2018.
# fn main() {}
```
