在 Rust 中不允许手动调用析构函数。

错误的代码示例：

```compile_fail,E0040
struct Foo {
    x: i32,
}

impl Drop for Foo {
    fn drop(&mut self) {
        println!("kaboom");
    }
}

fn main() {
    let mut x = Foo { x: -7 };
    x.drop(); // error: explicit use of destructor method
}
```

由于当值超出作用域时会自动调用 `drop`，因此无需这样做。然而，如果您确实需要手动释放值，可以使用 `std::mem::drop` 函数：

```
struct Foo {
    x: i32,
}
impl Drop for Foo {
    fn drop(&mut self) {
        println!("kaboom");
    }
}
fn main() {
    let mut x = Foo { x: -7 };
    drop(x); // ok!
}
```
