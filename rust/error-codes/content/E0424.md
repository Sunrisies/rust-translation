在关联函数内部使用了 `self` 关键字，但没有使用 "`self` 接收者" 参数。

错误的代码示例：

```compile_fail,E0424
struct Foo;

impl Foo {
    // `bar` is a method, because it has a receiver parameter.
    fn bar(&self) {}

    // `foo` is not a method, because it has no receiver parameter.
    fn foo() {
        self.bar(); // error: `self` value is a keyword only available in
                    //        methods with a `self` parameter
    }
}
```

`self` 关键字只能用于方法之中，即那些作为关联函数的方法（定义在 `trait` 或 `impl` 块中的函数），并且这些方法的第一个参数必须是 `self` 接收者，例如 `self`、`&self`、`&mut self` 或 `self: &mut Pin<Self>`（最后一种是一种["任意的 `self` 类型"](https://github.com/rust-lang/rust/issues/44874)的例子）。

检查关联函数的参数列表是否应包含 `self` 接收者才能成为方法，如果包含则添加它。示例：

```
struct Foo;

impl Foo {
    fn bar(&self) {}

    fn foo(self) { // `foo` is now a method.
        self.bar(); // ok!
    }
}
```
