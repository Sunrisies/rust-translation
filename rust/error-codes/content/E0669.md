#### 注意：此错误代码已不再由编译器生成。

无法将内联汇编操作数转换为单个 LLVM 值。

错误的代码示例：

```ignore (no longer emitted)
#![feature(llvm_asm)]

fn main() {
    unsafe {
        llvm_asm!("" :: "r"("")); // error!
    }
}
```

当试图将值传递给实际上为一对值的输入内联汇编操作数时，通常会出现此错误。特别是当尝试传递切片时，例如 `&str`。在 Rust 中，这些值在内部被表示为一个值对，即指针及其长度。当作为输入操作数传递时，这个值对无法被转换为寄存器，因此会导致错误。
