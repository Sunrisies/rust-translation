当编译器无法明确推断一个对返回类型为泛型的函数或方法的返回类型时，就会出现此错误，例如 `Iterator` 的 `collect` 方法。

例如：

```compile_fail,E0284
fn main() {
    let n: u32 = 1;
    let mut d: u64 = 2;
    d = d + n.into();
}
```

这里我们将 `d` 与 `n.into()` 相加。因此，`n.into()` 可以返回任何满足 `u64: Add<T>` 条件的类型 `T`。另一方面，`into` 方法则可以返回任何满足 `u32: Into<T>` 条件的类型。

该代码的作者可能希望 `into()` 返回 `u64`，但编译器无法确定是否存在另一种类型 `T`，使得既满足 `u32: Into<T>` 又满足 `u64: Add<T`。

要解决此错误，请为中间表达式使用具体的类型：

```
fn main() {
    let n: u32 = 1;
    let mut d: u64 = 2;
    let m: u64 = n.into();
    d = d + m;
}
```
