## 编写端到端测试

[Nuxt Test Utils](/docs/getting-started/testing) 是帮助你以端到端方式测试模块的优秀库。采用其工作流程如下：

1. 创建一个 Nuxt 应用，作为 `test/fixtures/*` 中的“模板”使用。
2. 在测试文件中引入该模板来配置 Nuxt。
3. 使用 `@nuxt/test-utils` 提供的工具与模板交互（例如获取页面）。
4. 执行与模板相关的检查（例如“HTML 包含 ...”）。
5. 重复上述步骤。

实际上，模板：

```ts [test/fixtures/ssr/nuxt.config.ts]
// 1. Create a Nuxt application to be used as a "fixture"
import MyModule from '../../../src/module'

export default defineNuxtConfig({
  ssr: true,
  modules: [
    MyModule,
  ],
})
```

其测试：

```ts [test/rendering.ts]
import { describe, expect, it } from 'vitest'
import { fileURLToPath } from 'node:url'
import { $fetch, setup } from '@nuxt/test-utils/e2e'

describe('ssr', async () => {
  // 2. Setup Nuxt with this fixture inside your test file
  await setup({
    rootDir: fileURLToPath(new URL('./fixtures/ssr', import.meta.url)),
  })

  it('renders the index page', async () => {
    // 3. Interact with the fixture using utilities from `@nuxt/test-utils`
    const html = await $fetch('/')

    // 4. Perform checks related to this fixture
    expect(html).toContain('<div>ssr</div>')
  })
})

// 5. Repeat
describe('csr', async () => { /* ... */ })
```

::tip
此类工作流程的示例可在 [模块 starter 中找到](https://github.com/nuxt/starter/blob/module/test/basic.test.ts)。
::

## 手动测试

在开发模块时，拥有一个可测试的 Playground Nuxt 应用非常有用。[模块 starter 为此提供了支持](/docs/guide/modules/getting-started#develop-your-module)。

你可以在本地使用其他 Nuxt 应用（非模块仓库中的应用）来测试你的模块。为此，可以使用 [`npm pack`](https://docs.npmjs.com/cli/commands/npm-pack/) 命令或相应的包管理工具，从你的模块中生成 tarball。然后在测试项目中，你可以将你的模块添加到 `package.json` 的包中，例如：`"my-module": "file:/path/to/tarball.tgz"`。

之后，你应该能够像在普通项目一样引用 `my-module`。
