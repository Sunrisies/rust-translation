## 探索 Nuxt 模块

在使用 Nuxt 开发生产级应用程序时，你可能会发现框架的核心功能不够用。可以通过配置选项和插件来扩展 Nuxt，但要在多个项目之间维护这些自定义设置会非常繁琐、重复且耗时。另一方面，如果为每个项目都提供完整的支持功能，会使 Nuxt 变得非常复杂且难以使用。

这就是 Nuxt 提供模块系统的原因之一，使得可以扩展核心功能。Nuxt 模块是异步函数，在开发模式下使用 [`nuxt dev`](/docs/api/commands/dev) 或针对生产环境构建项目时使用 [`nuxt build`](/docs/api/commands/build) 启动 Nuxt 时会依次运行。它们可以覆盖模板、配置 webpack 加载器、添加 CSS 库以及执行许多其他有用的任务。

最棒的是，Nuxt 模块可以作为 npm 包分发。这使得它们可以在不同项目之间复用，并与社区共享，从而帮助创建一个高质量的插件生态系统。

## 添加 Nuxt 模块

安装好模块后，你可以将其添加到你的 [`nuxt.config.ts`](/docs/directory-structure/nuxt-config) 文件的 `modules` 属性下。模块开发者通常会提供额外的使用步骤和说明。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    // Using package name (recommended usage)
    '@nuxtjs/example',

    // Load a local module
    './modules/example',

    // Add module with inline-options
    ['./modules/example', { token: '123' }],

    // Inline module definition
    async (inlineOptions, nuxt) => { },
  ],
})
```

::warning
现在 Nuxt 模块仅存在于构建时，Nuxt 2 中使用的 `buildModules` 属性已弃用，取而代之的是 `modules`。
::

## 禁用模块 :badge[v4.3]{color="info" size="xs" class="align-middle"}

你可以通过在 Nuxt 配置中将模块的配置键设置为 `false` 来禁用模块。当你想要禁用从层继承的模块时，这特别有用。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  // Disable `@nuxt/image` module
  image: false,
})
```
