## ESLint

对于 Nuxt 而言，推荐的做法是使用 [`@nuxt/eslint`](https://eslint.nuxt.com/packages/module) 模块启用 ESLint 支持，该模块会为你设置基于项目的 ESLint 配置。

:::callout{icon="i-lucide-lightbulb"}
该模块专为 [新的 ESLint flat 配置格式](https://eslint.org/docs/latest/use/configure/configuration-files) 设计，这是 [自 ESLint v9 起使用的默认格式](https://eslint.org/blog/2024/04/eslint-v9.0.0-released/)。如果你使用旧的 `.eslintrc` 配置，则需要 [使用 `@nuxt/eslint-config` 手动配置](https://eslint.nuxt.com/packages/config#customizing-the-config)。我们强烈建议将配置迁移到 flat 格式中，以确保未来兼容性。
:::

## 快速设置

```bash
npx nuxt module add eslint
```

启动你的 Nuxt 应用后，项目根目录下将生成 `eslint.config.mjs` 文件。你可以根据需要进行自定义。

你可以通过 [Nuxt ESLint 文档](https://eslint.nuxt.com/packages/module) 了解有关该模块和自定义配置的更多信息。
