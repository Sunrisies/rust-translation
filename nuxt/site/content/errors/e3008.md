# E3008

调用 `useAsyncData()` 时未提供有效的键。第一个参数必须是非空字符串，以便 Nuxt 在组件间缓存并去重请求。

## 解决方案

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
