# E1006

`onPrehydrate()` 没有经过 Nuxt 构建管道的转换。它需要在编译时处理，且仅在服务器上生效，因此当从 Nuxt 未转译的依赖中调用时就会出现这种情况。

## 解决方案

将有问题的库添加到 `nuxt.config.ts` 中的 `build.transpile` 中，以便构建管道能够处理其 `onPrehydrate()` 调用。

::
