# E5001

在 `experimental.appManifest` 被禁用时，依赖应用清单的代码会运行。该清单支持客户端上的路由规则匹配和预渲染负载检测等功能，因此必须启用它才能正常工作。

## 分辨率

在你的 `nuxt.config` 中启用应用清单：

```ts
export default defineNuxtConfig({
  experimental: {
    appManifest: true,
  },
})
```
