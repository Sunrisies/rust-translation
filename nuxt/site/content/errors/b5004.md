# B5004

Nuxt 在你的 `nuxt.config` 文件旁边发现了独立的 `vite.config` 或 `webpack.config` 文件。Nuxt 内部管理打包工具，忽略这些文件，因此它们通常是迁移过程遗留的或非 Nuxt 项目的副本。

从 `vite-plus` 导入的 `vite.config` 文件不会触发此警告，因为它配置的是 [Vite+](https://viteplus.dev) 命令，而非你的 Nuxt 应用。

## 解决方案

将配置移动到 `nuxt.config` 中对应的键下，然后删除外部文件：

- `vite.config`：使用 `vite` 键
- `webpack.config`：使用 `webpack` 键
- `nitro.config`：使用 `nitro` 键
- `postcss.config`：使用 `postcss` 键

```ts
export default defineNuxtConfig({
  vite: {
    // your Vite config here
  },
})
```
