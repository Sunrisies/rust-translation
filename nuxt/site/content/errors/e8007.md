# E8007

当设置 `features.noScripts: 'production'`（启用 `noScripts` 时默认值为此）时，脚本仅在生产构建的渲染 HTML 中被移除。在开发环境中，页面仍然包含 JavaScript，因此依赖该脚本的行为（如延迟 hydration 策略、服务器组件内的 `nuxt-client` 组件）在开发环境中可以正常工作，但在部署后会无声地失效。

当渲染的路由使用这些功能时，在开发过程中会发出此警告。

## 解决方案

要么从受影响的路由中移除客户端依赖，要么通过 `noScripts` 路由规则将脚本移除限制到真正静态的路由（该规则在开发环境中也适用，因此任何问题都会立即显现）：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    '/static/**': { noScripts: true },
  },
})
```

或者，设置 `features.noScripts: 'all'` 以在开发环境中也移除脚本，从而使生产环境的行为在开发阶段可观察。
