# E4016

当前路由匹配一个嵌套页面，但父页面组件未渲染 `<NuxtPage />`。Vue Router 只能在其父页面的 `<NuxtPage />` 出口中显示子页面，因此子页面始终无法显示。

当 `parent.vue` 文件不包含 `<NuxtPage />` 时，就会出现这种情况，此时结构类似于以下目录结构：

```bash [Directory Structure]
-| pages/
---| parent/
------| child.vue
---| parent.vue
```

## 解决方案

在父页面组件中添加 `<NuxtPage />`，以便子路由可以在其中渲染。如果您不打算创建嵌套路由，请重新构建 `pages/` 目录，使该页面不再包含子路由。

::
