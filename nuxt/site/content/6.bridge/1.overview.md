::note
如果您正在开始一个全新的 Nuxt 3 项目，请跳过此部分，直接前往 [Nuxt 3 安装](/docs/getting-started/introduction)。
::

::warning
Nuxt Bridge 提供与 Nuxt 3 相同的功能 ([文档](/docs/guide/concepts/auto-imports))，但存在一些限制，特别是 [`useAsyncData`](/docs/api/组合式函数/use-async-data) 和 [`useFetch`](/docs/api/组合式函数/use-fetch) 组合式函数不可用。请阅读此页面的其余部分以了解详情。
::

Bridge 是一个向前兼容性层，通过安装并启用 Nuxt 模块，您就可以体验许多新的 Nuxt 3 功能。

使用 Nuxt Bridge 可以确保您的项目（几乎）准备好迎接 Nuxt 3，并且您可以逐步进行向 Nuxt 3 的过渡。

## 第一步

### 升级 Nuxt 2

确保您的开发服务器 (`nuxt dev`) 没有运行，删除任何包锁定文件 (`package-lock.json` 和 `yarn.lock)`，然后安装最新版本的 Nuxt 2：

```diff [package.json]
- "nuxt": "^2.16.3"
+ "nuxt": "^2.17.3"
```

然后，重新安装依赖项：

::code-group{sync="pm"}

```bash [npm]
npm install
```

```bash [yarn]
yarn install
```

```bash [pnpm]
pnpm install
```

```bash [bun]
bun install
```

```bash [deno]
deno install
```

::

::note
安装完成后，在继续之前，请确保开发和生产构建都按预期工作。
::

### 安装 Nuxt Bridge

将 `@nuxt/bridge` 和 `nuxi` 作为开发依赖项安装：

::code-group{sync="pm"}

```bash [npm]
npm install -D @nuxt/bridge nuxi
```

```bash [yarn]
yarn add --dev @nuxt/bridge nuxi
```

```bash [pnpm]
pnpm add -D @nuxt/bridge nuxi
```

```bash [bun]
bun add -D @nuxt/bridge nuxi
```

```bash [deno]
deno add -D npm:@nuxt/bridge npm:nuxi
```

::

### 更新 `nuxt.config`

请确保在配置文件中避免使用 CommonJS 语法，如 `module.exports`、`require` 或 `require.resolve`。这些语法即将被弃用且不再受支持。

您可以改用静态 `import`、动态 `import()` 和 `export default`。使用 TypeScript 并将文件重命名为 [`nuxt.config.ts`](/docs/directory-structure/nuxt-config) 也是可行的，并且更推荐这样做。

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: false,
})
```

### 更新命令

现在，`nuxt` 命令应改为 `nuxt2` 命令。

```diff
{
  "scripts": {
-   "dev": "nuxt",
+   "dev": "nuxt2",
-   "build": "nuxt build",
+   "build": "nuxt2 build",
-   "start": "nuxt start",
+   "start": "nuxt2 start"
  }
}
```

尝试在这里运行 `nuxt2`。您会看到应用程序像以前一样工作。

（如果 'bridge' 设置为 false，您的应用程序将像以前一样运行，无需任何更改。）

## 升级步骤

使用 Nuxt Bridge，向 Nuxt 3 的迁移可以分步骤进行。
下面的 `Upgrade Steps` 不需要一次性完成。

- [TypeScript](/docs/bridge/typescript)

- [迁移旧版组合式 API](/docs/bridge/bridge-composition-api)

- [插件和中间件](/docs/bridge/plugins-and-中间件)

- [迁移新组合式函数 API](/docs/bridge/nuxt3-compatible-api)

- [元标签](/docs/bridge/meta)

- [运行时配置](/docs/bridge/runtime-config)

- [Nitro](/docs/bridge/nitro)

- [Vite](/docs/bridge/vite)

## 从 CommonJS 迁移到 ESM

Nuxt 3 原生支持 TypeScript 和 ECMAScript 模块。请查阅 [原生 ES 模块](/docs/guide/concepts/esm)以获取更多信息和升级指南。
