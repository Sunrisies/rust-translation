---
title: 新的组合式函数 API
description: Nuxt Bridge 实现了与 Nuxt 3 兼容的组合式函数。
---

通过从 `@nuxtjs/composition-api` 迁移到与 Nuxt 3 兼容的 API，在迁移到 Nuxt 3 时所需的重写工作会减少。

## `ssrRef` 和 `shallowSsrRef`

这两个函数已被新的组合式函数替代，该新函数在底层实现上非常类似：`useState`。

主要区别在于，您必须为此状态提供一个 _key_（Nuxt 会自动为 `ssrRef` 和 `shallowSsrRef` 生成该 key），并且它只能在 Nuxt 3 插件（由 `defineNuxtPlugin` 定义）或组件实例中调用。（换句话说，由于跨请求共享状态可能带来风险，您不能将 [`useState`](/docs/api/组合式函数/use-state) 用于全局/环境上下文。）

```diff
- import { ssrRef } from '@nuxtjs/composition-api'

- const ref1 = ssrRef('initialData')
- const ref2 = ssrRef(() => 'factory function')
+ const ref1 = useState('ref1-key', () => 'initialData')
+ const ref2 = useState('ref2-key', () => 'factory function')
  // accessing the state
  console.log(ref1.value)
```

由于状态具有键，只要使用相同的键，您可以从多个位置访问同一状态。

您可以在 [Nuxt 3 文档](/docs/api/组合式函数/use-state)中了解如何使用该组合式函数。

## `ssrPromise`

此函数已被移除，如果您曾经使用它，您需要找到替代实现。如果您有使用 `ssrPromise` 的场景，请通过讨论向我们反馈。

## `onGlobalSetup`

此函数已被移除，但可以通过在 `defineNuxtPlugin` 中使用 [`useNuxtApp`](/docs/api/组合式函数/use-nuxt-app) 或 [`useState`](/docs/api/组合式函数/use-state) 来满足其用途。您也可以在布局的 `setup()` 函数中运行任何自定义代码。

```diff
- import { onGlobalSetup } from '@nuxtjs/composition-api'

- export default () => {
-   onGlobalSetup(() => {
+ export default defineNuxtPlugin((nuxtApp) => {
+   nuxtApp.hook('vue:setup', () => {
      // ...
    })
- }
+ })
```

## `useStore`

为了访问 Vuex 存储实例，您可以使用 `useNuxtApp().$store`。

```diff
- import { useStore } from '@nuxtjs/composition-api`
+ const { $store } = useNuxtApp()
```

## `useContext` 和 `withContext`

您可以使用 `useNuxtApp` 访问注入的辅助函数。

```diff
- import { useContext } from '@nuxtjs/composition-api`
+ const { $axios } = useNuxtApp()
```

::note
`useNuxtApp()` 还提供了一个名为 `nuxt2Context` 的键，它包含从 Nuxt 2 上下文中通常可以访问的所有属性，但建议不要直接使用它，因为它在 Nuxt 3 中不存在。相反，请看看是否有其他方式可以访问所需内容。（如果没有，请提出功能请求或讨论。）
::

## `wrapProperty`

此辅助函数不再提供，但您可以用以下代码替代：

```ts
import { computed, getCurrentInstance } from 'vue'

const wrapProperty = (property: string, makeComputed = true) => () => {
  const vm = getCurrentInstance().proxy
  return makeComputed ? computed(() => vm[property]) : vm[property]
}
```

## `useAsync` 和 `useFetch`

这两个组合式函数可以被 `useLazyAsyncData` 和 `useLazyFetch` 替代，这些函数在 [Nuxt 3 文档](/docs/getting-started/data-fetching)中有说明。与之前的 `@nuxtjs/composition-api` 组合式函数一样，这些组合式函数在客户端侧不会阻塞路由导航（因此名称中包含“延迟”一词）。

::important
请注意，尽管名称相似，但 API 完全不同。重要的是，您不应尝试更改组合式函数外部的其他变量的值（就像之前使用 `useFetch` 时那样）。
::

::warning
`useLazyFetch` 必须已为 [Nitro](/docs/bridge/nitro) 配置。
::

从 `useAsync` 迁移到新的组合式函数：

```diff
<script setup>
- import { useAsync } from '@nuxtjs/composition-api'
- const posts = useAsync(() => $fetch('/api/posts'))
+ const { data: posts } = useLazyAsyncData('posts', () => $fetch('/api/posts'))
+ // or, more simply!
+ const { data: posts } = useLazyFetch('/api/posts')
</script>
```

从 `useFetch` 迁移到新的组合式函数：

```diff
<script setup>
- import { useFetch } from '@nuxtjs/composition-api'
- const posts = ref([])
- const { fetch } = useFetch(() => { posts.value = await $fetch('/api/posts') })
+ const { data: posts, refresh } = useLazyAsyncData('posts', () => $fetch('/api/posts'))
+ // or, more simply!
+ const { data: posts, refresh } = useLazyFetch('/api/posts')
  function updatePosts() {
-   return fetch()
+   return refresh()
  }
</script>
```

### `useMeta`

为了与 `vue-meta` 交互，您可以使用 `useNuxt2Meta`，该函数在 Nuxt Bridge 中有效（但在 Nuxt 3 中无效），并允许您以 `vue-meta` 兼容的方式操作元标签。

```diff
<script setup>
- import { useMeta } from '@nuxtjs/composition-api'
  useNuxt2Meta({
    title: 'My Nuxt App',
  })
</script>
```

您也可以传递计算值或引用，然后元值将进行响应式更新：

```vue
<script setup>
const title = ref('my title')
useNuxt2Meta({
  title,
})
title.value = 'new title'
</script>
```

::note
注意不要在同一个组件中同时使用 `useNuxt2Meta()` 和 Options API 的 `head()`，因为行为可能不可预测。
::

Nuxt Bridge 还提供了与 Nuxt 3 兼容的元实现，可以通过 [`useHead`](/docs/api/组合式函数/use-head) 组合式函数访问。

```diff
<script setup>
- import { useMeta } from '@nuxtjs/composition-api'
  useHead({
    title: 'My Nuxt App',
  })
</script>
```

您还需要在 `nuxt.config` 中显式启用它：

```js
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    meta: true,
  },
})
```

这个 [`useHead`](/docs/api/组合式函数/use-head) 组合式函数在底层使用 `@unhead/vue`（而不是 `vue-meta`）来操作您的 `<head>`。因此，建议不要同时使用原生的 Nuxt 2 `head()` 属性和 [`useHead`](/docs/api/组合式函数/use-head)，因为它们可能会冲突。

有关如何使用此组合式函数的更多信息，请参阅 [Nuxt 3 文档](/docs/getting-started/seo-meta)。

### 显式导入

Nuxt 通过 `#imports` 别名暴露所有自动导入，如果需要，可以使用该别名使导入变得明确：

```vue
<script setup lang="ts">
import { computed, ref } from '#imports'

const count = ref(1)
const double = computed(() => count.value * 2)
</script>
```

### 禁用自动导入

如果您希望禁用组合式函数和工具类的自动导入，可以在 `nuxt.config` 文件中将 `imports.autoImport` 设置为 `false`。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  imports: {
    autoImport: false,
  },
})
```

这将完全禁用自动导入，但仍然可以使用来自 `#imports` 的 [显式导入](/docs/bridge/nuxt3-compatible-api#explicit-imports)。
