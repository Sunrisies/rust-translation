`.nuxtignore` 文件指示 Nuxt 在构建阶段忽略项目根目录中的文件（[`rootDir`](/docs/api/nuxt-config#rootdir)）。

该文件遵循与 [`.gitignore`](/docs/directory-structure/gitignore) 和 `.eslintignore` 文件相同的规范，其中每一行都是一个通配符模式，用于指定应被忽略的文件。

::tip
您也可以在 `nuxt.config` 文件中配置 [`ignoreOptions`](/docs/api/nuxt-config#ignoreoptions)、 [`ignorePrefix`](/docs/api/nuxt-config#ignoreprefix) 和 [`ignore`](/docs/api/nuxt-config#ignore)。
::

## 使用方式

```bash [.nuxtignore]
# ignore layout foo.vue
app/layouts/foo.vue
# ignore layout files whose name ends with -ignore.vue
app/layouts/*-ignore.vue

# ignore page bar.vue
app/pages/bar.vue
# ignore page inside ignore folder
app/pages/ignore/*.vue

# ignore route middleware files under foo folder except foo/bar.js
app/middleware/foo/*.js
!app/middleware/foo/bar.js
```

关于该规范的更多细节可在 **gitignore 文档**中查看。
::
