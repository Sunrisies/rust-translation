Nuxt [自动生成](/docs/guide/concepts/typescript#auto-generated-types)多个 TypeScript 配置文件（`.nuxt/tsconfig.app.json`、`.nuxt/tsconfig.server.json`、`.nuxt/tsconfig.node.json` 和 `.nuxt/tsconfig.shared.json`），这些文件包含针对项目的推荐基本 TypeScript 配置、[自动导入引用](/docs/guide/concepts/auto-imports)、[API 路由类型](/docs/guide/concepts/server-engine#typed-api-routes)、路径别名等内容。

您的 Nuxt 项目应在项目根目录包含以下 `tsconfig.json` 文件：

```json [tsconfig.json]
{
  "files": [],
  "references": [
    {
      "path": "./.nuxt/tsconfig.app.json"
    },
    {
      "path": "./.nuxt/tsconfig.server.json"
    },
    {
      "path": "./.nuxt/tsconfig.shared.json"
    },
    {
      "path": "./.nuxt/tsconfig.node.json"
    }
  ]
}
```

::warning
我们不建议直接修改此文件的内容，因为这样做可能会覆盖 Nuxt 或其他模块依赖的重要设置。相反，应通过 `nuxt.config.ts` 进行扩展。
::

::read-more{to="/docs/guide/concepts/typescript#project-references"}
在此阅读更多关于 Nuxt 项目不同类型上下文的信息。
::

## 扩展 TypeScript 配置

您可以在 `nuxt.config.ts` 文件中自定义 Nuxt 项目的 TypeScript 配置：通过 `typescript.tsConfig` 一次性设置每个上下文的共享 `compilerOptions`，并分别针对每个上下文（`app`、`shared`、`node` 和 `server`）进行覆盖。
<!-- @case-police-ignore tsConfig -->
```ts twoslash [nuxt.config.ts]
// @errors: 2353
export default defineNuxtConfig({
  typescript: {
    // shared compiler options for every generated tsconfig
    tsConfig: {
      compilerOptions: {
        // ...
      },
    },
    // customize tsconfig.app.json
    appTsConfig: {
      // ...
    },
    // customize tsconfig.shared.json
    sharedTsConfig: {
      // ...
    },
    // customize tsconfig.node.json
    nodeTsConfig: {
      // ...
    },
    // customize tsconfig.server.json
    serverTsConfig: {
      // ...
    },
  },
})
```

::note
在 `typescript.tsConfig` 中设置的大多数 `compilerOptions` 都是共享给所有上下文的，但有些则不是。DOM 和 Vue 特定的选项（如 `lib`、`jsx` 和 `jsxImportSource`）仅对应用程序代码有意义，因此它们仅应用于 `tsconfig.app.json`。Nuxt 还根据上下文管理 `types`、`paths` 和 `noEmit`（`node`、`shared` 和 `server` 配置故意不生成任何内容且不扫描环境类型），因此在 `typescript.tsConfig` 中设置这些选项不会改变它们。当需要覆盖时，请使用相应的每个上下文选项（`appTsConfig`、`nodeTsConfig`、`sharedTsConfig` 或 `serverTsConfig`）。
::

::note
`typescript.serverTsConfig` 扩展 `tsconfig.server.json`。`nitro.typescript.tsConfig` 与其保持同步但已过时，因此应设置 `typescript.serverTsConfig`  instead。
::
