当页面以 `ssr: false` 模式渲染时（可以在 `nuxt.config` 中全局设置，也可以通过 [`routeRules`](/docs/guide/concepts/rendering#hybrid-rendering) 针对特定路由设置），服务器返回的 HTML 壳中不包含服务器渲染的应用内容。直到 JavaScript 包下载完成、Nuxt 插件运行完毕且第一个页面渲染后，你的页面内容才可见。

你可以通过添加 `app/spa-loading-template.html` 文件来填补这一空白。其内容直接插入到服务器返回的 HTML 中，因此它们在 Nuxt 客户端包加载之前就可见了。

```html [app/spa-loading-template.html]
<!-- https://github.com/barelyhuman/snips/blob/dev/pages/css-loader.md -->
<div class="loader"></div>
<style>
  .loader {
    position: fixed;
    top: 50%;
    left: 50%;
    width: 24px;
    height: 24px;
    margin: -12px 0 0 -12px;
    border: 2px solid #efefef;
    border-top-color: #000;
    border-radius: 50%;
    animation: loader 600ms linear infinite;
  }

  @keyframes loader {
    to { transform: rotate(360deg); }
  }
</style>
```

::warning
此文件是纯 HTML，可以独立于 Vue 渲染，因此无法在其中使用 Vue 组件或自动导入。请将加载屏幕所需的样式直接包含在此文件中，而不是依赖应用程序的样式表。
::

::tip
此文件仅涵盖客户端渲染页面的初始加载过程。要在页面切换时显示加载状态，请使用 [`<NuxtLoadingIndicator>`](/docs/api/components/nuxt-loading-indicator) 组件。
::

## 移除时机

默认情况下，加载模板会显示在 Nuxt 应用根目录旁边，而不是内部：

```html
<div id="__nuxt"></div>
<div id="__nuxt-loader"><!-- spa-loading-template.html --></div>
```

它一直保持可见，直到第一个页面准备渲染，包括页面中的异步设置，之后才会被移除。这样可以避免加载屏幕和页面之间出现白色闪光。包装元素可以通过 [`app.spaLoaderTag`](/docs/api/nuxt-config#spaloadertag) 和 [`app.spaLoaderAttrs`](/docs/api/nuxt-config#spaloaderattrs) 进行自定义；请保持一个 `id`，因为 Nuxt 使用它来移除该元素。

你可以通过设置实验性选项 [`spaLoadingTemplateLocation`](/docs/guide/going-further/experimental-features#spaloadingtemplatelocation) 为 `'within'`，将加载模板渲染在应用根目录内。在这种情况下，一旦 Vue 挂载应用，它就会被移除，因此屏幕可能保持空白，直到第一个页面准备渲染。

## 配置

Nuxt 会在项目的 `app/` 目录（更具体地说，是 [`dir.app`](/docs/api/nuxt-config#dir) 目录）以及每个 [层](/docs/directory-structure/layers) 中查找 `spa-loading-template.html`。

您可以通过 [`spaLoadingTemplate`](/docs/api/nuxt-config#spaloadingtemplate) 选项来更改此设置：

- 一个路径（相对于 [`srcDir`](/docs/api/nuxt-config#srcdir)，默认值为 `app/`），用于使用不同的 HTML 文件，
- `true` 在找不到文件时使用 Nuxt 内置的加载屏幕，
- `false` 则完全禁用加载模板。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  ssr: false,
  spaLoadingTemplate: 'my-loader.html',
})
```
