## 使用方法

**方法 1：** 使用命名导出

```ts [app/composables/useFoo.ts]
export const useFoo = () => {
  return useState('foo', () => 'bar')
}
```

**方法 2：** 使用默认导出

```ts [app/composables/use-foo.ts or composables/useFoo.ts]
// It will be available as useFoo() (camelCase of file name without extension)
export default function () {
  return useState('foo', () => 'bar')
}
```

**使用方式：** 你现在可以在 `.js`、`.ts` 和 `.vue` 文件中使用自动导入的组合式函数。

```vue [app/app.vue]
<script setup lang="ts">
const foo = useFoo()
</script>

<template>
  <div>
    {{ foo }}
  </div>
</template>
```

::note
Nuxt 中的 `app/composables/` 目录不会为你的代码提供任何额外的响应式功能。相反，组合式函数中的所有响应式功能都通过 Vue 的 Composition API 机制实现，例如 `ref` 和 `reactive`。请注意，响应式代码也不受 `app/composables/` 目录边界的限制。你可以自由地在应用需要的地方使用响应式功能。
::

## 类型

在底层，Nuxt 会自动生成 `.nuxt/imports.d.ts` 文件来声明类型。

请注意，你必须运行 [`nuxt prepare`](/docs/api/commands/prepare)、 [`nuxt dev`](/docs/api/commands/dev) 或 [`nuxt build`](/docs/api/commands/build) 才能让 Nuxt 生成类型。

::note
如果你在开发服务器未运行时创建组合式函数，TypeScript 会抛出错误，例如 `Cannot find name 'useBar'.`
::

## 示例

### 嵌套组合式函数

你可以使用自动导入在另一个组合式函数中使用组合式函数：

```ts [app/composables/test.ts]
export const useFoo = () => {
  const nuxtApp = useNuxtApp()
  const bar = useBar()
}
```

### 访问插件注入

你可以从组合式函数中访问 [插件注入](/docs/directory-structure/app/plugins#providing-helpers)：

```ts [app/composables/test.ts]
export const useHello = () => {
  const nuxtApp = useNuxtApp()
  return nuxtApp.$hello
}
```

## 文件扫描方式

Nuxt 仅扫描 [`app/composables/` 目录](/docs/directory-structure/app/组合式函数) 顶层的文件，例如：

```bash [Directory Structure]
-| composables/
---| index.ts     // scanned
---| useFoo.ts    // scanned
---| nested/
-----| utils.ts   // not scanned
```

只有 `app/composables/index.ts` 和 `app/composables/useFoo.ts` 会被搜索导入项。

为了让嵌套模块能够使用自动导入，你可以重新导出它们（推荐方式），或者配置扫描器以包含嵌套目录：

**示例：** 从 `app/composables/index.ts` 文件中重新导出所需的组合式函数：

```ts [app/composables/index.ts]
// Enables auto import for this export
export { utils } from './nested/utils.ts'
```

**示例：** 扫描 `app/composables/` 文件夹内的嵌套目录：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  imports: {
    dirs: [
      // Scan top-level composables
      '~/composables',
      // ... or scan composables nested one level deep with a specific name and file extension
      '~/composables/*/index.{ts,js,mjs,mts}',
      // ... or scan all composables within given directory
      '~/composables/**',
    ],
  },
})
```
