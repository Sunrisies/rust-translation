`public/` 目录中的文件在根路径下提供，不会在构建过程中被修改。这适用于需要保留其名称的文件（例如 `robots.txt`）或很可能不会变化的文件（例如 `favicon.ico`）。

```bash [Directory structure]
-| public/
---| favicon.ico
---| og-image.png
---| robots.txt
```

```vue [app/app.vue]
<script setup lang="ts">
useSeoMeta({
  ogImage: '/og-image.png',
})
</script>
```

::tip{to="https://nuxt.com/docs/2.x/directory-structure/static" target="_blank"}
在 Nuxt 2 中，这被称为 [`static/`] 目录。
::
