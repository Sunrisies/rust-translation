`layers/` 目录允许你在 Nuxt 应用程序中组织并共享可复用的代码、组件、组合式函数和配置。项目中的任何位于 `layers/` 目录的层都会自动被注册。

::note
`layers/` 目录的自动注册功能在 Nuxt v3.12.0+ 中可用。
::

::tip{icon="i-lucide-lightbulb"}
层非常适合用于以 **领域驱动设计 (DDD)** 方式组织大型代码库，创建可复用的 **UI 库** 或 **主题**，在多个项目之间共享 **配置预设**，以及分离如 **管理面板** 或 **功能模块** 等职责。
::

## 结构

`layers/` 中的每个子目录都被视为一个独立的层。一个层可以包含与标准 Nuxt 应用程序相同的结构。

::important
每个层**必须**拥有 `nuxt.config.ts` 文件才能被识别为有效的层，即使该文件为空也是如此。
::

```bash [Directory structure]
-| layers/
---| base/
-----| nuxt.config.ts
-----| app/
-------| components/
---------| BaseButton.vue
-------| composables/
---------| useBase.ts
-----| server/
-------| api/
---------| hello.ts
---| admin/
-----| nuxt.config.ts
-----| app/
-------| pages/
---------| admin.vue
-------| layouts/
---------| admin.vue
```

## 自动别名

每个层的 `srcDir` 会自动创建名称化的层别名。你可以使用 `#layers/[name]` 别名来访问该层：

```ts
// Access the base layer
import something from '#layers/base/path/to/file'

// Access the admin layer
import { useAdmin } from '#layers/admin/composables/useAdmin'
```

::note
名称化的层别名是在 Nuxt v3.16.0 中引入的。
::

## 层内容

每个层可以包含：

- [`nuxt.config.ts`](/docs/directory-structure/nuxt-config) - 特定于层的配置，将与主配置合并
- [`app.config.ts`](/docs/directory-structure/app/app-config) - 响应式应用程序配置
- [`app/components/`](/docs/directory-structure/app/components) - Vue 组件（自动导入）
- [`app/composables/`](/docs/directory-structure/app/组合式函数) - Vue 组合式函数（自动导入）
- [`app/utils/`](/docs/directory-structure/app/utils) - 工具函数（自动导入）
- [`app/pages/`](/docs/directory-structure/app/pages) - 应用程序页面
- [`app/layouts/`](/docs/directory-structure/app/layouts) - 应用程序布局
- [`app/middleware/`](/docs/directory-structure/app/中间件) - 路由中间件
- [`app/plugins/`](/docs/directory-structure/app/plugins) - Nuxt 插件
- [`server/`](/docs/directory-structure/server) - 服务器路由、中间件和工具函数
- [`shared/`](/docs/directory-structure/shared) - 应用程序和服务器之间的共享代码

## 优先级顺序

当多个层定义相同的资源（组件、组合式函数、页面等）时，具有**更高优先级**的层会优先被使用。层的排序按字母顺序进行，后出现的字母具有更高的优先级（Z > A）。

为了控制顺序，请在目录前加上数字前缀：`1.base/`、`2.features/`、`3.admin/`。

或者，在 [`extends`](/docs/api/nuxt-config#extends) 中引用这些目录（例如 `extends: ['~~/layers/admin', '~~/layers/base']`），从而从 `nuxt.config` 中按顺序排列，无需重命名，其中第一个条目具有最高优先级。
