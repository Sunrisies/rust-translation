---
title: 元标签
description: 在 Nuxt 2 到 Nuxt 3 之间管理您的元标签。
---

Nuxt 3 提供了多种不同的方式来管理元标签：
1. 通过 `nuxt.config` 配置。
2. 通过 [`useHead`](/docs/api/组合式函数/use-head) 组合式函数
3. 通过 [全局元组件](/docs/getting-started/seo-meta)

您可以自定义 `title`、`titleTemplate`、`base`、`script`、`noscript`、`style`、`meta`、`link`、`htmlAttrs` 和 `bodyAttrs`。

::tip
目前 Nuxt 使用 [`Unhead`](https://github.com/unjs/unhead) 来管理元标签，但实现细节可能会发生变化。
::

:read-more{to="/docs/getting-started/seo-meta"}

## 迁移指南

1. 在 `nuxt.config` 中，将 `head` 重命名为 `meta`。考虑将此共享元配置移动到 `app.vue` 中。（注意：对象不再有 `hid` 键用于去重。）
2. 如果您需要使用 `head` 访问组件状态，应迁移到使用 [`useHead`](/docs/api/组合式函数/use-head) 。您也可以考虑使用内置的元组件。
3. 如果您需要使用 Options API，在调用 `defineNuxtComponent` 时可以使用 `head()` 方法。

### useHead

::code-group

```vue [Nuxt 2]
<script>
export default {
  data: () => ({
    title: 'My App',
    description: 'My App Description',
  }),
  head () {
    return {
      title: this.title,
      meta: [{
        hid: 'description',
        name: 'description',
        content: this.description,
      }],
    }
  },
}
</script>
```

```vue [Nuxt 3]
<script setup lang="ts">
const title = ref('My App')
const description = ref('My App Description')

// This will be reactive when you change title/description above
useHead({
  title,
  meta: [{
    name: 'description',
    content: description,
  }],
})
</script>
```

::

### 元组件

Nuxt 3 还提供了元组件，您可以使用这些组件完成相同任务。虽然这些组件看起来与 HTML 标签相似，但它们由 Nuxt 提供并具有类似功能。

::code-group

```vue [Nuxt 2]
<script>
export default {
  head () {
    return {
      title: 'My App',
      meta: [{
        hid: 'description',
        name: 'description',
        content: 'My App Description',
      }],
    }
  },
}
</script>
```

```vue [Nuxt 3]
<template>
  <div>
    <Head>
      <Title>My App</Title>
      <Meta
        name="description"
        content="My app description"
      />
    </Head>
    <!-- -->
  </div>
</template>
```

::

::important
1. 确保使用大写字母作为这些组件名称，以便与原生 HTML 元素区分（`<Title>` 而非 `<title>`）。
2. 您可以在模板中的任何位置放置这些组件。
::

### Options API

```vue [Nuxt 3 (Options API)]
<script>
// if using options API `head` method you must use `defineNuxtComponent`
export default defineNuxtComponent({
  head (nuxtApp) {
    // `head` receives the nuxt app but cannot access the component instance
    return {
      meta: [{
        name: 'description',
        content: 'This is my page description.',
      }],
    }
  },
})
</script>
```
