::note
Nuxt 利用 Vue 的 [`<Transition>`](https://vuejs.org/guide/built-ins/transition#the-transition-component) 组件来在页面和布局之间应用过渡效果。
::

::important
由于 Nuxt 使用 Vue 的 `<Transition>` 组件，因此需要动画化的页面或布局必须有一个**单一的根元素**。具有多个根元素的页面或布局（即片段）无法被动画化，因此过渡将不会执行，导航到不同路由时可能会出错。Nuxt 在开发过程中会对此进行提示。请将模板包裹在一个单一的根元素中（例如一个 `<div>`）。
::

## 页面过渡

您可以启用页面过渡功能，为所有 [页面](/docs/directory-structure/app/pages) 应用自动过渡效果。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'page', mode: 'out-in' },
  },
})
```

::note
如果您同时修改布局和页面，此处设置的页面过渡将不会执行。相反，您应该设置 [布局过渡](/docs/getting-started/transitions#layout-transitions)。
::

要开始在页面之间添加过渡效果，请在 [`app.vue`](/docs/directory-structure/app/app) 中添加以下 CSS 代码：

::code-group

```vue [app/app.vue]
<template>
  <NuxtPage />
</template>

<style>
.page-enter-active,
.page-leave-active {
  transition: all 0.4s;
}
.page-enter-from,
.page-leave-to {
  opacity: 0;
  filter: blur(1rem);
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Home page</h1>
    <NuxtLink to="/about">About page</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <div>
    <h1>About page</h1>
    <NuxtLink to="/">Home page</NuxtLink>
  </div>
</template>
```

::

::code-group

```vue twoslash [pages/about.vue]
  pageTransition: {
    name: 'rotate',
  },

```

```vue [app/app.vue]
<template>

/* ... */

.rotate-enter-from,
.rotate-leave-to {
  opacity: 0;
  transform: rotate3d(1, 1, 1, 15deg);

```

## 布局过渡

您可以启用布局过渡功能，为所有 [布局](/docs/directory-structure/app/layouts) 应用自动过渡效果。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    layoutTransition: { name: 'layout', mode: 'out-in' },
  },
})
```

要开始在页面和布局之间添加过渡效果，请在 [`app.vue`](/docs/directory-structure/app/app) 中添加以下 CSS 代码：

::code-group

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>

<style>
.layout-enter-active,
.layout-leave-active {
  transition: all 0.4s;
}
.layout-enter-from,
.layout-leave-to {
  filter: grayscale(1);
}
</style>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <pre>default layout</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: lightgreen;
}
</style>
```

```vue [app/layouts/orange.vue]
<template>
  <div>
    <pre>orange layout</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: #eebb90;
  padding: 20px;
  height: 100vh;
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Home page</h1>
    <NuxtLink to="/about">About page</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'orange',
})
</script>

<template>
  <div>
    <h1>About page</h1>
    <NuxtLink to="/">Home page</NuxtLink>
  </div>
</template>
```

## 全局设置

您可以通过 `nuxt.config` 全局自定义这些默认的过渡名称。

`pageTransition` 和 `layoutTransition` 键接受 [`TransitionProps`](https://vuejs.org/api/built-in-components#transition) 作为可序列化的 JSON 值，您可以在其中传递自定义 CSS 过渡的 `name`、`mode` 和其他有效的过渡属性。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: {
      name: 'fade',
      mode: 'out-in', // default
    },
    layoutTransition: {
      name: 'slide',
      mode: 'out-in', // default
    },
  },
})
```

::warning
如果您更改 `name` 属性，也必须相应地重命名 CSS 类。
::

要覆盖全局过渡属性，请使用 `definePageMeta` 为单个 Nuxt 页面定义页面或布局过渡，并覆盖 `nuxt.config` 文件中全局定义的任何页面或布局过渡。

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'bounce',
    mode: 'out-in', // default
  },
})
</script>
```

## 禁用过渡效果

`pageTransition` 和 `layoutTransition` 可以针对特定路由进行禁用：

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: false,
  layoutTransition: false,
})
</script>
```

或者在全球范围内在 `nuxt.config` 中设置：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: false,
    layoutTransition: false,
  },
})
```

## JavaScript Hooks

对于高级用例，您可以使用 JavaScript Hooks 为 Nuxt 页面创建高度动态且自定义的过渡效果。

这种方式非常适合使用 [GSAP](https://gsap.com) 等 JavaScript 动画库。

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'custom-flip',
    mode: 'out-in',
    onBeforeEnter: (el) => {
      console.log('Before enter...')
    },
    onEnter: (el, done) => {},
    onAfterEnter: (el) => {},
  },
})
</script>
```

::tip
了解更多关于 `Transition` 组件中可用的其他 [JavaScript Hooks](https://vuejs.org/guide/built-ins/transition#javascript-hooks)。
::

## 动态过渡

要使用条件逻辑应用动态过渡效果，您可以利用内联 [中间件](/docs/directory-structure/app/中间件) 为 `to.meta.pageTransition` 分配不同的过渡名称。

::code-group

```vue twoslash [pages/[id\\].vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'slide-right',
    mode: 'out-in',
  },
  middleware (to, from) {
    if (to.meta.pageTransition && typeof to.meta.pageTransition !== 'boolean') {
      to.meta.pageTransition.name = +to.params.id! > +from.params.id! ? 'slide-left' : 'slide-right'
    }
  },
})
</script>

<template>
  <h1>#{{ $route.params.id }}</h1>
</template>

<style>
.slide-left-enter-active,
.slide-left-leave-active,
.slide-right-enter-active,
.slide-right-leave-active {
  transition: all 0.2s;
}
.slide-left-enter-from {
  opacity: 0;
  transform: translate(50px, 0);
}
.slide-left-leave-to {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-enter-from {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-leave-to {
  opacity: 0;
  transform: translate(50px, 0);
}
</style>
```

```vue [app/layouts/default.vue]
<script setup lang="ts">
const route = useRoute()
const id = computed(() => Number(route.params.id || 1))
const prev = computed(() => '/' + (id.value - 1))
const next = computed(() => '/' + (id.value + 1))
</script>

<template>
  <div>
    <slot />
    <div v-if="$route.params.id">
      <NuxtLink :to="prev">⬅️</NuxtLink> |
      <NuxtLink :to="next">➡️</NuxtLink>
    </div>
  </div>
</template>
```

::

现在，页面在切换到下一个 id 时应用 `slide-left` 过渡效果，在切换到上一个 id 时应用 `slide-right` 过渡效果：

## 使用 NuxtPage 的过渡效果

当在 `app.vue` 中使用 `<NuxtPage />` 时，可以通过 `transition` 属性配置过渡效果，以全局启用过渡功能。

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage
        :transition="{
          name: 'bounce',
          mode: 'out-in',
        }"
      />
    </NuxtLayout>
  </div>
</template>
```

::note
请注意，此页面过渡无法通过 `definePageMeta` 在单个页面上覆盖。
::

## 视图过渡 API（实验性）

Nuxt 提供了 [**视图过渡 API**](https://developer.chrome.com/docs/web-platform/view-transitions) 的实验性实现（参见 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API））。这是一种令人兴奋的新方法，用于实现浏览器原生过渡效果，这些过渡效果能够在不同页面之间切换无关元素。

您可以在 [StackBlitz](https://stackblitz.com/edit/nuxt-view-transitions) 上查看演示。

您可以在配置文件中使用 `experimental.viewTransition` 选项启用 Nuxt 集成：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  experimental: {
    viewTransition: true,
  },
})
```

可能的值包括：`false`、`true` 或 `'always'`。

如果设置为 `true`，当用户浏览器符合 `prefers-reduced-motion: reduce`（推荐）设置时，Nuxt 将不会应用过渡效果。如果设置为 `always`，Nuxt 将始终应用过渡效果，而是否尊重用户的偏好则取决于您。

默认情况下，所有 [页面](/docs/directory-structure/app/pages) 都启用视图过渡，但您可以设置不同的全局默认值。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    // Disable view transitions globally, and opt-in on a per page basis
    viewTransition: false,
  },
})
```

可以通过在页面的 [`definePageMeta`](/docs/api/utils/define-page-meta) 中设置 `viewTransition` 键来覆盖页面的默认 `viewTransition` 值：

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: false,
})
</script>
```

::warning
仅在启用了 `experimental.viewTransition` 选项的情况下，针对单个页面覆盖视图过渡才有效。
::

### 视图过渡类型 :badge[v4.4]{color="info" size="xs" class="align-middle"}

[视图过渡类型](https://developer.chrome.com/blog/view-transitions-update-io24#view-transition-types) 允许根据导航类型应用不同的 CSS 动画。这对于创建非对称过渡效果非常有用（例如，向前和向后导航时应用不同的动画）。

类型设置在 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 上，可以使用 [`:active-view-transition-type()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:active-view-transition-type) 伪类选择器在 CSS 中指定目标类型。

你可以在 `nuxt.config.ts` 中全局设置默认类型：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    viewTransition: {
      enabled: true,
      types: ['slide'],
    },
  },
})
```

或者使用 `definePageMeta` 按页面配置类型。页面级别的类型支持静态数组和函数，以实现动态行为：

```vue twoslash [pages/detail.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    // Types applied to any transition involving this page
    types: ['slide'],
    // Types applied only when navigating TO this page
    toTypes: ['slide-in'],
    // Types applied only when navigating FROM this page
    fromTypes: ['slide-out'],
  },
})
</script>
```

你也可以在 `definePageMeta` 中的 `types`、`toTypes` 和 `fromTypes` 使用函数，根据路由动态确定类型：

```vue twoslash [pages/[id].vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    toTypes: (to, from) => {
      // Slide left when going to a higher ID, right otherwise
      return Number(to.params.id) > Number(from.params.id)
        ? ['slide-left']
        : ['slide-right']
    },
  },
})
</script>
```

然后可以在 CSS 中引用这些类型：

```css
/* Default crossfade */
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 0.3s;
}

/* Slide left animation */
html:active-view-transition-type(slide-left) {
  &::view-transition-old(root) {
    animation: slide-out-left 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-right 0.3s ease-in-out;
  }
}

/* Slide right animation */
html:active-view-transition-type(slide-right) {
  &::view-transition-old(root) {
    animation: slide-out-right 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-left 0.3s ease-in-out;
  }
}
```

::note
在 `definePageMeta` 中，`types`、`toTypes` 和 `fromTypes` 的函数值才有效，在 `nuxt.config.ts` 中无效（后者仅支持静态 `string[]`）。
::

`page:view-transition:start` 钩子提供了对 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 对象的访问权限，该对象包含 [`types`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition/types) 属性（`ViewTransitionTypeSet`），可以在运行时读取或修改：

```ts [plugins/view-transition.client.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('page:view-transition:start', (transition) => {
    // Read or modify types at runtime
    console.log([...transition.types])
  })
})
```

如果你也使用 `pageTransition` 和 `layoutTransition` 等 Vue 过渡效果（参见上文）来实现与新的 View Transitions API 相同的效果，那么如果用户的浏览器支持新的原生 Web API，你可能希望_禁用_ Vue 过渡。可以通过创建 `~/middleware/disable-vue-transitions.global.ts` 文件来实现这一点：

```ts
export default defineNuxtRouteMiddleware((to) => {
  if (import.meta.server || !document.startViewTransition) {
    return
  }

  // Disable built-in Vue transitions
  to.meta.pageTransition = false
  to.meta.layoutTransition = false
})
```

### 已知问题

- 如果你在页面设置函数中进行数据获取操作，可能需要暂时考虑不使用此功能。（按设计，View Transitions 在执行过程中会完全冻结 DOM 更新。我们正在研究将 View Transition 限制在 `<Suspense>` 解析前的最后时刻，但在那之前，如果你认为适合，请仔细考虑是否采用此功能。）
