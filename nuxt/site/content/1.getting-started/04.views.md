## `app.vue`

![The app.vue file is the entry point of your application](/assets/docs/getting-started/views/app.svg)

默认情况下，Nuxt 会将此文件视为 **入口文件**，并为应用程序的每个路由渲染其内容。

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
  </div>
</template>
```

::tip
如果您熟悉 Vue，可能会好奇 `main.js` 位于何处（该文件通常用于创建 Vue 应用）。Nuxt 会在背后完成这一操作。
::

## 组件

![Components are reusable pieces of UI](/assets/docs/getting-started/views/components.svg)

大多数组件都是用户界面的可复用部分，如按钮和菜单。在 Nuxt 中，您可以在 [`app/components/`](/docs/directory-structure/app/components) 目录中创建这些组件，它们将自动在应用程序中可用，无需显式导入。

::code-group

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component.
    </AppAlert>
  </div>
</template>
```

```vue [app/components/AppAlert.vue]
<template>
  <span>
    <slot />
  </span>
</template>
```

::

## 页面

![Pages are views tied to a specific route](/assets/docs/getting-started/views/pages.svg)

页面代表每个特定路由模式的视图。 [`app/pages/`](/docs/directory-structure/app/pages) 目录中的每个文件都代表一个不同的路由及其内容。

要使用页面，请创建 `app/pages/index.vue` 文件，并在 [`app/app.vue`](/docs/directory-structure/app/app) 中添加 `<NuxtPage />` 组件（或删除 `app/app.vue` 作为默认入口）。现在，您可以通过在 [`app/pages/`](/docs/directory-structure/app/pages) 目录中添加新文件来创建更多页面及其对应的路由。

::code-group

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

::

## 布局

![Layouts are wrapper around pages](/assets/docs/getting-started/views/layouts.svg)

布局是页面的包装器，包含多个页面的通用用户界面，如标题和页脚显示。布局是使用 `<slot />` 组件来显示 **页面** 内容的 Vue 文件。`app/layouts/default.vue` 文件将作为默认使用。自定义布局可以作为页面元数据的一部分进行设置。

::note
如果您在应用程序中只有一个布局，我们建议使用 [`app/app.vue`](/docs/directory-structure/app/app) 和 [`<NuxtPage />`](/docs/api/components/nuxt-page)。
::

::code-group

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </div>
</template>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <AppHeader />
    <slot />
    <AppFooter />
  </div>
</template>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

::

如果您想创建更多布局并了解如何在页面中使用它们，请查看 [布局部分](/docs/directory-structure/app/layouts)。

## 高级：扩展 HTML 模板

::note
如果您只需要修改 `<head>`，可以参考 [SEO 和元信息部分](/docs/getting-started/seo-meta)。
::

您可以通过添加注册了钩子的 Nitro 插件来完全控制 HTML 模板。
`render:html` 钩子的回调函数允许您在 HTML 发送到客户端之前对其进行修改。

<!-- TODO: figure out how to use twoslash to inject types for a different context -->

```ts [server/plugins/extend-html.ts]
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('render:html', (html, { event }) => {
    // This will be an object representation of the html template.
    console.log(html)
    html.head.push(`<meta name="description" content="My custom description" />`)
  })
  // You can also intercept the response here.
  nitroApp.hooks.hook('render:response', (response, { event }) => { console.log(response) })
})
```
