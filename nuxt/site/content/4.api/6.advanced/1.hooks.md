## 应用钩子（运行时）

请查看 [应用源代码](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/nuxt.ts#L37)，以了解所有可用的钩子。

| 钩子                         | 参数               | 环境             | 描述                                                                                                                                                                           |
|------------------------------|---------------------|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `app:created`                | `vueApp`           | 服务器与客户端    | 在初始 `vueApp` 实例创建时调用。                                                                                                                                             |
| `app:error`                  | `err`               | 服务器与客户端    | 发生致命错误时调用。                                                                                                                                                         |
| `app:error:cleared`          | `{ redirect? }`      | 服务器与客户端    | 发生致命错误时调用。                                                                                                                                                         |
| `vue:setup`                  | -                   | 服务器与客户端    | Nuxt 根组件的 setup 初始化时调用。此回调必须是同步的。                                                                                                 |
| `vue:error`                  | `err, target, info` | 服务器与客户端    | 当 vue 错误传播到根组件时调用。[了解更多](https://vuejs.org/api/composition-api-lifecycle#onerrorcaptured)。                                              |
| `app:rendered`               | `renderContext`     | 服务器            | SSR 渲染完成后调用。                                                                                                                                                          |
| `app:redirected`             | -                   | 服务器            | SSR 重定向之前调用。                                                                                                                                                            |
| `app:beforeMount`            | `vueApp`            | 客户端          | 在应用挂载前调用，仅在客户端侧调用。                                                                                                                           |
| `app:mounted`                | `vueApp`            | 客户端          | 当 Vue 应用在浏览器中初始化并挂载时调用。                                                                                                                            |
| `app:suspense:resolve`       | `appComponent`      | 客户端          | 在 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense) 解析事件时调用。                                                                                                    |
| `app:manifest:update`        | `{ id, timestamp }` | 客户端          | 当检测到应用的新版本时调用。                                                                                                                            |
| `app:data:refresh`           | `keys?`             | 客户端          | 当调用 `refreshNuxtData` 时调用。                                                                                                                                              |
| `link:prefetch`              | `to`                | 客户端          | 当观察到 `<NuxtLink>` 被预加载时调用。                                                                                                                              |
| `page:start`                 | `pageComponent?`    | 客户端          | 在 `NuxtPage` 的 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense) 待处理事件时调用。                                                                         |
| `page:finish`                | `pageComponent?`    | 客户端          | 在 `NuxtPage` 的 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense) 解析事件时调用。                                                                        |
| `page:loading:start`         | -                   | 客户端          | 当路由导航开始（在解析前）或页面 key 发生变化时调用。如果页面被复用，可能无需重新运行页面组件的 `setup()`，例如使用 `definePageMeta` 中的静态 `key`。 |
| `page:loading:end`           | -                   | 客户端          | 在 `page:finish` 之后调用                                                                                                                                                            |
| `page:transition:finish`     | `pageComponent?`    | 客户端          | 页面过渡完成后，通过 [onAfterLeave](https://vuejs.org/guide/built-ins/transition#javascript-hooks) 事件触发。                                                                            |
| `dev:ssr-logs`               | `logs`              | 客户端          | 当 `features.devLogs` 被启用时，将服务器端的日志数组传递给客户端调用。                                                                      |
| `page:view-transition:start` | `transition`        | 客户端          | 在 [实验性 viewTransition 支持被启用时](/docs/getting-started/transitions#view-transitions-api-experimental)，在 `document.startViewTransition` 被调用后调用。`transition` 参数是一个 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 对象，该对象具有可读取或修改的 `types` 属性 ([`ViewTransitionTypeSet`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransitionTypeSet))。 |

## Nuxt Hooks（构建时）

请查看 [schema 源代码](https://github.com/nuxt/nuxt/blob/main/packages/schema/src/types/hooks.ts#L83) 以了解所有可用的组合式函数。

| 组合式函数                | 参数                                                                                   | 描述                                                                                                                                                                                                                                                                                  |
|-----------------------------|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `kit:compatibility`         | `compatibility, issues`                                  | 允许扩展兼容性检查。                                                                                                                                                                                                                                                       |
| `ready`                     | `nuxt`                                                   | 在 Nuxt 初始化后，当 Nuxt 实例准备运行时调用。                                                                                                                                                                                                                        |
| `close`                     | `nuxt`                                                   | 当 Nuxt 实例优雅关闭时调用。                                                                                                                                                                                                                                                |
| `restart`                   | `{ hard?: boolean }`                                     | 用于重启当前的 Nuxt 实例。                                                                                                                                                                                                                                                |
| `modules:before`            | -                                                        | 在 Nuxt 初始化期间调用，在安装用户模块之前。                                                                                                                                                                                                                              |
| `modules:done`              | -                                                        | 在 Nuxt 初始化期间调用，在安装用户模块之后。                                                                                                                                                                                                                              |
| `module:before`             | `module`                                                 | 在每个单独模块设置之前立即调用。                                                                                                                                                                                                                                          |
| `module:done`               | `module`                                                 | 在每个独立模块设置完成后立即调用，包括所花费的时间。                                                                                                                                                                                                  |
| `app:resolve`               | `app`                                                    | 在解析 `app` 实例后调用                                                                                                                                                                                                                                                   |
| `app:templates`             | `app`                                                    | 在 `NuxtApp` 生成过程中调用，用于自定义、修改或向构建目录添加新文件（无论是虚拟文件还是写入 `.nuxt` 文件）。                                                                                                                                  |
| `app:templatesGenerated`    | `app`                                                    | 在模板被编译为 [虚拟文件系统](/docs/directory-structure/nuxt) (vfs) 后调用。                                                                                                                                                                                |
| `build:before`              | -                                                        | 在 Nuxt 包构建器之前调用。                                                                                                                                                                                                                                                           |
| `build:done`                | -                                                        | 在 Nuxt 包构建器完成后调用。                                                                                                                                                                                                                                                |
| `build:manifest`            | `manifest`                                               | 由 Vite 和 webpack 在 manifest 构建过程中调用。这允许自定义 Nitro 在最终 HTML 中渲染 `<script>` 和 `<link>` 标签所使用的 manifest，包括每个入口的 `prefetch` 和 `preload` 标志。                                                                  |
| `builder:generateApp`       | `options`                                                | 在生成应用之前调用。                                                                                                                                                                                                                                                            |
| `builder:watch`             | `event, path`                                            | 在开发过程中，当观察器检测到项目中的文件或目录发生变化时，在构建阶段调用。                                                                                                                                                                                   |
| `pages:extend`              | `pages`                                                  | 从文件系统扫描出页面路由后调用。                                                                                                                                                                                                                                   |
| `pages:resolved`            | `pages`                                                  | 在通过扫描的元数据增强页面路由后调用。                                                                                                                                                                                                                          |
| `pages:routerOptions`       | `{ files: Array<{ path: string, optional?: boolean }> }` | 在解析 `router.options` 文件时调用。数组中的后续项会覆盖之前的项。                                                                                                                                                                                                |
| `server:routes`             | `routes`, `context`                                      | 在 Nuxt 需要服务器提供的所有路由处理程序时调用，以便可以针对它们使用 `$fetch` 和 `useFetch`。                                                                                                                                                        |
| `server:devHandler`         | `handler`                                                | 在 Nitro 开发服务器注册开发中间件时调用。                                                                                                                                                                                                                  |
| `imports:sources`           | `presets`                                                | 在 setup 阶段调用，允许模块扩展源文件。                                                                                                                                                                                                                                          |
| `imports:extend`            | `imports`                                                | 在 setup 阶段调用，允许模块扩展导入项。                                                                                                                                                                                                                                          |
| `imports:context`           | `context`                                                | 在创建 [unimport](https://github.com/unjs/unimport) 上下文时调用。                                                                                                                                                                                                             |
| `imports:dirs`              | `dirs`                                                   | 允许扩展导入目录。                                                                                                                                                                                                                                                         |
| `components:dirs`           | `dirs`                                                   | 在 `app:resolve` 中调用，用于扩展用于自动导入组件的目录。                                                                                                                                                                          |
| `components:extend`         | `components`                                             | 用于扩展新组件。                                                                                                                                                                                                                                                             |
| `nitro:config`              | `nitroConfig`                                            | 在初始化 Nitro 之前调用，用于自定义 Nitro 配置。                                                                                                                                                                                                           |
| `nitro:init`                | `nitro`                                                  | 在 Nitro 初始化之后调用，用于注册 Nitro 钩子并直接与 Nitro 交互。                                                                                                                                                                                 |
| `nitro:build:before`        | `nitro`                                                  | 在构建 Nitro 实例之前调用。                                                                                                                                                                                                                                                   |
| `nitro:build:public-assets` | `nitro`                                                  | 在复制公共资产之后调用。允许在 Nitro 服务器构建之前修改公共资产。                                                                                                                                                                                             |
| `prerender:routes`          | `ctx`                                                    | 允许扩展路由以进行预渲染。                                                                                                                                                                                                                                              |
| `build:error`               | `error`                                                  | 在构建过程中出现错误时调用。                                                                                                                                                                                                                                                   |
| `prepare:types`             | `options`                                                | `@nuxt/cli` 在写入 TypeScript 配置文件（`.nuxt/tsconfig.app.json`、`.nuxt/tsconfig.server.json` 等）和 `.nuxt/nuxt.d.ts` 之前调用此函数，允许在 `nuxt.d.ts` 中添加自定义引用和声明，或直接修改生成的配置中的选项。 |
| `listen`                    | `listenerServer, listener`                               | 开发服务器加载时调用。                                                                                                                                                                                                                                                       |
| `schema:extend`             | `schemas`                                                | 允许扩展默认Schema。                                                                                                                                                                                                                                                            |
| `schema:resolved`           | `schema`                                                 | 允许扩展已解析的Schema。                                                                                                                                                                                                                                                            |
| `schema:beforeWrite`        | `schema`                                                 | 在写入给定 schema 之前被调用。                                                                                                                                                                                                                                                      |
| `schema:written`            | -                                                        | 在 schema 写入之后被调用。                                                                                                                                                                                                                                                          |
| `vite:extend`               | `viteBuildContext`                                       | 允许扩展 Vite 默认上下文。                                                                                                                                                                                                                                                       |
| `vite:extendConfig`         | `viteInlineConfig, env`                                  | 允许扩展 Vite 默认配置。**在 Nuxt 5+ 中已弃用。**在 Nuxt 5 中，此功能基于共享配置运行，而非独立的客户端/服务器配置。                                                                                                                              |
| `vite:configResolved`       | `viteInlineConfig, env`                                  | 允许读取解析后的 Vite 配置。**在 Nuxt 5+ 中已弃用。**在 Nuxt 5 中，此功能基于共享配置运行，而非独立的客户端/服务器配置。                                                                                                                           |
| `vite:serverCreated`        | `viteServer, env`                                        | 在 Vite 服务器创建时被调用。                                                                                                                                                                                                                                                      |
| `vite:compiled`             | -                                                        | 在 Vite 服务器编译后调用。                                                                                                                                                                                                                                                        |
| `webpack:config`            | `webpackConfigs`                                         | 在配置 webpack 编译器之前调用。                                                                                                                                                                                                                                              |
| `webpack:configResolved`    | `webpackConfigs`                                         | 用于读取已解析的 webpack 配置。                                                                                                                                                                                                                                                  |
| `webpack:compile`           | `options`                                                | 在编译之前直接调用。                                                                                                                                                                                                                                                             |
| `webpack:compiled`          | `options`                                                | 在资源加载后调用。                                                                                                                                                                                                                                                           |
| `webpack:change`            | `shortPath`                                              | 在 WebpackBar 的 `change` 事件时调用。                                                                                                                                                                                                                                                            |
| `webpack:error`             | -                                                        | 如果在 WebpackBar 出现错误，则会在 `done` 时调用。                                                                                                                                                                                                                                                |
| `webpack:done`              | -                                                        | 在 WebpackBar 的 `allDone` 时调用。                                                                                                                                                                                                                                                           |
| `webpack:progress`          | `statesArray`                                            | 在 WebpackBar 的 `progress` 时调用。                                                                                                                                                                                                                                                          |

|-------------------|--------------------------------------------|---------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| `render:response` | `response, { event }`                      | 在发送响应之前调用。                        | [response](https://github.com/nuxt/nuxt/blob/71ef8bd3ff207fd51c2ca18d5a8c7140476780c7/packages/nuxt/src/core/runtime/nitro/renderer.ts#L24), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)                                                                                                                                                         |
| `render:html`     | `html, { event }`                          | 在构建 HTML 之前调用。                      | [html](https://github.com/nuxt/nuxt/blob/71ef8bd3ff207fd51c2ca18d5a8c7140476780c7/packages/nuxt/src/core/runtime/nitro/renderer.ts#L15), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)                                                                                                                                                             |

| `beforeResponse`  | `event, { body }`                          | 在发送响应之前调用。                        | [事件](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), 类型未知                                                                                                                                                                                                                                                                                             |
