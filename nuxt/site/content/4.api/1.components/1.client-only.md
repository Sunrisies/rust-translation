`<ClientOnly>` 组合式函数用于专门在客户端渲染组件。

::note
默认插槽的内容将在服务器构建过程中进行摇树优化。（这意味着其中使用的任何 CSS 在初始 HTML 渲染时可能不会被内联。）
::

## Props

- `placeholderTag` | `fallbackTag`：指定在服务器端渲染的标签。
- `placeholder` | `fallback`：指定在服务器端渲染的内容。

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- The <Comment> component will only be rendered on client-side -->
    <ClientOnly
      fallback-tag="span"
      fallback="Loading comments..."
    >
      <Comment />
    </ClientOnly>
  </div>
</template>
```

## Slots

- `#fallback`：指定在服务器上渲染并在浏览器中显示直到 `<ClientOnly>` 挂载的内容。

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- This renders the "span" element on the server side -->
    <ClientOnly fallback-tag="span">
      <!-- this component will only be rendered on client side -->
      <Comments />
      <template #fallback>
        <!-- this will be rendered on server side -->
        <p>Loading comments...</p>
      </template>
    </ClientOnly>
  </div>
</template>
```

## Example

### 访问 HTML 元素

位于 `<ClientOnly>` 内的组件仅在挂载后才会被渲染。要访问 DOM 中渲染的元素，可以查看模板引用：

```vue [app/pages/example.vue]
<script setup lang="ts">
const nuxtWelcomeRef = useTemplateRef('nuxtWelcomeRef')

// The watch will be triggered when the component is available
watch(nuxtWelcomeRef, () => {
  console.log('<NuxtWelcome /> mounted')
}, { once: true })
</script>

<template>
  <ClientOnly>
    <NuxtWelcome ref="nuxtWelcomeRef" />
  </ClientOnly>
</template>
```
