如果 Nuxt 的子组件在 SSR 过程中触发错误，Nuxt 会提供 `<NuxtClientFallback>` 组件在客户端上渲染其内容。

::note{to="/docs/guide/going-further/experimental-features#clientfallback"}
该组件为实验性组件，要使用它，必须在 `nuxt.config` 中启用 `experimental.clientFallback` 选项。
::

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- this component will be rendered on client-side -->
    <NuxtClientFallback fallback-tag="span">
      <Comments />
      <BrokeInSSR />
    </NuxtClientFallback>
  </div>
</template>
```

## 事件

- `@ssr-error`：当子组件在 SSR 过程中触发错误时发射的事件。注意，此事件仅在服务器上触发。

  ```vue
  <template>
    <NuxtClientFallback @ssr-error="logSomeError">
      <!-- ... -->
    </NuxtClientFallback>
  </template>
  ```

## 属性

- `placeholderTag` | `fallbackTag`：指定如果插槽在服务器上无法渲染时要渲染的备用标签。
  - **type**：`string`
  - **default**：`div`
- `placeholder` | `fallback`：指定如果插槽无法渲染时要渲染的备用内容。
  - **type**：`string`
- `keepFallback`：如果备用内容在服务器端无法渲染，则保留该内容。
  - **type**：`boolean`
  - **default**：`false`

::warning{icon="i-ph-warning-duotone"}
`placeholder` 和 `fallback` 属性以原始 HTML 形式渲染内容。不要将不可信的用户输入传递给这些属性，因为这可能导致 XSS 漏洞。对于需要正确转义的动态内容，请使用 `#fallback` 或 `#placeholder` 插槽。
::

```vue
<template>
  <!-- render <span>Hello world</span> server-side if the default slot fails to render -->
  <NuxtClientFallback
    fallback-tag="span"
    fallback="Hello world"
  >
    <BrokeInSSR />
  </NuxtClientFallback>
</template>
```

## 插槽

- `#fallback`：指定如果插槽无法在服务器端渲染时要在服务器上显示的内容。

```vue
<template>
  <NuxtClientFallback>
    <!-- ... -->
    <template #fallback>
      <!-- this will be rendered on server side if the default slot fails to render in ssr -->
      <p>Hello world</p>
    </template>
  </NuxtClientFallback>
</template>
```
