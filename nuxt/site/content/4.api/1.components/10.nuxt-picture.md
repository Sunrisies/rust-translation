`<NuxtPicture>` 是原生 `<picture>` 标签的替代方案。

使用 `<NuxtPicture>` 的方式与 [`<NuxtImg>`](/docs/api/components/nuxt-img) 几乎相同，但它还允许在可能的情况下提供 `webp` 等现代格式。

更多关于 [`<picture>` 标签的信息`，请参见 MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/picture)。

## 设置

要使用 `<NuxtPicture>`，您应该安装并启用 Nuxt Image 模块：

```bash [Terminal]
npx nuxt module add image
```
