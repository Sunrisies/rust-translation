`<NuxtImg>` 是原生 `<img>` 标签的替代方案。

- 使用内置提供器来优化本地和远程图片
- 将 `src` 转换为由提供器优化的 URL
- 根据 `width` 和 `height` 自动调整图片尺寸
- 在提供 `sizes` 选项时生成响应式尺寸
- 支持原生延迟加载以及其他 `<img>` 属性

## 设置

要使用 <NuxtImg>，您应该安装并启用 Nuxt Image 模块：

```bash [Terminal]
npx nuxt module add image
```

## 使用

`<NuxtImg>` 直接输出原生 `img` 标签（无需任何包装）。使用方式与使用 `<img>` 标签相同：

```html
<NuxtImg src="/nuxt-icon.png" />
```

结果如下：

```html
<img src="/nuxt-icon.png" />
```
