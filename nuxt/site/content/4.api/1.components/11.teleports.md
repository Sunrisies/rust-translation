---
title: <Teleport>
description: <Teleport> 组件可以将一个组件移动到 DOM 中的不同位置。
---

::warning
[<Teleport>](https://vuejs.org/guide/built-ins/teleport) 的 `to` 目标可以是一个 CSS 选择器字符串或一个实际的 DOM 节点。目前 Nuxt 仅对 `#teleports` 类型的 teleport 提供 SSR 支持，对于其他目标则使用 `<ClientOnly>` 包装器并提供客户端侧支持。
::

## Body Teleport

```vue
<template>
  <button @click="open = true">
    Open Modal
  </button>
  <Teleport to="#teleports">
    <div
      v-if="open"
      class="modal"
    >
      <p>Hello from the modal!</p>
      <button @click="open = false">
        Close
      </button>
    </div>
  </Teleport>
</template>
```

## 客户端侧 Teleport

```vue
<template>
  <ClientOnly>
    <Teleport to="#some-selector">
      <!-- content -->
    </Teleport>
  </ClientOnly>
</template>
```
