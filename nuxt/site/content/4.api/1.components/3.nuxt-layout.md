您可以使用 `<NuxtLayout />` 组件在 `app.vue` 或 `error.vue` 中激活 `default` 布局。

```vue [app/app.vue]
<template>
  <NuxtLayout>
    some page content
  </NuxtLayout>
</template>
```

:read-more{to="/docs/directory-structure/app/layouts"}

## Props

- `name`: 指定要渲染的布局名称，可以是字符串、响应式引用或计算属性。该值**必须**与 [`app/layouts/`](/docs/directory-structure/app/layouts) 目录中对应布局文件的名称一致，或设置为 `false` 以禁用该布局。
  - **type**: `string | false`
  - **default**: `default`

```vue [app/pages/index.vue]
<script setup lang="ts">
// layouts/custom.vue
const layout = 'custom'
</script>

<template>
  <NuxtLayout :name="layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

::note
请注意，布局名称会被规范为 kebab-case 格式，因此如果您的布局文件名为 `errorLayout.vue`，在作为 `name` 属性传递给 <NuxtLayout > 时将会变为 `error-layout`。
::

```vue [error.vue]
<template>
  <NuxtLayout name="error-layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

::read-more{to="/docs/directory-structure/app/layouts"}
了解更多关于动态布局的信息。
::

- `fallback`: 如果向 `name` prop 传递无效的布局，则不会渲染任何布局。在此情况下，请指定一个要渲染的 `fallback` 布局。该值**必须**与 [`app/layouts/`](/docs/directory-structure/app/layouts) 目录中对应布局文件的名称一致。
  - **type**: `string`
  - **default**: `null`

## 其他 Props

<NuxtLayout> 还接受您可能需要传递给布局的任何额外 Props。这些自定义 Props 随后可以作为属性使用。

```vue [app/pages/some-page.vue]
<template>
  <div>
    <NuxtLayout
      name="custom"
      title="I am a custom layout"
    >
      <!-- ... -->
    </NuxtLayout>
  </div>
</template>
```

在上述示例中，`title` 的值可以通过模板中的 `$attrs.title` 或在 custom.vue 中的 `useAttrs().title` 获取。

```vue [app/layouts/custom.vue]
<script setup lang="ts">
const layoutCustomProps = useAttrs()

console.log(layoutCustomProps.title) // I am a custom layout
</script>
```

## 来自页面元数据的布局 Props

当使用 [`definePageMeta`](/docs/api/utils/define-page-meta) 并以对象语法定义 `layout` 时，Props 会自动传递给布局组件。通过 `defineProps` 可以接收这些 Props。

```vue [app/pages/dashboard.vue]
<script setup lang="ts">
definePageMeta({
  layout: {
    name: 'admin',
    props: {
      sidebar: true,
    },
  },
})
</script>
```

```vue [app/layouts/admin.vue]
<script setup lang="ts">
const props = defineProps<{
  sidebar?: boolean
}>()
</script>
```

::read-more{to="/docs/directory-structure/app/layouts#passing-props-to-layouts"}
了解更多关于向布局传递 Props 的信息。
::

## 过渡效果

<NuxtLayout> 通过 `<slot />` 渲染传入的内容，然后将其包裹在 Vue 的 `<Transition />` 组件周围以激活布局过渡效果。为确保正常运作，建议 <NuxtLayout > 不是页面组件的根元素。

::code-group

```vue [app/pages/index.vue]
<template>
  <div>
    <NuxtLayout name="custom">
      <template #header>
        Some header template content.
      </template>
    </NuxtLayout>
  </div>
</template>
```

```vue [app/layouts/custom.vue]
<template>
  <div>
    <!-- named slot -->
    <slot name="header" />
    <slot />
  </div>
</template>
```

::

:read-more{to="/docs/getting-started/transitions"}

## 布局的 Ref

要获取布局组件的 ref，可通过 `ref.value.layoutRef` 访问。

::code-group

```vue [app/app.vue]
<script setup lang="ts">
const layout = ref()

function logFoo () {
  layout.value.layoutRef.foo()
}
</script>

<template>
  <NuxtLayout ref="layout">
    default layout
  </NuxtLayout>
</template>
```

```vue [app/layouts/default.vue]
<script setup lang="ts">
const foo = () => console.log('foo')
defineExpose({
  foo,
})
</script>

<template>
  <div>
    default layout
    <slot />
  </div>
</template>
```
