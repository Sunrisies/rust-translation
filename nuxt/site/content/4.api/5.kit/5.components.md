组件是你的 Nuxt 应用程序的基础构建块。它们是可重用的 Vue 实例，可用于创建用户界面。在 Nuxt 中，来自 components 目录的组件默认会被自动导入。然而，如果你需要从其他目录导入组件或根据需求选择性导入组件，@nuxt/kit 提供了 `addComponentsDir` 和 `addComponent` 方法。这些工具允许你自定义组件配置，以更好地满足你的需求。

## `addComponentsDir`

注册一个目录以进行组件扫描，并在使用时才导入该目录。请注意，这不会全局注册组件，除非你指定 `global: true` 选项。

### 使用方式

```ts
export default defineNuxtModule({
  meta: {
    name: '@nuxt/ui',
    configKey: 'ui',
  },
  setup () {
    addComponentsDir({
      path: resolve('./runtime/components'),
      prefix: 'U',
      pathPrefix: false,
    })
  },
})
```

### 类型

```ts
function addComponentsDir (dir: ComponentsDir, opts: { prepend?: boolean } = {}): void
```

### 参数

`dir` 一个包含以下属性的对象：

| 属性                | 类型                                                                                     | 必填 | 描述                                                                                                                                                                                                                                             |
|-------------------|------------------------------------------------------------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `path`             | `string`                                                                                 | `true` | 包含组件的目录路径（绝对或相对）。你可以使用 Nuxt 别名 (~ 或 @) 来引用项目内的目录，或者直接使用类似于 require 的 npm 包路径。                                               |
| `pattern`          | `string \| string[]{lang="ts"}`                                                          | `false` | 接受的模式，该模式将针对指定的路径进行匹配。                                                                                                                                                                                                 |
| `ignore`           | `string[]`                                                                               | `false` | 忽略将针对指定路径进行的匹配模式。                                                                                                                                                                                                |
| `prefix`          | `string`                                                                                 | `false`  | 用此字符串对匹配到的组件添加前缀。                                                                                                                                                                                                         |
| `pathPrefix`      | `boolean`                                                                                | `false`  | 根据组件路径为组件名称添加前缀。                                                                                                                                                                                                                      |
| `prefetch`        | `boolean`                                                                                | `false`  | 这些属性（prefetch/preload）在生产环境中用于通过 webpack 的魔法注释配置带有 Lazy 前缀的组件的处理方式。更多详情请参阅 [webpack 文档](https://webpack.js.org/api/module-methods/#magic-comments)。 |
| `preload`         | `boolean`                                                                                | `false`  | 这些属性（prefetch/preload）在生产环境中用于通过 webpack 的魔法注释配置带有 Lazy 前缀的组件的处理方式。更多详情请参阅 [webpack 文档](https://webpack.js.org/api/module-methods/#magic-comments)。 |
| `isAsync`         | `boolean`                                                                                | `false`  | 此标志指示组件是否应异步加载（通过独立的 chunk 文件），无论是否使用 Lazy 前缀。                                                                                                                                   |
| `extendComponent` | `(component: Component) => Promise<Component \| void> \| (Component \| void)`{lang="ts"} | `false`  | 这是一个函数，用于处理目录中找到的每个组件。它接受一个组件对象，并应返回一个组件对象或一个解析为组件对象的 Promise。                                                          |
| `global`          | `boolean`                                                                                | `false`  | 如果启用，会将组件注册为全局可用组件。                                                                                                                                                                                              |
| `island`          | `boolean`                                                                                | `false`  | 如果启用，会将组件注册为独立岛屿。您可以在 [`<NuxtIsland/>`](/docs/api/components/nuxt-island) 组件描述中了解有关岛屿的更多信息。                                                                                          |
| `watch`           | `boolean`                                                                                | `false`  | 监控指定路径的变化，包括文件的添加和删除。                                                                                                                                                                          |
| `extensions`      | `string[]`                                                                               | `false`  | Nuxt 构建器支持的扩展项。                                                                                                                                                                                                                   |
| `transpile`       | `'auto' \| boolean`{lang="ts"}                                                           | `false`  | 使用 build.transpile 对指定路径进行转换。如果设置为 `'auto'`，且 `node_modules/` 在路径中，则会将 `transpile: true` 设置到该值。                                                                                                                        |

`opts`

| Property  | Type      | Required | Description                                                                                          |
|-----------|-----------|----------|------------------------------------------------------------------------------------------------------|
| `prepend` | `boolean` | `false`  | 如果设置为 `true`，目录将通过 `unshift()` 而不是 `push()` 添加到数组中。 |

## `addComponent`

注册一个将自动导入的组件。

### 使用说明

```ts
import { addComponent, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  meta: {
    name: '@nuxt/image',
    configKey: 'image',
  },
  setup () {
    const resolver = createResolver(import.meta.url)

    addComponent({
      name: 'NuxtImg',
      filePath: resolver.resolve('./runtime/components/NuxtImg.vue'),
    })

    addComponent({
      name: 'NuxtPicture',
      filePath: resolver.resolve('./runtime/components/NuxtPicture.vue'),
    })
  },
})
```

### 类型

```ts
function addComponent (options: AddComponentOptions): void
```

### 参数

`options`: 一个包含以下属性的对象：

| 属性                | 类型                                       | 必填 | 描述                                                                                                                                                                                                                                             |
|-------------------|--------------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|  
| `name`              | `string`                                   | `true` | 组件名称。                                                                                                                                                                                                                                         |
| `filePath`          | `string`                                   | `true` | 组件的路径。                                                                                                                                                                                                                                  |
| `declarationPath`   | `string`                                   | `false` | 组件声明文件的路径。用于生成组件의 [类型模板](/docs/api/kit/templates#addtypetemplate)；如果未提供，则使用 `filePath`。                                                                      |
| `pascalName`        | `string`                                   | `false` | Pascal 大小写的组件名称。如果未提供，将从组件名称生成。                                                                                                                                                              |
| `kebabName`         | `string`                                   | `false` | Kebab 大小写的组件名称。如果未提供，将从组件名称生成。                                                                                                                                                               |
| `export`            | `string`                                   | `false` | 指定命名导出或默认导出。如果未提供，将设置为 `'default'`。                                                                                                                                          |
| `shortPath`       | `string`                                   | `false`  | 组件的短路径。如果未提供，则从组件路径生成。                                                                                                                                                             |
| `chunkName`       | `string`                                   | `false`  | 组件的块名称。如果未提供，则从组件名称生成。                                                                                                                                                            |
| `prefetch`        | `boolean`                                  | `false`  | 这些属性（prefetch/preload）在生产环境中用于通过 webpack 的魔法注释配置带有 Lazy 前缀的组件的处理方式。更多详情请参阅 [webpack 文档](https://webpack.js.org/api/module-methods/#magic-comments) |
| `preload`         | `boolean`                                  | `false`  | 这些属性（prefetch/preload）在生产环境中用于通过 webpack 的魔法注释配置带有 Lazy 前缀的组件的处理方式。更多详情请参阅 [webpack 文档](https://webpack.js.org/api/module-methods/#magic-comments) |
| `global`          | `boolean`                                  | `false`  | 如果启用，将注册该组件使其可在全局使用。                                                                                                                                                                                               |
| `island`          | `boolean`                                  | `false`  | 如果启用，将将该组件注册为岛屿组件。关于岛屿组件的更多信息，请参阅 [`<NuxtIsland/>`](/docs/api/components/nuxt-island) 组件描述。                                                                                            |
| `mode`            | `'client' \| 'server' \| 'all'`{lang="ts"} | `false`  | 此选项指示组件应在客户端、服务器或两者上渲染。默认情况下，它将在客户端和服务器上均进行渲染。                                                                                                                      |
| `priority`        | `number`                                   | `false`  | 组件的优先级。如果多个组件名称相同，则使用优先级最高的那个。                                                                                                                                   |

### 示例

如果您希望从 npm 包中自动导入组件，且该组件是命名导出（而非默认导出），可以使用 `export` 选项来指定它。

```ts
import { addComponent, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    // import { MyComponent as MyAutoImportedComponent } from 'my-npm-package'
    addComponent({
      name: 'MyAutoImportedComponent',
      export: 'MyComponent',
      filePath: 'my-npm-package',
    })
  },
})
```
