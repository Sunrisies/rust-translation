安装 Leaflet

Leaflet 2.0.0-beta.5 是 Leaflet 2.0 的测试版本，该版本采用 ES 模块和类结构进行重构。请查看更新日志了解新功能，若从 1.x 升级，请参考迁移指南。例如，如果您的应用依赖尚未支持 2.0 的插件，仍应使用 Leaflet 1.9.4 版本以保持在 1.x 版本上运行。

使用 npm

如果您使用 Vite 等 bundler 构建应用，可通过 npm 安装 Leaflet：

npm install leaflet@beta 然后导入所需的类以及 Leaflet CSS：

import {LeafletMap, TileLayer} from 'leaflet'; import 'leaflet/styles.css'; const map = new LeafletMap('map').setView([51.505, -0.09], 13); new TileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', { maxZoom: 19, attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>' }).addTo(map); 该包包含 TypeScript 类型，因此无需单独安装 @types 包。

使用 CDN

无需构建步骤，可通过带有 import map 的 CDN 加载 Leaflet，该 map 指示浏览器“leaflet”导入的来源。将其放在页面的 head 中：

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@2.0.0-beta.5/dist/leaflet.css" integrity="sha256-LJzbbQFquR1Trwrwy++9x2Pl6ipfBZUR8Da0GGJ8Wfo=" crossorigin="anonymous"> <script type="importmap"> { "imports": { "leaflet": "https://cdn.jsdelivr.net/npm/leaflet@2.0.0-beta.5/dist/leaflet.js" }, "integrity": { "https://cdn.jsdelivr.net/npm/leaflet@2.0.0-beta.5/dist/leaflet.js": "sha256-wtAeAyJwpxq8jkj3LfBxdh3sPS3xw9kViJv+AtdXLDE=" } } </script> 然后像使用 npm 一样在模块脚本中导入 Leaflet：

<script type="module"> import {LeafletMap, TileLayer} from 'leaflet'; const map = new LeafletMap('map').setView([51.505, -0.09], 13); </script> 完整性哈希确保从 CDN 获取的文件与我们发布的版本一致，因此在复制代码片段时请保留它们。Leaflet 也存在于 unpkg 和 cdnjs 中。

这些服务是 Leaflet 之外的外部资源；如有疑问或支持需求，请直接联系它们。

自行将 Leaflet 部署到服务器时，请从发布页面下载 leaflet.zip 文件。该文件中包含：

  • leaflet.js：经过压缩的 Leaflet ES 模块版本。
  • leaflet-global.js：与经典脚本相同，用于定义全局 L 变量。
  • leaflet.css：样式表文件。无需复制任何图片。
  • 两个脚本都包含源映射，因此浏览器开发者工具在调试时可显示原始源码。

    从源代码构建

    若需自行构建 Leaflet，请克隆仓库后安装 Node.js 并运行：

    npm install npm run build 构建后的文件将保存到 dist 文件夹中。
