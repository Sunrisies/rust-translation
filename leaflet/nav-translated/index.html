Leaflet 是用于构建强大交互地图的领先开源 JavaScript 库。其 JS 文件仅约 40 KB，具备大多数开发者所需的所有地图功能。

Leaflet 的设计注重简洁性、性能与易用性。它在所有主要桌面和移动平台上都能高效运行，可通过大量插件进行扩展，拥有美观、易于使用且文档完善的 API，以及简单易读的源代码，非常适合贡献者参与开发。它支撑着数百万个网站中的地图功能，每周有超过 1000 万次 npm 下载量。

在这里，我们在 “map” div 中创建地图，添加自己选择的瓦片，然后在弹出框中添加带有文字的标记：

import {LeafletMap, TileLayer, Marker} from 'leaflet'; const map = new LeafletMap('map').setView([51.505, -0.159], 15); new TileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', { attribution: '© <a href="https://www.openstreetmap.org/copyright>OpenStreetMap</a>' }).addTo(map); new Marker([51.504, -0.159]).addTo(map) .bindPopup('A pretty CSS popup.<br>Easily customizable.') .openPopup();Learn more with the quick start guide, check out other tutorials, or head straight to the API documentation. Leaflet 不会试图为所有人完成所有事情，而是专注于让核心功能运行得非常好。

  • 标记、弹出框和工具提示
  • 多线、多边形、圆形
  • 图像、视频和 SVG 覆盖层
  • 具有惯性效果的平滑平移
  • 使用滚轮、捏合、双击或 Shift-Drag 进行缩放
  • 支持鼠标、触摸和笔操作
  • 可拖动的标记
  • 缩放、图层、比例、全屏显示和归属信息控制
  • 由 GPU 加速的缩放和平移
  • SVG 或 Canvas 矢量图，可即时裁剪和简化
  • 在高 DPI 屏幕上清晰可见
  • 分数级缩放级别
  • 与其容器一起调整大小
  • 使用纯 CSS 进行样式设计
  • 图像和 HTML 标记
  • 超出内置 EPSG:3857/4326/3395 的自定义投影
  • 用于平面图、游戏或图像的非地理地图
  • 地图、标记和控制项的键盘导航
  • 带有标签的控制项和替代文本
  • 适合屏幕阅读器的弹出框和工具提示
  • 可翻译的内置文本
