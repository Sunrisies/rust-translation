Leaflet是用于构建强大交互地图的领先开源JavaScript库。尽管它仅包含 40 KB of JS，但它具备大多数开发者所需的所有映射功能 features 。

Leaflet的设计考虑到了 simplicity, performance and usability 。它在所有主要的桌面和移动平台上都高效运行， 可以通过大量 plugins进行扩展，拥有美观、易用的 且文档完善的API 以及简单易读的源代码 ，令人愉悦。 它为数百万网站上的地图提供支持，每周有超过1000万次npm下载量。 contribute

在这里我们在`div`中创建地图，添加 我们选择的瓦片，然后在弹出窗口中添加带有文本的标记：

import {LeafletMap, TileLayer, Marker} from 'leaflet';

const map = new LeafletMap('map').setView([51.505, -0.159], 15);

new TileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
    attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>'
}).addTo(map);

new Marker([51.504, -0.159]).addTo(map)
    .bindPopup('A pretty CSS popup.<br>Easily customizable.')
    .openPopup();

Features

Leaflet不会试图为所有人做所有事情。相反，它专注于让核心功能表现良好 。 瓦片层和WMS.

Layers

  • 标记、弹出窗口和工具提示
  • 多线、多边形、圆形
  • 图像、视频和SVG覆盖层
  • GeoJSON
  • 具有惯性效果的平滑平移

Interaction

  • 使用滚轮、捏合、双击或Shift拖拽进行缩放
  • 支持鼠标、触摸和笔操作
  • 可拖动标记
  • 缩放、图层、比例、全屏和来源控制
  • GPU加速的缩放和平移

Rendering

  • SVG或Canvas向量，可即时裁剪和简化
  • 在高DPI屏幕上清晰显示
  • 分数级缩放级别
  • 与其容器一起调整大小
  • 使用纯JS类进行扩展

Customization

  • 每个地图和图层都有事件
  • 适用于所有现代浏览器
  • 除了内置EPSG:3857/4326/3395之外，还支持自定义投影
  • 用于平面图、游戏或图像的非地理地图

Accessibility

  • 地图、标记和控制器的键盘导航
  • 带有标签的控制和替代文本
  • 适合屏幕阅读器的弹出窗口和工具提示
  • 可翻译的内置文本

对于开发者

  • 可树剔除的ES模块
  • 包含TypeScript类型
  • 无需依赖
  • 可通过纯JS类进行扩展
  • 每个地图和图层都有事件
  • 适用于所有现代浏览器

如果您发现Leaflet缺少某些功能，首先检查是否有 相关插件 以及之前是否已有讨论 GitHub 问题报告. 如果没有，请打开一个新的 GitHub 问题报告。
