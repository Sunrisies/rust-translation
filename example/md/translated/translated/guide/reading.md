# 阅读书籍

本章介绍了如何与 mdBook 制作的书籍进行交互。  
假设您正在阅读的是 HTML 格式的书籍。  
对于其他输出格式，如 PDF，选项和格式会有所不同。

一本书被组织成多个*章节*。每个章节都是独立的页面。章节之间可以嵌套成子章节的层次结构。通常，每个章节会被组织成一系列*标题*来进一步细分章节内容。

## 导航

有几种方法可以浏览一本书的章节。

左侧的**侧边栏**列出了所有章节的列表。点击任何章节标题即可加载该页面。

如果窗口过于狭窄，尤其是在移动设备上，侧边栏可能不会自动出现。在这种情况下，可以点击页面左上角的菜单图标（三个水平条）来打开或关闭侧边栏。

页面底部的**箭头按钮**可以用来导航到上一章或下一章。

键盘上的**左右箭头键**可以用来导航到上一章或下一章。

## 顶部菜单栏

页面顶部的菜单栏提供了一些用于与书籍进行交互的图标。这些图标会根据书籍的生成设置而有所不同。

| 图标 | 描述 |
|------|-------------|
| <i class="fas fa-bars"></i> | 打开和关闭章节列表侧边栏。 |
| <i class="fas fa-paintbrush"></i> | 打开选择器，用于选择不同的颜色主题。 |
| <i class="fas fa-magnifying-glass"></i> | 打开搜索栏，用于在书中进行搜索。 |
| <i class="fas fa-print"></i> | 指示网络浏览器打印整本书。 |
| <i class="fab fa-github"></i> | 打开链接，访问包含书籍源代码的网站。 |
| <i class="fas fa-pencil"></i> | 打开页面，直接编辑当前阅读的页面的源代码。 |

点击菜单栏会将页面滚动到顶部。

## 搜索

每本书都内置了搜索系统。在菜单栏中点击搜索图标 <i class="fas fa-magnifying-glass"></i>，或者按下键盘上的 <kbd>/</kbd> 或 <kbd>S</kbd> 键，都会弹出一个输入框供用户输入搜索条件。输入一些关键词后，匹配到的章节和段落会实时显示出来。

点击任何结果都可以跳转到相应的部分。可以使用上下箭头键来浏览结果，而输入键则可以打开被高亮显示的部分。

在加载搜索结果后，匹配的搜索词会在文本中被高亮显示。点击被高亮的单词或按下 <kbd>Escape</kbd> 键可以取消高亮显示。

## 代码块

mdBook 常用于编程项目，因此支持高亮显示代码块和示例。代码块中可能包含多种图标，用于与之交互：

| 图标 | 描述 |
|------|-------------|
| <i class="fa fa-copy"></i> | 将代码块复制到本地剪贴板中，以便粘贴到其他应用程序中。 |
| <i class="fas fa-play"></i> | 对于 Rust 代码示例，这将执行示例代码，并在示例下方显示编译器输出（详见[游乐场]）。 |
| <i class="fa fa-eye"></i> | 对于 Rust 代码示例，这将切换“隐藏”行的显示状态。有时，较大的示例会隐藏那些与所演示内容无关的行（详见[隐藏代码行]）。 |
| <i class="fas fa-clock-rotate-left"></i> | 对于 [editable code examples][editor]，这将撤销您所做的任何更改。 |

以下是一个例子：

```rust
println!("Hello, World!");
```
