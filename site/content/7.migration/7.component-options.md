## `asyncData` 和 `fetch`

### 异类 Fetch

在 Nuxt 2 中，你可能会使用 `@nuxtjs/axios` 或 `@nuxt/http` 来获取数据，或者直接使用全局的 `fetch` 函数。

在 Nuxt 3 中，你可以使用全局可用的 `fetch` 方法，该方法的 API 与 [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) 或 [`$fetch`](/docs/api/utils/dollarfetch) 方法相同，后者使用 [unjs/ofetch](https://github.com/unjs/ofetch)。它具有许多优势，包括：

1. 它会“智能”处理在服务器上运行时进行 [直接 API 调用]，或在客户端上运行时进行客户端侧对 API 的调用。（它还可以处理调用第三方 API。）

2. 此外，它还包含便捷功能，如自动解析响应和字符串化数据。

你可以阅读更多关于直接 API 调用 [（/docs/guide/concepts/server-engine#direct-api-calls）] 或获取数据的信息 [（/docs/getting-started/data-fetching）]。

### 组合式函数

Nuxt 3 提供了新的组合式函数用于获取数据获取：[`useAsyncData`](/docs/api/组合式函数/use-async-data) 和 `useFetch`。它们都有“惰性”变体（`useLazyAsyncData` 和 `useLazyFetch`），不会阻塞客户端导航。

在 Nuxt 2 中，你会在组件中使用类似以下的语法来获取数据：

```ts
export default {
  async asyncData ({ params, $http }) {
    const post = await $http.$get(`https://api.nuxtjs.dev/posts/${params.id}`)
    return { post }
  },
  // or alternatively
  fetch () {
    this.post = await $http.$get(`https://api.nuxtjs.dev/posts/${params.id}`)
  },
}
```

在你的方法和模板中，你可以像使用组件提供的其他数据一样使用 `post` 变量。

在 Nuxt 3 中，你可以在 `setup()` 方法或 `<script setup>` 标签中使用组合式函数来进行数据获取：

```vue
<script setup lang="ts">
// Define params wherever, through `defineProps()`, `useRoute()`, etc.
const { data: post, refresh } = await useAsyncData('post', () => $fetch(`https://api.nuxtjs.dev/posts/${params.id}`))
// Or instead - useFetch is a convenience wrapper around useAsyncData when you're just performing a simple fetch
const { data: post, refresh } = await useFetch(`https://api.nuxtjs.dev/posts/${params.id}`)
</script>
```

你现在可以在 Nuxt 3 模板中使用 `post`，或者调用 `refresh` 来更新数据。

::note
尽管名称如此， [`useFetch`](/docs/api/组合式函数/use-fetch) 并不是 `fetch()` hook 的直接替代。相反，`[useAsyncData`](/docs/api/组合式函数/use-async-data) 替代了这两个钩子，并且更可定制；它不仅可以从端点获取数据。 [`useFetch`](/docs/api/组合式函数/use-fetch) 是 [`useAsyncData`](/docs/api/组合式函数/use-async-data) 的一个便捷包装器，用于从端点简单获取数据。
::

### 迁移

1. 在页面或组件中，将 `asyncData` 钩子替换为 [`useAsyncData`](/docs/api/组合式函数/use-async-data) 或 [`useFetch`](/docs/api/组合式函数/use-fetch)。
2. 在组件中，将 `fetch` 钩子替换为 [`useAsyncData`](/docs/api/组合式函数/use-async-data) 或 [`useFetch`](/docs/api/组合式函数/use-fetch)。

## `key`

现在你可以在 [`definePageMeta`](/docs/api/utils/define-page-meta) 编译宏中定义 `key`。

```diff [app/pages/index.vue]
- <script>
- export default {
-   key: 'index'
-   // or a method
-   // key: route => route.fullPath
- }
+ <script setup>
+ definePageMeta({
+   key: 'index'
+   // or a method
+   // key: route => route.fullPath
+ })
</script>
```

## `scrollToTop`

此功能在 Nuxt 3 中尚未支持。如果您希望覆盖 `vue-router` 的默认滚动行为，可以在 `~/router.options.ts` 中实现（更多详情请参见 [文档](/docs/guide/recipes/custom-routing#router-options)）。
与 `key` 类似，可在 [`definePageMeta`](/docs/api/utils/define-page-meta) 编译宏中指定它。

```diff [app/pages/index.vue]
- <script>
- export default {
-   scrollToTop: false
- }
+ <script setup>
+ definePageMeta({
+   scrollToTop: false
+ })
</script>
```

## `validate`

Nuxt 3 中的 `validate` 钩子仅接受一个参数，即 `route`。与 Nuxt 2 一样，您可以返回布尔值。如果您返回 `false` 且找不到其他匹配项，则会导致 404 错误。您也可以直接返回一个包含 `status`/`statusText` 的对象，以立即响应错误（此时不会检查其他匹配项）。

```diff [app/pages/users/[id\\].vue]
- <script>
- export default {
-   async validate({ params }) {
-     return /^\d+$/.test(params.id)
-   }
- }
+ <script setup>
+ definePageMeta({
+   validate: async (route) => {
+     const nuxtApp = useNuxtApp()
+     return /^\d+$/.test(route.params.id)
+   }
+ })
  </script>
```

## `watchQuery`

此功能在 Nuxt 3 中不支持。相反，您可以直接使用观察者来触发数据重新获取。

```vue [app/pages/users/[id\\].vue]
<script setup lang="ts">
const route = useRoute()
const { data, refresh } = await useFetch('/api/user')
watch(() => route.query, () => refresh())
</script>
```
