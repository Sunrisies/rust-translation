## 模块兼容性

Nuxt 3 使用 `@nuxt/kit` 自动包装器为 Nuxt 2 模块提供了基本的向后兼容层。但通常需要一些步骤才能使模块与 Nuxt 3 兼容，有时则需要使用 Nuxt Bridge 以实现跨版本兼容。

我们准备了 [专用指南](/docs/guide/modules)，用于使用 `@nuxt/kit` 编写适用于 Nuxt 3 的模块。目前最佳迁移方式就是遵循该指南并重写你的模块。如果希望避免完全重写，但仍要使模块与 Nuxt 3 兼容，本指南的其他部分则包含准备步骤。

::tip{icon="i-lucide-puzzle" to="/modules"}
探索与 Nuxt 3 兼容的模块。
::

### 插件兼容性

Nuxt 3 插件 **并不** 完全与 Nuxt 2 向后兼容。

:read-more{to="/docs/directory-structure/app/plugins"}

### Vue 兼容性

使用 Composition API 的插件或组件需要专门的 Vue 2 或 Vue 3 支持。

通过使用 [vue-demi](https://github.com/vueuse/vue-demi)，它们应与 Nuxt 2 和 3 兼容。

## 模块迁移

当 Nuxt 3 用户添加你的模块时，你将无法访问模块容器（`this.*`），因此你需要使用 `@nuxt/kit` 中的工具函数来访问容器功能。

### 使用 `@nuxt/bridge` 进行测试

迁移到 `@nuxt/bridge` 是支持 Nuxt 3 的第一步也是最重要的步骤。

如果你的模块中有 fixture 或示例，请将 `@nuxt/bridge` 包添加到其配置中（参见 [示例](/docs/bridge/overview#update-nuxtconfig)）。

### 从 CommonJS 迁移到 ESM

Nuxt 3 原生支持 TypeScript 和 ECMAScript 模块。请查看 [Native ES Modules](/docs/guide/concepts/esm) 以获取更多信息和升级指导。

### 确保插件默认导出

如果你注入的 Nuxt 插件没有 `export default` 声明（例如全局 Vue 插件），请确保在其末尾添加 `export default () => { }`。

::code-group

```js [Before]
// ~/plugins/vuelidate.js
import Vue from 'vue'
import Vuelidate from 'vuelidate'

Vue.use(Vuelidate)
```

```js [After]
// ~/plugins/vuelidate.js
import Vue from 'vue'
import Vuelidate from 'vuelidate'

Vue.use(Vuelidate)

export default () => { }
```

::

### 避免运行时模块

在 Nuxt 3 中，Nuxt 现在仅作为构建时依赖，这意味着模块不应尝试接入 Nuxt 运行时。

即使你的模块仅被添加到 [`buildModules`](/docs/api/nuxt-config#runtimeconfig-1)（而非 `modules`），它也应能正常工作。例如：

- 避免在 Nuxt 模块中更新 `process.env`，并让 Nuxt 插件读取；应使用 [`runtimeConfig`](/docs/api/nuxt-config#runtimeconfig-1)  instead.
- (*) 在生产环境中应避免依赖 `vue-renderer:*` 之类的运行时钩子。
- (*) 避免通过在模块内部导入 `serverMiddleware` 来添加它们。相反，应通过引用文件路径来添加这些中间件，使其独立于模块的上下文。

(*) 除非仅用于 `nuxt dev` 目的，并且用 `if (nuxt.options.dev) { }` 进行保护。

::tip
请继续阅读关于 Nuxt 3 模块的 [模块作者指南](/docs/guide/modules)。
::

### 使用 TypeScript（可选）

虽然并非必需，但大多数 Nuxt 生态系统正在转向使用 TypeScript，因此强烈建议考虑迁移。

::tip
您可以通过将 `.js` 文件重命名为 `.ts` 来开始迁移。TypeScript 设计为可逐步升级的！
::

::tip
您可以在不使用任何额外依赖的情况下，在 Nuxt 2 和 3 的模块和插件中使用 TypeScript 语法。
::
