---
title: 概述
description: Nuxt 3 是对 Nuxt 2 的完全重构，并基于一套新的底层技术。
---

将 Nuxt 2 应用迁移到 Nuxt 3 时会有显著变化，不过随着稳定版本的发布，迁移过程将变得更加简单。

::note
本迁移指南正在持续更新，以匹配 Nuxt 3 的发展进度。
::

这些显著变化包括：

1. 从 Vue 2 迁移到 Vue 3，包括默认使用组合式 API 和 script setup。
1. 从 webpack 4 和 Babel 迁移到 Vite 或 webpack 5 和 esbuild。
1. 从运行时 Nuxt 依赖迁移到使用 nitropack 编译的最小独立服务器。

::tip
如果您希望继续使用 Nuxt 2，但想在 Nuxt 2 中享受 Nuxt 3 的功能，可以查看 [如何开始使用 Bridge](/docs/bridge/overview)。
::
