---
title: Vite
description: 通过 Nuxt Bridge 为你的 Nuxt 2 应用激活 Vite。
---

::warning
使用 `vite` 时，必须已配置 [nitro](/docs/bridge/nitro)。
::

## 移除模块

- 移除 `nuxt-vite`：Bridge 会启用相同的功能。

## 更新配置

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    vite: true,
    nitro: true,
  },
})
```

## 配置

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  vite: {
    // Config for Vite
  },
})
```
