## 更新运行时配置

Nuxt 3 与 Nuxt 2 在运行时配置的实现方式不同，采用了新的组合式 `runtimeConfig` 选项。

首先，你需要将 `publicRuntimeConfig` 和 `privateRuntimeConfig` 属性合并为一个名为 `runtimeConfig` 的新属性，并将公共配置放在名为 `public` 的键中。

```diff
// nuxt.config.js
- privateRuntimeConfig: {
-   apiKey: process.env.NUXT_API_KEY || 'super-secret-key'
- },
- publicRuntimeConfig: {
-   websiteURL: 'https://public-data.com'
- }
+ runtimeConfig: {
+   apiKey: process.env.NUXT_API_KEY || 'super-secret-key',
+   public: {
+     websiteURL: 'https://public-data.com'
+   }
+ }
```

这意味着当需要访问公共运行时配置时，必须通过名为 `public` 的属性来访问。如果你使用公共运行时配置，就需要更新代码。

```diff
// MyWidget.vue
- <div>Website: {{ $config.websiteURL }}</div>
+ <div>Website: {{ $config.public.websiteURL }}</div>
```
