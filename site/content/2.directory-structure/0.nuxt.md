::important
请将该目录添加到你的 [`.gitignore`](/docs/directory-structure/gitignore) 文件中，以避免将开发构建输出推送到仓库中。
::

如果你希望了解 Nuxt 根据目录结构生成的文件详情，该目录非常有趣。

Nuxt 还提供了虚拟文件系统（VFS），使得模块可以在不将模板写入磁盘的情况下将其添加到此目录中。

你可以在开发模式下打开 [Nuxt DevTools](/modules/devtools)，并导航到 **Virtual Files** 标签页来探索生成的文件。

::warning
由于运行 [`nuxt dev`](/docs/api/commands/dev)时会重新创建整个目录，因此不应随意修改其中的任何文件。
::
