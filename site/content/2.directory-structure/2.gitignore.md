`.gitignore` 文件用于指定 git 应忽略的故意未跟踪的文件。

:read-more{icon="i-simple-icons-git" title="Git 文档" to="https://git-scm.com/docs/gitignore" target="_blank"}

我们建议拥有一个 `.gitignore` 文件，其中**至少**包含以下条目：

```bash [.gitignore]
# Nuxt dev/build outputs
.output
.data
.nuxt
.nitro
.cache
dist

# Node dependencies
node_modules

# Logs
logs
*.log

# Misc
.DS_Store

# Local env files
.env
.env.*
!.env.example
```
