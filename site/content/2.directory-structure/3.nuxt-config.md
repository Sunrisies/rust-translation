`nuxt.config` 文件扩展名可以是 `.js`、`.ts` 或 `.mjs`。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // My Nuxt config
})
```

::tip
`defineNuxtConfig` 辅助函数无需导入即可全局使用。
::

如果您愿意，也可以从 `nuxt/config` 中直接导入 `defineNuxtConfig`：

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // My Nuxt config
})
```

::read-more{to="/docs/api/nuxt-config"}
请在 **Nuxt 配置**文档中了解所有可用的选项。
::

为了确保您的配置保持最新，当检测到主配置文件、[`.env`](/docs/directory-structure/env)、[`.nuxtignore`](/docs/directory-structure/nuxtignore) 和 [`.nuxtrc`](/docs/directory-structure/nuxtrc) 点文件发生变化时，Nuxt 将执行完全重启。
