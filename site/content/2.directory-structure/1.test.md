`test/` 目录是进行应用程序测试的推荐位置。Nuxt 不会像扫描 `app/` 或 `server/` 那样进行扫描；你可以自行选择运行器和布局（通常使用 [`@nuxt/test-utils`](/docs/getting-started/testing)）。

常见的布局会区分不同环境：

```bash [Directory structure]
-| test/
---| e2e/
---| nuxt/
---| unit/
```

- `test/unit/` — 无需 Nuxt 运行时的快速 Node 测试
- `test/nuxt/` — 需要 Nuxt 运行时环境的测试
- `test/e2e/` — 针对正在运行的应用程序进行的端到端测试
