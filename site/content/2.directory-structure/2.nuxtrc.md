`.nuxtrc` 文件可以使用简洁的语法来配置 Nuxt，它基于 [`unjs/rc9`](https://github.com/unjs/rc9)。

::tip
对于更高级的配置，请使用 [`nuxt.config`](/docs/directory-structure/nuxt-config)。
::

## 使用方法

```bash [.nuxtrc]
# Disable SSR
ssr=false

# Configuration for `@nuxt/devtools`
devtools.enabled=true

# Add Nuxt modules
modules[]=@nuxt/image
modules[]=nuxt-security

# Module setups (automatically added by Nuxt)
setups.@nuxt/test-utils="3.23.0"
```

如果存在，`nuxt.config` 文件中的属性将覆盖 `.nuxtrc` 文件中的属性。

::note
Nuxt 会自动添加 `setups` 部分以跟踪模块安装和升级状态。此部分用于内部处理 [模块生命周期钩子](/docs/api/kit/modules#using-lifecycle-hooks-for-module-installation-and-upgrade)，不应手动修改。
::

::read-more{to="/docs/api/nuxt-config"}
在 **Nuxt 配置** 文档中可以探索所有可用的选项。
::

## 全局 `.nuxtrc` 文件

你也可以在首页目录中创建全局 `.nuxtrc` 文件，以在全局范围内应用配置。

- 在 macOS/Linux 上，该文件位于：

  ```md
  ~/.nuxtrc
  ```

- 在 Windows 上，该文件位于：

  ```md
  C:\Users\{username}\.nuxtrc
  ```

此全局 `.nuxtrc` 文件允许你定义适用于系统上所有 Nuxt 项目的默认设置。不过，项目级别的 `.nuxtrc` 文件将覆盖这些全局设置，`nuxt.config` 则优先于两者。
