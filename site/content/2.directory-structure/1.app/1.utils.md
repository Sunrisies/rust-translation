[`app/utils/` 目录](/docs/directory-structure/app/utils) 的主要作用在于让 Vue 组合式函数与其他自动导入的工具函数之间具有语义上的区分。

## 使用方法

**方法 1：** 使用命名导出

```ts twoslash [utils/index.ts]
export const { format: formatNumber } = Intl.NumberFormat('en-GB', {
  notation: 'compact',
  maximumFractionDigits: 1,
})
```

**方法 2：** 使用默认导出

```ts twoslash [utils/random-entry.ts or utils/randomEntry.ts]
// It will be available as randomEntry() (camelCase of file name without extension)
export default function (arr: Array<any>) {
  return arr[Math.floor(Math.random() * arr.length)]
}
```

现在你可以在 `.js`、`.ts` 和 `.vue` 文件中使用自动导入的工具函数。

```vue [app/app.vue]
<template>
  <p>{{ formatNumber(1234) }}</p>
</template>
```

::tip
`app/utils/` 的自动导入机制与 [`app/composables/`](/docs/directory-structure/app/组合式函数) 目录中的机制相同。
::

::important
这些工具函数仅在你的应用 Vue 部分可用。 :br
只有 `server/utils` 在 [`server/`](/docs/directory-structure/server#server-utilities) 目录中被自动导入。
::

::tip
类型也可以以相同的方式被自动导入。将仅适用于应用的类型放在 `app/types/`，将仅适用于服务器的类型放在 [`server/types/`](/docs/directory-structure/server#server-types)，将同时适用于两者类型的类型放在 [`shared/types/`](/docs/directory-structure/shared) 中。
::
