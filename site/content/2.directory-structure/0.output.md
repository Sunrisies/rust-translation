title: .output
description: 在为生产环境构建你的应用程序时，Nuxt 会创建 .output/ 目录。
head.title: ".output/"
navigation.icon: i-vscode-icons-folder-type-package
---

::important
请将该目录添加到你的 [`.gitignore`](/docs/directory-structure/gitignore) 文件中，以避免将构建输出推送到仓库中。
::

使用此目录将你的 Nuxt 应用程序部署到生产环境。

:read-more{to="/docs/getting-started/deployment"}

::warning
由于在运行 [`nuxt build`](/docs/api/commands/build) 时整个目录会被重新创建，因此不应修改其中的任何文件。
::
