# E1001

当组合式函数需要在插件、Nuxt 钩子、路由中间件或 Vue `setup()` 之外运行，并且需要依赖 Nuxt 实例（`useNuxtApp()`、`useRoute()`、`useFetch()` 等）时，就会出现这种情况。最常见的触发方式是在一个异步回调中调用它（如 `setTimeout`、`.then()` 或 `await` 之后的操作），此时上下文已经丢失。

## 解决方案

可以在 `setup()`、插件或中间件的开头同步调用该组合式函数，并在之后复用捕获到的结果。对于服务器端异步操作，可以使用 `nuxtApp.runWithContext()` 包裹调用以保留上下文。
