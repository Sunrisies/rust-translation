# E3001

传递给 `useFetch()` 的 URL 以 `//` 开头。此类协议相对 URL 会解析为外部主机，这几乎不是预期的情况，因此会被拒绝，以避免将请求泄露到不同的源。

## 解决方案

使用带有明确协议的绝对 URL，或相对路径：

```ts
useFetch('/api/data')
useFetch('https://api.example.com/data')
```
