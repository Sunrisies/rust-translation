# E2005

在路由中间件内部（直接调用或通过其他组合式函数调用）调用了 `useRoute()`。此时目标路由尚未解析，因此 `useRoute()` 可能返回意外值；中间件则接收 `to` 和 `from` 路由作为参数。

## 解析

```ts
export default defineNuxtRouteMiddleware((to, from) => {
  // use `to` / `from` instead of useRoute()
})
```
