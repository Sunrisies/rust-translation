# B5003

你在 `runtimeConfig.app` 下使用了自定义键，该命名空间由 Nuxt 保留用于内部值（如 `baseURL` 和 `cdnURL`）。这里的自定义键可能会与 Nuxt 自身的配置产生冲突。

## 解决方案

将自定义键移动到 `runtimeConfig.public`（供客户端访问）或顶级自定义命名空间中（仅服务器可访问）：

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    // instead of runtimeConfig.app.myKey
    public: {
      myKey: 'value',
    },
  },
})
```
