# E6001

当没有活跃的 Unhead 实例时，调用了如 `useHead()` 这样的 head 组合式函数。这种情况发生在它在有效的 Nuxt 上下文之外运行时，例如在 Nuxt 实例不再可用后的分离异步回调中。

## 解决方案

在组件 `setup()`、Nuxt 插件或路由中间件中同步调用 head 组合式函数。如果需要在 `await` 之后使用它们，请先捕获 Nuxt 上下文：

```ts
const nuxtApp = useNuxtApp()
await someAsyncWork()
nuxtApp.runWithContext(() => useHead({ title: 'Late title' }))
```
