# E3009

调用 `useAsyncData()` 时未提供处理器函数。处理器是执行获取操作并返回数据的函数，因此不能省略或采用其他类型。

## 解决方案

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
