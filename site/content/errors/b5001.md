# B5001

您的 Nuxt 配置中未设置 `compatibilityDate`。Nuxt 使用此日期来决定默认应用何种行为，这样您的项目在 Nuxt 和 Nitro 更新中都能保持稳定，而不会默默接受新的默认设置。

## 解决方案

在 `nuxt.config` 中添加 `compatibilityDate`，使用当前日期，以便启用当前默认设置：

```ts
export default defineNuxtConfig({
  // use the current date, e.g. the day you add this line
  compatibilityDate: 'YYYY-MM-DD',
})
```
