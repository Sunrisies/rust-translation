## LLMs.txt 是什么？.txt

LLMs.txt 是一种专为大型语言模型（LLM）设计的结构化文档格式。Nuxt 提供包含关于框架的全面信息的 LLMs.txt 文件，使 AI 工具能够轻松理解并协助 Nuxt 开发。

这些文件针对 AI 使用进行了优化，包含关于概念、API、使用模式和最佳实践的结构化信息。

## 可用的路由

我们提供 LLMs.txt 路由，以帮助 AI 工具访问我们的文档：

- **`/llms.txt`** - 包含所有文档页面的结构化概览及其链接（约 5K 个词元）
- **`/llms-full.txt`** - 提供全面的文档，包括入门指南、API 参考、博客文章和部署指南（约 100 万+ 个词元）

## 选择合适的文件

::note{icon="i-lucide-info"}
**大多数用户应从 `/llms.txt` 开始** - 它包含所有必要信息，并适用于标准的 LLM 上下文窗口。

仅当您需要全面的实现细节且您的 AI 工具支持大上下文（200K+ 个词元）时，才使用 `/llms-full.txt`。
::

## 重要的使用说明

::warning{icon="i-lucide-alert-triangle"}
**@-符号必须手动输入** - 当使用如 Cursor 或 Windsurf 等工具时，@ 符号必须在聊天界面中手动输入。复制粘贴会破坏工具将其识别为上下文引用的能力。
::

## 与 AI 工具的配合使用

### Cursor

Nuxt 提供专门的 LLMs.txt 文件，您可以在 Cursor 中引用这些文件，以获得更好的 Nuxt 开发 AI 辅助。

#### 使用方法

1. **直接引用**：提问时提及 LLMs.txt 的 URL
2. 使用 `@docs` 将这些特定 URL 添加到您的项目上下文中

[阅读更多关于 Cursor Web 和 Docs 搜索的信息](https://cursor.com/docs/context/mentions)

### Windsurf

Windsurf 可以直接访问 Nuxt LLMs.txt 文件，以理解框架用法和最佳实践。

#### 使用 LLMs.txt 与 Windsurf

- 使用 `@docs` 引用特定的 LLMs.txt URL
- 在您的工作区中创建持久规则来引用这些 URL

[阅读更多关于 Windsurf Web 和 Docs 搜索的信息](https://docs.windsurf.com/windsurf/cascade/web-search)

### 其他 AI 工具

任何支持 LLM 的 AI 工具都可以使用这些路径来更好地理解 Nuxt。

#### ChatGPT、Claude 或其他 LLM 的示例

- “使用来自 https://nuxt.com/llms.txt 的 Nuxt 文档”
- “遵循来自 https://nuxt.com/llms-full.txt 的完整 Nuxt 指南”
