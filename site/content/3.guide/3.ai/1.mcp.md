## MCP 是什么？

MCP (Model Context Protocol) 是一种标准化协议，使 AI 助手能够访问外部数据来源和工具。Nuxt 提供了 MCP 服务器，允许 Claude Code、Cursor 和 Windsurf 等 AI 助手直接访问文档、博客文章和部署指南。

MCP 服务器提供对 Nuxt 文档的结构化访问，使得 AI 工具能够轻松理解并协助 Nuxt 开发。

## 资源

Nuxt MCP 服务器提供以下资源供用户探索：

- **`resource://nuxt-com/documentation-pages`**：浏览所有可用的文档页面（默认版本为 v4.x）
- **`resource://nuxt-com/blog-posts`**：浏览所有 Nuxt 博客文章，包括发布信息和教程
- **`resource://nuxt-com/deploy-providers`**：浏览所有部署提供者和托管平台

您可以使用 `@` 与 Claude Code 等工具访问这些资源。

## 工具

Nuxt MCP 服务器按类别提供了以下工具：

### 文档

- **`list-documentation-pages`**：列出所有可用的 Nuxt 文档页面及其类别和基本信息。支持版本筛选（3.x、4.x、5.x 或全部）
- **`get-documentation-page`**：按路径获取文档页面内容和详细信息
- **`get-getting-started-guide`**：获取特定 Nuxt 版本的入门指南

### 博客

- **`list-blog-posts`**：列出所有 Nuxt 博客文章及其元数据，包括日期、类别和标签
- **`get-blog-post`**：按路径获取博客文章内容和详细信息

### 部署

- **`list-deploy-providers`**：列出 Nuxt 应用程序的所有部署提供者和托管平台
- **`get-deploy-provider`**：按路径获取部署提供者的详细信息和说明

### 模块

- **`list-modules`**：列出所有可用的 Nuxt 模块，支持按下载量、点赞数或日期进行筛选和排序
- **`get-module`**：获取特定模块的完整信息，包括 README、兼容性说明、维护者及统计数据

### 变更日志

- **`get-changelog`**：获取 Nuxt 核心和官方模块的最新发布信息

## 限制可用工具

将可选的 `X-MCP-Tools` HTTP 头设置为工具名称的逗号分隔列表，以便仅暴露助手所需的工具。这减少了发送给助手的工具上下文。

使用服务器返回的精确的 kebab-case MCP 工具名称，例如：

```json
{
  "X-MCP-Tools": "list-documentation-pages,get-documentation-page"
}
```

没有头信息会暴露所有工具，空头信息不会暴露任何工具，而未知的工具名称则会返回配置错误。

## 提示词

Nuxt MCP 服务器为常见工作流提供引导式提示词：

- **`find-documentation-for-topic`**：查找特定主题或功能的最佳 Nuxt 文档
- **`deployment-guide`**：获取特定托管提供商的部署说明
- **`migration-help`**：获取关于在 Nuxt 版本间迁移的帮助

您可以使用 Claude Code 等工具通过 `/` 访问这些资源。

## 设置

Nuxt MCP 服务器使用 HTTP 传输，可以安装在不同的 AI 助手中。

### ChatGPT

::note{icon="i-lucide-info"}
**对于 Pro 和 Plus 账户，ChatGPT 上提供使用 MCP 的自定义连接器**。
::

按照以下步骤在 ChatGPT 中设置 Nuxt 作为连接器：

1. **启用开发者模式：**
   - 前往 Settings → Connectors → Advanced settings → Developer mode

2. **打开 ChatGPT 设置**

3. **在 Connectors 标签页中，创建新连接器：**
   - 给它起个名字：`Nuxt`
   - MCP 服务器 URL：`https://nuxt.com/mcp`
   - 认证：`None`

4. **点击创建**

在对话后期中，Nuxt 连接器将出现在组合式函数的“开发者模式”工具中。

### Claude Code

::note{icon="i-lucide-info"}
**确保已安装 Claude Code** - 访问 [Anthropic 文档](https://code.claude.com/docs/en/quickstart) 获取安装说明。
::

使用 CLI 命令添加服务器：

```bash
claude mcp add --transport http nuxt https://nuxt.com/mcp
```

### Claude Desktop

#### 设置说明

1. 打开 Claude Desktop，导航到“Settings” > “Developer”。
2. 点击“Edit Config”。这将打开本地 Claude 目录。
3. 使用您的自定义 MCP 服务器配置修改 `claude_desktop_config.json` 文件。
    ```json [claude_desktop_config.json]
    {
      "mcpServers": {
        "nuxt": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://nuxt.com/mcp"
          ]
        }
      }
    }
    ```
4. 重启 Claude Desktop 应用。此时 Nuxt MCP 服务器应已注册。

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "nuxt": {
      "type": "http",

```

### Gemini CLI

1. 找到您的 Gemini CLI 配置文件（通常位于 `~/.gemini/settings.json`，或根据环境设置而定）。
2. 在 `mcpServers` 对象中添加以下配置：

```json [~/.gemini/settings.json]
{
  "mcpServers": {
    "nuxt": {
      "httpUrl": "https://nuxt.com/mcp"
    }
  }
}
```

1. 重启终端会话或重新加载 CLI。此时 Nuxt MCP 服务器工具即可使用。

### Le Chat Mistral

1. 导航到“Intelligence” > “Connectors”
2. 点击“Add Connector”按钮，然后选择“Custom MCP Connector”
3. 创建您的自定义 MCP 连接器：
    - 连接器名称：`Nuxt`
    - 服务器 URL：`https://nuxt.com/mcp`

### Visual Studio Code

::note{icon="i-lucide-info"}
**安装必要的扩展** - 确保已安装 [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) 和 [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) 扩展。
::

1. 打开 VS Code 并访问命令面板（Ctrl/Cmd + Shift + P）
2. 输入“Preferences: Open Workspace Settings (JSON)”并选择它
3. 导航到项目的 `.vscode` 文件夹，如果不存在则创建该文件夹
4. 使用以下配置创建或编辑 `mcp.json` 文件：

```json [.vscode/mcp.json]
{
  "servers": {
    "nuxt": {
      "type": "http",
      "url": "https://nuxt.com/mcp"
    }
  }
}
```

### GitHub Copilot Agent

::note{icon="i-lucide-info"}
**需要仓库管理员权限**才能为 GitHub Copilot 编码代理配置 MCP 服务器。
::

如果您已在 VS Code 中配置了 MCP 服务器（将 `servers` 键替换为 `mcpServers` 用于 GitHub Copilot Agent），您可以为 GitHub Copilot 编码代理采用类似的配置。您需要添加 `tools` 键来指定哪些工具对 Copilot 可用。

1. 导航到您的 GitHub 仓库
2. 进入 **Settings** > **Code & automation** > **Copilot** > **Coding agent**
3. 在 **MCP configuration** 部分添加以下配置：
    ```json
    {
      "mcpServers": {
        "nuxt": {
          "type": "http",
          "url": "https://nuxt.com/mcp",
          "tools": ["*"]
        }
      }
    }
    ```
4. 点击 **Save**

#### 验证配置

要确认 MCP 服务器配置正确：

1. 在仓库中创建问题并分配给 Copilot
2. 等待 Copilot 创建拉取请求
3. 在拉取请求中，在“Copilot started work”时间线事件中点击 **View session**
4. 点击右上角的省略号按钮 (**...**)，然后点击侧边栏中的 **Copilot**
5. 展开 **Start MCP Servers** 步骤以查看已配置的 Nuxt 工具

关于如何使用 GitHub Copilot 编码代理与 MCP 的更多信息，请参阅 [通过 MCP 扩展编码代理](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp)。

### GitHub Copilot CLI

1. 以交互模式启动 GitHub Copilot CLI。
2. 运行 `/mcp add`。
3. 填写以下配置表单：
   - **Server Name**: `nuxt`
   - **Server Type**: `HTTP`
   - **URL**: `https://nuxt.com/mcp`
   - **HTTP Headers**: 留空
   - **Tools**: `*`
4. 按下 <kbd>Ctrl</kbd>+<kbd>S</kbd> 保存。无需重启 CLI，MCP 服务器即可立即使用。

或者直接将服务器添加到 `~/.copilot/mcp-config.json` 中：

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "nuxt": {
      "type": "http",
      "url": "https://nuxt.com/mcp",
      "tools": ["*"]
    }
  }
}
```

使用 `/mcp show` 确认服务器已配置且可用。

更多详情，请参阅 [为 GitHub Copilot CLI 添加 MCP 服务器](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)。

### Google Antigravity

1. 通过编辑器代理面板顶部的 "..." 下拉菜单打开 MCP 商店。
2. 点击 “Manage MCP Servers”
3. 点击 “View raw config”
4. 使用以下自定义 MCP 服务器配置修改 `mcp_config.json`：

```json [mcp_config.json]
{
  "mcpServers": {
    "nuxt": {
      "serverUrl": "https://nuxt.com/mcp"
    }
  }
}
```

1. 返回 “Manage MCP Servers” 标签页并点击 “Refresh”。此时 Nuxt MCP 服务器应出现。

### Windsurf

1. 打开 Windsurf 并导航至 “Settings” > “Windsurf Settings” > “Cascade”
2. 点击 “Manage MCPs” 按钮，然后选择 “View raw config” 选项
3. 在您的 MCP 设置中添加以下配置：

```json [.codeium/windsurf/mcp_config.json]
{
  "mcpServers": {
    "nuxt": {
      "serverUrl": "https://nuxt.com/mcp"
    }
  }
}
```

### Zed

1. 打开 Zed 并前往 “Settings” > “Open Settings”
2. 导航到 JSON 设置文件
3. 在您的设置中添加以下上下文服务器配置：

```json [.config/zed/settings.json]
{
  "context_servers": {
    "nuxt": {
      "url": "https://nuxt.com/mcp"
    }
  }
}
```

### Opencode

1. 在项目根目录中创建 `opencode.json`
2. 添加以下配置：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "nuxt": {
      "type": "remote",
      "url": "https://nuxt.com/mcp",
      "enabled": true
    }
  }
}
```

## 提示示例

配置完成后，您可以像这样向 AI 助手提问：

- “列出所有可用的 Nuxt 文档页面”
- “获取介绍性文档”
- “v3 和 v4 之间有什么区别？”
- “如何部署到 Vercel？”
- “显示最新的博客文章”
- “帮助我从 Nuxt 3 迁移到 Nuxt 4”
- “搜索关于组合式函数的文档”
- “查找 Cloudflare 的部署指南”

AI 助手将使用 MCP 服务器获取结构化的 JSON 数据，并为 Nuxt 开发提供指导性帮助。
