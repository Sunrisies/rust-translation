---
title: 夜间发布通道
description: 夜间发布通道允许使用从仓库最新提交直接构建出的 Nuxt 版本。
---

Nuxt 每天都会合并提交、改进项和错误修复。你可以选择在下次发布前提前测试这些变更。

当某个提交被合并到 [nuxt/nuxt](https://github.com/nuxt/nuxt) 的 `main` 分支并**通过所有测试**后，我们将通过 GitHub Actions 触发自动的 npm 发布。

你可以使用这些“夜间”版本进行新功能和变更的测试版测试。

这些“夜间”版本的构建和发布方式及质量与稳定版本相同。唯一的区别是你需要经常查看 GitHub 仓库以获取更新。在审查过程和自动测试过程中，有可能出现未被发现的回归问题。因此，我们在内部使用此通道在每次发布前进行双重检查。

::note
仅在夜间发布通道中可用的功能会在文档中标记为警告。
::

::warning
当前的 `latest` 夜间发布通道正在跟踪 Nuxt v4 分支，这意味着现在特别容易出现破坏性变更——请小心！你可以通过设置 `"nuxt": "npm:nuxt-nightly@3x"` 来启用 3.x 分支的夜间发布。
::

## 启用功能

在 `package.json` 中更新 `nuxt` 依赖项：

```diff [package.json]
{
  "dependencies": {
--    "nuxt": "^4.0.0"
++    "nuxt": "npm:nuxt-nightly@latest"
  }
}
```

删除锁定文件（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`、`bun.lock` 或 `bun.lockb`）并重新安装依赖项。

## 禁用功能

在 `package.json` 中更新 `nuxt` 依赖项：

```diff [package.json]
{
  "dependencies": {
--    "nuxt": "npm:nuxt-nightly@latest"
++    "nuxt": "^4.0.0"
  }
}
```

删除锁定文件（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`、`bun.lock` 或 `bun.lockb`）并重新安装依赖项。

## 使用夜间版 `@nuxt/cli`

要尝试最新版本的 [nuxt/cli](https://github.com/nuxt/cli)：

```bash [Terminal]
npx @nuxt/cli-nightly@latest [command]
```

::read-more{to="/docs/api/commands"}
了解更多关于可用命令的信息。
::
