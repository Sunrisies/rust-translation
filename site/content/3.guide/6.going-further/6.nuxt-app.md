## Nuxt 上下文

许多内置和用户创建的组合式函数与工具可能需要访问 Nuxt 实例。由于每次请求都会创建新的实例，因此这种上下文并非在应用程序的所有地方都存在。

目前，Nuxt 上下文仅在 [插件](/docs/directory-structure/app/plugins)、[Nuxt hooks](/docs/guide/going-further/hooks)、[Nuxt 中间件](/docs/directory-structure/app/中间件)（如果包裹在 `defineNuxtRouteMiddleware` 中）以及 [setup functions](https://vuejs.org/api/composition-api-setup)（在页面和组件中）中可访问。

如果调用组合式函数没有访问上下文，可能会收到错误提示：“一个需要访问 Nuxt 实例的组合式函数在插件、Nuxt hook、Nuxt 中间件 或 Vue setup function 之外被调用。”在这种情况下，你也可以使用 [`nuxtApp.runWithContext`](/docs/api/组合式函数/use-nuxt-app#runwithcontext) 显式地在该上下文中调用函数。

## 访问 NuxtApp

在组合式函数、插件和组件中，你可以使用 [`useNuxtApp()`](/docs/api/组合式函数/use-nuxt-app) 来访问 `nuxtApp`：

```ts [app/composables/useMyComposable.ts]
export function useMyComposable () {
  const nuxtApp = useNuxtApp()
  // access runtime nuxt app instance
}
```

如果你的组合式函数不总是需要 `nuxtApp`，或者你只是想检查它是否存在，由于 [`useNuxtApp`](/docs/api/组合式函数/use-nuxt-app) 会抛出异常，你可以改用 [`tryUseNuxtApp`](/docs/api/组合式函数/use-nuxt-app#tryusenuxtapp)。

为了方便，插件也会将 `nuxtApp` 作为第一个参数传递。

:read-more{to="/docs/directory-structure/app/plugins"}

## 提供辅助函数

你可以提供辅助函数，使其在所有组合式函数和应用程序中可用。这通常发生在 Nuxt 插件中。

```ts
const nuxtApp = useNuxtApp()
nuxtApp.provide('hello', name => `Hello ${name}!`)

console.log(nuxtApp.$hello('name')) // Prints "Hello name!"
```

::read-more{to="/docs/directory-structure/app/plugins#providing-helpers"}
在插件中返回包含 `provide` 键的对象，就可以注入辅助函数。
::

::read-more{to="https://nuxt.com/docs/2.x/directory-structure/plugins#inject-in-root-context" target="_blank"}
在 Nuxt 2 插件中，这被称为 **注入函数**。
::
