Nuxt Kit 提供了组合式函数工具，使得与 [Nuxt Hooks](/docs/api/advanced/hooks)、[Nuxt Interface](/docs/guide/going-further/internals#the-nuxt-interface) 以及开发 [Nuxt modules](/docs/guide/modules) 的交互变得非常简单。

::read-more{to="/docs/api/kit"}
探索所有 Nuxt Kit 工具。
::

## 使用方式

### 安装依赖项

您可以通过将 Nuxt Kit 添加到 `package.json` 的 `dependencies` 部分来安装最新版本。不过，即使 Nuxt 已自动安装，也请始终明确安装 `@nuxt/kit` 包。

::note
`@nuxt/kit` 和 `@nuxt/schema` 是 Nuxt 的关键依赖项。如果您单独安装它们，请确保 `@nuxt/kit` 和 `@nuxt/schema` 的版本与您的 `nuxt` 版本相等或更高，以避免意外行为。
::

```json [package.json]
{
  "dependencies": {
    "@nuxt/kit": "npm:@nuxt/kit-nightly@latest"
  }
}
```

### 导入 Kit 工具

```ts [test.mjs]
import { useNuxt } from '@nuxt/kit'
```

:read-more{to="/docs/api/kit"}

::note
Nuxt Kit 工具仅适用于模块，不用于运行时导入（如组件、Vue 组合式函数、页面、插件或服务器路由）。
::

Nuxt Kit 是一个 [仅支持 ESM 的包](/docs/guide/concepts/esm)，这意味着您**不能**使用 `require('@nuxt/kit')`。作为替代方案，请在 CommonJS 环境中使用动态导入：

```ts [test.cjs]
// This does NOT work!
// const kit = require('@nuxt/kit')
async function main () {
  const kit = await import('@nuxt/kit')
}
main()
```
