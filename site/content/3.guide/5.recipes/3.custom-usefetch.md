在使用 Nuxt 时，你可能需要开发前端并获取外部 API，并且可能希望为从 API 获取数据设置一些默认选项。

[`$fetch`](/docs/api/utils/dollarfetch) 实用函数（由 [`useFetch`](/docs/api/组合式函数/use-fetch) 组合式函数使用）并非全局可配置。这是出于以下原因：确保整个应用程序的获取行为保持一致，同时其他集成（如模块）可以依赖像 `$fetch` 这样的核心工具的行为。

然而，Nuxt 提供了一种方法来为你的 API 创建自定义 fetcher（如果你有多个 API 需要调用，也可以创建多个 fetcher）。

## 示例：带认证的 API 客户端

假设你有一个位于 `https://api.nuxt.com` 的外部 API，该 API 需要通过 [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils) 进行 JWT 认证，并且在 `401` 响应时希望重定向到 `/login`。

```ts [app/composables/useAPI.ts]
export const useAPI = createUseFetch({
  baseURL: 'https://api.nuxt.com',
  onRequest ({ options }) {
    const { session } = useUserSession()
    if (session.value?.token) {
      options.headers.set('Authorization', `Bearer ${session.value.token}`)
    }
  },
  async onResponseError ({ response }) {
    if (response.status === 401) {
      await navigateTo('/login')
    }
  },
})
```

现在，每次调用 `useAPI` 都会自动包含认证头并处理 401 重定向：

```vue [app/pages/dashboard.vue]
<script setup lang="ts">
const { data: profile } = await useAPI('/me')
const { data: orders } = await useAPI('/orders')
</script>
```

## 示例：自定义 `$fetch` 实例

如果你需要更低级别的控制，可以通过 [Nuxt 插件](/docs/directory-structure/app/plugins) 创建自定义 `$fetch` 实例，然后直接将其与 `useAsyncData` 一起使用，或将其传递给 `createUseFetch`。

::note
`$fetch` 是 [ofetch](https://github.com/unjs/ofetch) 的配置实例，它支持添加你的 Nuxt 服务器的基础 URL，并在 SSR 期间进行直接函数调用（避免 HTTP 往返传输）。
::

```ts [app/plugins/api.ts]
export default defineNuxtPlugin((nuxtApp) => {
  const { session } = useUserSession()

  const api = $fetch.create({
    baseURL: 'https://api.nuxt.com',
    onRequest ({ request, options, error }) {
      if (session.value?.token) {
        options.headers.set('Authorization', `Bearer ${session.value?.token}`)
      }
    },
    async onResponseError ({ response }) {
      if (response.status === 401) {
        await nuxtApp.runWithContext(() => navigateTo('/login'))
      }
    },
  })

  return {
    provide: {
      api,
    },
  }
})
```

然后你可以直接使用这个自定义 `$fetch` 实例：

```vue [app/app.vue]
<script setup>
const { $api } = useNuxtApp()
const { data: modules } = await useAsyncData('modules', () => $api('/modules'))
</script>
```

::callout
使用 [`useAsyncData`](/docs/api/组合式函数/use-async-data) 包裹可以**避免在服务器端渲染时重复获取数据**（在 hydration 时服务器和客户端都会获取数据）。
::
