Nuxt 提供 [`useState`](/docs/api/组合式函数/use-state) 组合式函数，用于在组件间创建响应式且适合 SSR 的共享状态。

`[ useState`](/docs/api/组合式函数/use-state) 是一个适合 SSR 的 [`ref`](https://vuejs.org/api/reactivity-core#ref) 替代方案。其值将在服务器端渲染（客户端水合期间）后保留，并通过唯一键在所有组件间共享。

:video-accordion{title="亚历山大·利希特视频：何时使用 useState" videoId="mv0WcBABcIk"}

::important
由于 `[ useState`](/docs/api/组合式函数/use-state) 中的数据会被序列化为 JSON，因此必须确保其中不包含无法序列化的内容，如类、函数或符号。
::

::read-more{to="/docs/api/composables/use-state"}
了解更多关于 `useState` 组合式函数的信息。
::

## 最佳实践

::warning
永远不要在 `<script setup>` 或 `setup()` 函数之外定义 `const state = ref()`。
例如，使用 `export myState = ref({})` 会导致状态在服务器上的多个请求间共享，可能导致内存泄漏。
::

::tip{icon="i-lucide-circle-check"}
应改为使用 `const useX = () => useState('x')`
::

## 示例

### 基本用法

在这个示例中，我们使用组件本地计数器状态。任何使用 `useState('counter')` 的其他组件都会共享相同的响应式状态。

```vue twoslash [app/app.vue]
<script setup lang="ts">
const counter = useState('counter', () => Math.round(Math.random() * 1000))
</script>

<template>
  <div>
    Counter: {{ counter }}
    <button @click="counter++">
      +
    </button>
    <button @click="counter--">
      -
    </button>
  </div>
</template>
```

:link-example{to="/docs/examples/features/state-management"}

::note
要全局使缓存状态失效，请参阅 [`clearNuxtState`](/docs/api/utils/clear-nuxt-state) 工具。
::

### 初始化状态

大多数情况下，您希望使用异步解析的数据来初始化状态。可以使用 `[ app.vue`](/docs/directory-structure/app/app) 组件和 `[ callOnce`](/docs/api/utils/call-once) 工具来实现这一点。

```vue twoslash [app/app.vue]
<script setup lang="ts">
const websiteConfig = useState('config')

await callOnce(async () => {
  websiteConfig.value = await $fetch('https://my-cms.com/api/website-config')
})
</script>
```

::tip
这类似于 Nuxt 2 中的 [`nuxtServerInit` 动作](https://nuxt.com/docs/2.x/directory-structure/store#the-nuxtserverinit-action)，该动作允许在页面渲染前在服务器端填充存储的初始状态。
::

:read-more{to="/docs/api/utils/call-once"}

### 与 Pinia 的使用

在这个示例中，我们利用 [Pinia 模块](/modules/pinia) 创建全局存储并在整个应用中使用它。

::important
确保使用 `npx nuxt module add pinia` 安装 Pinia 模块，或遵循 [模块安装步骤](https://pinia.vuejs.org/ssr/nuxt.html#Installation)。
::

::code-group
```ts [app/stores/website.ts]
export const useWebsiteStore = defineStore('websiteStore', {
  state: () => ({
    name: '',
    description: '',
  }),
  actions: {
    async fetch () {
      const infos = await $fetch('https://api.nuxt.com/modules/pinia')

      this.name = infos.name
      this.description = infos.description
    },
  },
})
```
```vue [app/app.vue]
<script setup lang="ts">
const website = useWebsiteStore()

await callOnce(website.fetch)
</script>

<template>
  <main>
    <h1>{{ website.name }}</h1>
    <p>{{ website.description }}</p>
  </main>
</template>
```
::

## 高级用法

::code-group
```ts [app/composables/locale.ts]
import type { Ref } from 'vue'

export const useLocale = () => {
  return useState<string>('locale', () => useDefaultLocale().value)
}

export const useDefaultLocale = (fallback = 'en-US') => {
  const locale = ref(fallback)
  if (import.meta.server) {
    const reqLocale = useRequestHeaders()['accept-language']?.split(',')[0]
    if (reqLocale) {
      locale.value = reqLocale
    }
  } else if (import.meta.client) {
    const navLang = navigator.language
    if (navLang) {
      locale.value = navLang
    }
  }
  return locale
}

export const useLocales = () => {
  const locale = useLocale()
  const locales = ref([
    'en-US',
    'en-GB',
    // ...,
    'ja-JP-u-ca-japanese',
  ])
  if (!locales.value.includes(locale.value)) {
    locales.value.unshift(locale.value)
  }
  return locales
}

export const useLocaleDate = (date: Ref<Date> | Date, locale = useLocale()) => {
  return computed(() => new Intl.DateTimeFormat(locale.value, { dateStyle: 'full' }).format(unref(date)))
}
```

```vue [app/app.vue]
<script setup lang="ts">
const locales = useLocales()
const locale = useLocale()
const date = useLocaleDate(new Date('2016-10-26'))
</script>

<template>
  <div>
    <h1>Nuxt birthday</h1>
    <p>{{ date }}</p>
    <label for="locale-chooser">Preview a different locale</label>
    <select
      id="locale-chooser"
      v-model="locale"
    >
      <option
        v-for="loc of locales"
        :key="loc"
        :value="loc"
      >
        {{ loc }}
      </option>
    </select>
  </div>
</template>
```
::

## 共享状态

通过使用 [自动导入的组合式函数](/docs/directory-structure/app/组合式函数)，我们可以定义全局类型安全的状态并在整个应用中进行导入。

```ts twoslash [composables/states.ts]
export const useColor = () => useState<string>('color', () => 'pink')
```

```vue [app/app.vue]
<script setup lang="ts">
// ---cut-start---
const useColor = () => useState<string>('color', () => 'pink')
// ---cut-end---
const color = useColor() // Same as useState('color')
</script>

<template>
  <p>Current color: {{ color }}</p>
</template>
```

## 使用第三方库

Nuxt **过去**依赖 Vuex 库来提供全局状态管理。如果您正在从 Nuxt 2 迁移，请前往 [迁移指南](/docs/migration/configuration#vuex)。

Nuxt 对状态管理没有特定要求，因此您可以自由选择适合您需求的解决方案。它支持与最流行的状态管理库进行多种集成，包括：

- [Pinia](/modules/pinia) - Vue 官方推荐方案
- [Harlem](/modules/harlem) - 不可变全局状态管理
- [XState](/modules/xstate) - 状态机方法，提供可视化与测试状态逻辑的工具
