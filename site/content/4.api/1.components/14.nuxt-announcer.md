::

## 使用方式

在 [`app.vue`](/docs/directory-structure/app/app) 或 [`app/layouts/`](/docs/directory-structure/app/layouts) 中添加 `<NuxtAnnouner/>`，即可启用对屏幕阅读器的动态内容变化提示功能。这适用于表单验证、提示通知、加载状态以及页面内其他更新情况。

```vue [app/app.vue]
<template>
  <NuxtAnnouncer />
  <NuxtRouteAnnouncer />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

然后在应用程序中的任何地方使用 [`useAnnouncer`](/docs/api/组合式函数/use-announcer) 组合式函数来提示消息：

```vue [app/pages/contact.vue]
<script setup lang="ts">
const { polite, assertive } = useAnnouncer()

async function submitForm () {
  try {
    await $fetch('/api/contact', { method: 'POST', body: formData })
    polite('Message sent successfully')
  } catch (error) {
    assertive('Error: Failed to send message')
  }
}
</script>
```

## Slots（插槽）

您可以通过 announer 的默认插槽传递自定义 HTML 或组件。

```vue
<template>
  <NuxtAnnouncer>
    <template #default="{ message }">
      <p>{{ message }}</p>
    </template>
  </NuxtAnnouncer>
</template>
```

## Props（属性）

- `atomic`：控制屏幕阅读器是仅提示变化还是提示整个内容。设置为 true 则更新时显示完整内容，设置为 false 则仅提示变化。（默认值为 `true`）
- `politeness`：设置屏幕阅读器提示的默认紧急程度：`off`（禁用提示）、`polite`（等待静默）或 `assertive`（立即中断）。（默认值为 `polite`）

## 与 `<NuxtRouteAnnouncer>` 的区别

| 方面 | `<NuxtRouteAnnouncer>` | `<NuxtAnnouner>` |
|--------|------------------------|-------------------|
| **目的** | 提示路由/页面变化 | 提示任何动态内容 |
| **触发方式** | 导航时自动触发 | 通过 `polite()`/`assertive()` 手动触发 |
| **消息来源** | 页面 `<title>` | 开发者提供的内容 |
| **atomic 默认值** | `false` | `true` |
