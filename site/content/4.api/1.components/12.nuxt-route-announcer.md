## 使用方式

在 [`app.vue`](/docs/directory-structure/app/app) 或 [`app/layouts/`](/docs/directory-structure/app/layouts) 中添加 `<NuxtRouteAnnouner/>`，即可通过向辅助技术通报页面标题变化来提升可访问性。这确保了依赖屏幕阅读器的用户能够得知导航变化。

```vue [app/app.vue]
<template>
  <NuxtRouteAnnouncer />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

## Slots

您可以通过路由宣告器的默认 slot 传递自定义 HTML 或组件。

```vue
<template>
  <NuxtRouteAnnouncer>
    <template #default="{ message }">
      <p>{{ message }} was loaded.</p>
    </template>
  </NuxtRouteAnnouncer>
</template>
```

## Props

- `atomic`: 控制屏幕阅读器是仅宣布变化还是宣布全部内容。设置为 true 则更新时显示完整内容，设置为 false 则仅宣布变化。（默认值为 `false`）
- `politeness`: 设置屏幕阅读器公告的紧急程度：`off`（禁用公告）、`polite`（等待静默）或 `assertive`（立即中断）。（默认值为 `polite`）

::callout
此组件是可选的。 :br
如需完全自定义，您可以根据 [其源代码](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-route-announcer.ts)实现自己的组合式函数。
::

::callout
您可以使用 [`useRouteAnnouner` 组合式函数](/docs/api/组合式函数/use-route-announcer) 接入底层宣告器实例，从而设置自定义公告消息。
::

::callout
对于页面内内容变化的宣告（如表单验证、提示通知、加载状态等），请使用 [`<NuxtAnnouncer>`](/docs/api/components/nuxt-announcer) 组件并结合 [`useAnnouncer`](/docs/api/组合式函数/use-announer) 组合式函数。
::
