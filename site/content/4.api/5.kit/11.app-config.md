## `updateAppConfig`

更新将应用于 `nuxt.options.appConfig` 的应用配置。这对于模块设置默认值非常有用，这些默认值可以被用户配置覆盖。该更新通过 [`defu`](https://github.com/unjs/defu) 与现有配置合并。

### 类型

```ts
function updateAppConfig (appConfig: Record<string, unknown>): void
```

### 示例

```ts
import { defineNuxtModule, updateAppConfig } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    updateAppConfig({
      myModule: {
        option: 'value',
      },
    })
  },
})
```
