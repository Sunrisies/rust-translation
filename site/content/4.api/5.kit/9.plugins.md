插件是独立的代码，通常用于为 Vue 添加应用级功能。在 Nuxt 中，插件会自动从 `app/plugins/` 目录导入。然而，如果你需要将插件集成到你的模块中，Nuxt Kit 提供了 `addPlugin` 和 `addPluginTemplate` 方法。这些工具允许你自定义插件配置，以更好地满足你的需求。

## `addPlugin`

注册一个 Nuxt 插件并将其添加到插件数组中。

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/injecting-plugins?friend=nuxt" target="_blank"}
观看关于 `addPlugin` 的 Vue School 视频。
::

### 使用方式

```ts twoslash
import { addPlugin, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const { resolve } = createResolver(import.meta.url)

    addPlugin({
      src: resolve('runtime/plugin.js'),
      mode: 'client',
    })
  },
})
```

### 类型

```ts
function addPlugin (plugin: NuxtPlugin | string, options?: AddPluginOptions): NuxtPlugin
```

### 参数

**`plugin`**：插件对象或包含插件路径的字符串。如果提供的是字符串，它将被转换为插件对象，其中 `src` 设置为字符串值。

如果提供的是插件对象，它必须具有以下属性：

| 属性 | 类型 | 是否必填 | 描述 |
|------|------|----------|------|
| `src` | `string` | `true` | 插件文件的路径。 |
| -------- | ------------------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src`    | `string`                                   | `true`   | Path to the plugin file.                                                                                                                                                                                                                                                                                                                                                 |
| `mode` | `'all' \| 'server' \| 'client'`{lang="ts"} | `false` | 如果设置为 `'all'`，插件将同时包含在客户端和服务器包中。如果设置为 `'server'`，插件将仅包含在服务器包中。如果设置为 `'client'`，插件将仅包含在客户端包中。在指定 `src` 选项时，你也可以使用 `.client` 和 `.server` 修饰符，以仅在客户端或服务器侧使用插件。 |
| `order` | `number`                                   | `false`  | 插件的顺序。这允许对插件顺序进行更精细的控制，仅适用于高级用户使用。数值越小，运行优先级越高，用户自定义插件默认值为 `0`。建议将 `order` 设置为 `-20`，用于 `pre`-插件（在 Nuxt 插件之前运行的插件），设置为 `20`，用于 `post`-插件（在 Nuxt 插件之后运行的插件）。      |

::warning
除非必要，避免使用 `order`。如果只需在 Nuxt 默认设置之后注册插件，则使用 `append`。
::

**`options`**: 可选对象，包含以下属性：

| 属性 | 类型 | 是否必填 | 描述                                                                                                         |
| -------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------- |
| `append` | `boolean` | `false`  | 如果为 `true`，插件将追加到插件数组中；如果为 `false`，则将其前置。默认值为 `false`。 |

### 示例

::code-group

```ts [module.ts]
import { addPlugin, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const { resolve } = createResolver(import.meta.url)

    addPlugin({
      src: resolve('runtime/plugin.js'),
      mode: 'client',
    })
  },
})
```

```ts [runtime/plugin.ts]
export default defineNuxtPlugin((nuxtApp) => {
  const colorMode = useColorMode()

  nuxtApp.hook('app:mounted', () => {
    if (colorMode.preference !== 'dark') {
      colorMode.preference = 'dark'
    }
  })
})
```

## `addPluginTemplate`

添加模板并将其注册为 nuxt 插件。这对于需要在构建时生成代码的插件非常有用。

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/injecting-plugin-templates?friend=nuxt" target="_blank"}
观看 Vue School 关于 `addPluginTemplate` 的视频。
::

### 使用方式

```ts twoslash
import { addPluginTemplate, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options) {
    addPluginTemplate({
      filename: 'module-plugin.mjs',
      getContents: () => `import { defineNuxtPlugin } from '#app/nuxt'
export default defineNuxtPlugin({
  name: 'module-plugin',
  setup (nuxtApp) {
    ${options.log ? 'console.log("Plugin install")' : ''}
  }
})`,
    })
  },
})
```

### 类型

```ts
function addPluginTemplate (pluginOptions: NuxtPluginTemplate, options?: AddPluginOptions): NuxtPlugin
```

### 参数

**`pluginOptions`**: 包含以下属性的插件模板对象：

| 属性 | 类型 | 是否必填 | 描述                                                                                                                                                                                                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src` | `string` | `false`  | 模板的路径。如果未提供 `src`，则必须提供 `getContents`。                                                                                                                                                                                                                                                                                  |
| `filename` | `string` | `false`  | 模板的文件名。如果未提供 `filename`，将从 `src` 路径生成。此时需要提供 `src` 选项。                                                                                                                                                                                                                           |
| `dst`         | `string`                                                              | `false`  | 目标文件的路径。如果未提供 `dst`，则根据 `filename` 路径和 nuxt `buildDir` 选项生成。                                                                                                                                                                                                                                        |
| `mode`        | `'all' \| 'server' \| 'client'`{lang="ts"}                            | `false`  | 如果设置为 `'all'`，插件将同时包含在客户端和服务器包中。如果设置为 `'server'`，插件仅包含在服务器包中。如果设置为 `'client'`，插件仅包含在客户端包中。在指定 `src` 选项时，也可以使用 `.client` 和 `.server` 修饰符，以仅在客户端或服务器侧使用该插件。 |
| `options`     | `Record<string, any>`{lang="ts"}                                      | `false`  | 传递给模板的选项。                                                                                                                                                                                                                                                                                                                                         |
| `getContents` | `(data: Record<string, any>) => string \| Promise<string>`{lang="ts"} | `false`  | 一个函数，该函数将使用 `options` 对象被调用。它应返回字符串或解析为字符串的 Promise。如果提供了 `src`，则此函数将被忽略。                                                                                                                                                                                         |
| `write`       | `boolean`                                                             | `false`  | 如果设置为 `true`，模板将写入目标文件。否则，模板仅在虚拟文件系统中使用。                                                                                                                                                                                                                                 |
| `order`       | `number`                                                              | `false`  | 插件的顺序。这允许对插件顺序进行更精细的控制，仅适用于高级用户使用。数值越小，执行顺序越先，用户插件默认值为 `0`。建议将 `order` 设置为 `-20`，用于 `pre`-插件（在 Nuxt 插件之前运行的插件），以及 `20`，用于 `post`-插件（在 Nuxt 插件之后运行的插件）。      |

::warning
建议使用 `getContents` 来动态生成插件。除非必要，否则应避免设置 `order`。
::

**`options`**：可选对象，包含以下属性：

| 属性 | 类型      | 是否必填 | 描述                                                                                                         |
| -------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------- |
| `append` | `boolean` | `false`  | 如果为 `true`，插件将追加到插件数组中；如果为 `false`，则将其前置。默认值为 `false`。 |

### 示例

#### 使用不同选项生成插件模板

当需要在构建时动态生成插件代码时，请使用 `addPluginTemplate` 函数。这允许根据传递给它的选项生成不同的插件内容。例如，Nuxt 内部使用此函数来生成 Vue 应用配置。

```ts twoslash [module.ts]
import { addPluginTemplate, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (_, nuxt) {
    if (nuxt.options.vue.config && Object.values(nuxt.options.vue.config).some(v => v !== null && v !== undefined)) {
      addPluginTemplate({
        filename: 'vue-app-config.mjs',
        write: true,
        getContents: () => `import { defineNuxtPlugin } from '#app/nuxt'
export default defineNuxtPlugin({
  name: 'nuxt:vue-app-config',
  enforce: 'pre',
  setup (nuxtApp) {
    ${Object.keys(nuxt.options.vue.config!)
        .map(k => `nuxtApp.vueApp.config[${JSON.stringify(k)}] = ${JSON.stringify(nuxt.options.vue.config![k as 'idPrefix'])}`)
        .join('\n')
    }
  }
})`,
      })
    }
  },
})
```

根据提供的配置，它会生成不同的插件代码。

::code-group

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  vue: {
    config: {
      idPrefix: 'nuxt',
    },
  },
})
```

```ts [#build/vue-app-config.mjs]
import { defineNuxtPlugin } from '#app/nuxt'

export default defineNuxtPlugin({
  name: 'nuxt:vue-app-config',
  enforce: 'pre',
  setup (nuxtApp) {
    nuxtApp.vueApp.config.idPrefix = 'nuxt'
  },
})
```
