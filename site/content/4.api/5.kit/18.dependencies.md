模块通常依赖于某些项目才需要的包，或者期望用户自行安装该包。Nuxt Kit 不会假设该包已存在，也不会为用户未使用的包管理器打印安装命令，而是可以检查依赖项是否可解析，并建议使用项目自身的包管理器进行安装。

## `ensureDependencyInstalled`

检查是否安装了一个或多个依赖项，并提示用户安装缺失的依赖项。

### 使用方式

```ts twoslash
import { defineNuxtModule, ensureDependencyInstalled } from '@nuxt/kit'

export default defineNuxtModule({
  async setup () {
    if (!await ensureDependencyInstalled('sass')) {
      return
    }
  },
})
```

### 类型

```ts
function ensureDependencyInstalled (names: string, options?: EnsureDependencyInstalledOptions): Promise<boolean>
function ensureDependencyInstalled (names: string[], options?: EnsureDependencyInstalledOptions): Promise<true | string[]>
```

### 参数

**`names`**: 要检查的一个或多个包名称，如果缺失则进行安装。

**`options`**:

| 属性          | 类型       | 默认值     | 描述                                                                                                                                                            |
| ------------- | ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rootDir`     | `string`   | `nuxt.options.rootDir` | 用于解析包并安装到的目录。                                                                                                     |
| `searchPaths` | `string[]` | `nuxt.options.modulesDir` | 用于解析包的额外目录。                                                                                                         |
| `from`        | `string`   | `undefined` | 用于解析包的额外 URL 或路径，例如 `import.meta.url`。当你的包将依赖项作为同级依赖提供时非常有用。                       |
| `prompt`      | `boolean`  | `undefined` | 安装前是否提示用户。`true` 始终提示用户，`false` 从不提示（在 StackBlitz 中自动安装），未设置则仅在 StackBlitz 之外的地方提示。

### 返回值

传递单个包名称时，如果包可用则返回 `true`，否则返回 `false`。传递数组时，如果所有包都可用则返回 `true`，否则返回仍缺失的包名称数组（因为用户拒绝、安装失败或没有交互式终端）。

::note
在 CI 环境中或没有交互式终端时不会安装任何内容。在这种情况下，缺失的包会被作为诊断信息报告，并包含安装命令，函数也会将其标记为缺失，使你的模块能够优雅地降级运行。
::

## `getAddDependencyCommand`

获取用户应运行的命令，以向项目添加依赖项，该命令使用从 `cwd` 检测到的包管理器，若无法识别则 fallback 到 `npm`。在打印安装说明时使用此命令，以确保命令与项目的包管理器一致。

### 用法

```ts twoslash
import { defineNuxtModule, getAddDependencyCommand, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  async setup (options, nuxt) {
    const logger = useLogger('my-module')
    const command = await getAddDependencyCommand('sass', nuxt.options.rootDir, { dev: true })

    logger.warn(`\`sass\` is required. Run \`${command}\` to install it.`)
  },
})
```

### 类型

```ts
function getAddDependencyCommand (names: string | string[], cwd: string, options?: { dev?: boolean }): Promise<string>
```

### 参数

**`names`**: 要安装的一个或多个包名称。

**`cwd`**: 用于检测包管理器的目录。

**`options.dev`**: 指示命令是否应将包作为开发依赖项安装。
