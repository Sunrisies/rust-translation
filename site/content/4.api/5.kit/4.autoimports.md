Nuxt 提供了辅助函数、组合式函数和 Vue API，你可以在应用程序中直接使用这些功能，而无需显式导入它们。根据目录结构，每个 Nuxt 应用程序也可以对自己的组合式函数和插件使用自动导入。

使用 Nuxt Kit，你还可以添加自己的自动导入。`addImports` 和 `addImportsDir` 允许你将导入项添加到 Nuxt 应用程序中。`addImportsSources` 则允许你从第三方包中列出的导入项添加到 Nuxt 应用程序中。

这些工具由 [`unimport`](https://github.com/unjs/unimport) 提供支持，后者提供了 Nuxt 中使用的底层自动导入机制。

::note
这些函数旨在用于注册你的工具、组合式函数和 Vue API。对于页面、组件和插件，请参考相关章节：[页面](/docs/api/kit/pages)、[组件](/docs/api/kit/components)、[插件](/docs/api/kit/plugins)。
::

## `addImports`

向 Nuxt 应用程序添加导入项。这样即可在 Nuxt 应用上下文中使用这些导入项，而无需手动导入。

::tip
要为 Nitro 服务器上下文添加导入项，请参考 [`addServerImports`](/docs/api/kit/nitro#addserverimports) 函数。
::

### 用法

```ts twoslash
import { addImports, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const names = [
      'useStoryblok',
      'useStoryblokApi',
      'useStoryblokBridge',
      'renderRichText',
      'RichTextSchema',
    ]

    names.forEach(name =>
      addImports({ name, as: name, from: '@storyblok/vue' }),
    )
  },
})
```

### 类型

```ts
function addImports (imports: NuxtImport | NuxtImport[]): void
```

### 参数

`imports`: 一个对象或对象数组，包含以下属性：

| 属性       | 类型                  | 必填   | 描述                                                                                                     |
|------------|-----------------------|----------|-----------------------------------------------------------------------------------------------------------------|
| `name`     | `string`              | `true`  | 要被检测的导入名称。                                                                                     |
| `from`     | `string`              | `true`  | 要导入的模块标识符。                                                                                     |
| `priority` | `number`              | `false`  | 导入的优先级；如果多个导入具有相同的名称，则使用优先级最高的那个。 |
| `disabled` | `boolean`             | `false`  | 如果此导入被禁用。                                                                                     |
| `meta`     | `Record<string, any>` | `false`  | 导入的元数据。                                                                                         |
| `type`     | `boolean`             | `false`  | 如果此导入是纯类型导入。                                                                           |
| `typeFrom` | `string`              | `false`  | 在生成类型声明时，用作 `from` 值。                                                 |
| `as`       | `string`              | `false`  | 以此名称进行导入。                                                                                            |

## `addImportsDir`

将目录中的导入项添加到 Nuxt 应用中。它会自动导入该目录中的所有文件，并让它们在 Nuxt 应用中可用，无需手动导入。

### 使用方式

```ts twoslash
import { addImportsDir, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  meta: {
    name: '@vueuse/motion',
    configKey: 'motion',
  },
  setup (options, nuxt) {
    const resolver = createResolver(import.meta.url)
    addImportsDir(resolver.resolve('./runtime/composables'))
  },
})
```

### 类型

```ts
function addImportsDir (dirs: string | string[], options?: { prepend?: boolean }): void
```

### 参数

| 属性      | 类型                               | 必需   | 描述                                                                                                         |
|-----------|------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------|
| `dirs`    | `string \| string[]{lang="ts"}` | `true`   | 字符串或字符串数组，包含要导入的目录路径。                                      |
| `options` | `{ prepend?: boolean}{lang="ts"}` | `false`  | 传递给导入的选项。如果 `prepend` 设置为 `true`，则导入项将前置到导入列表顶部。       |

## `addImportsSources`

将列出的导入项添加到 Nuxt 应用中。

### 使用方式

```ts twoslash
import { addImportsSources, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    addImportsSources([
      { package: '@vueuse/core' },
      {
        from: 'h3',
        imports: [
          'defineEventHandler',
          'getQuery',
          'getRouterParams',
          'readBody',
          'sendRedirect',
        ],
      },
    ])
  },
})
```

### 类型

```ts
function addImportsSources (importSources: NuxtImportPresetSource | NuxtImportPresetSource[]): void
```

### 参数

**importSources**: 包含以下属性的对象或对象数组：

- `NuxtImportPreset`

| 属性      | 类型                                                 | 必需   | 描述                                                                       |
|-----------|------------------------------------------------------|----------|-----------------------------------------------------------------------------------|
| `from`    | `string`                                             | `true`   | 要导入的模块指定符。                                                  |
| `imports` | `(NuxtImportEntry \| NuxtImportPreset)[]{lang="ts"}` | `true`   | 条目数组，可以是导入名称、导入对象或嵌套预设。                           |

- `NuxtPackageImportPreset`

| 属性      | 类型     | 必需   | 描述          |
|-----------|----------|----------|----------------------|
| `package` | `string` | `true`   | 包的名称。 |
